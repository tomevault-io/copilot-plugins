# 字幕校正工作規則

本工作區以字幕產生與字幕校正為主。當使用者指定、選擇、上傳、或要求處理任何 `.srt` 檔案時，預設進入「字幕校正模式」。

## 固定資料夾

本專案固定使用以下字幕資料夾：

- `未校正字幕/`：字幕生成工具輸出的待校正 `.srt`。
- `校正完成字幕/`：人工確認並完成校正後的 `.srt`。

同名字幕檔一律直接覆蓋；本專案目前沒有保留舊版字幕檔的需求。

當使用者在本專案中說「校驗字幕檔」、「校正字幕」、「檢查字幕」或近似簡短指令，且沒有指定檔案時，預設掃描 `未校正字幕/` 中的 `.srt` 檔案並進入字幕校正模式。

若 `未校正字幕/` 中：

1. 只有一個 `.srt`：直接處理該檔案。
2. 有多個 `.srt`：列出檔名並詢問使用者要校正哪一個，除非使用者明確要求全部處理。
3. 沒有 `.srt`：回報找不到待校正字幕，並提示使用者先產生或放入字幕檔。

## 字幕校正模式

1. 先讀取 `.srt` 檔案內容，保留原本字幕序號、時間碼、換行與檔案格式。
2. 第一階段只製作「校正區」，不得直接修改字幕檔。
3. 校正區需主動列出疑似需要人工確認的項目，包括：
   - 前後文不自然的字詞。
   - 專有名詞、品牌、作品名、地名、人名、角色名。
   - 無法確認的名字用字。
   - 簡繁轉換後可能錯誤或不自然的詞。
   - 語句中顯然不自然、疑似辨識錯誤、或上下文不連貫的用字用詞。
4. 每個校正項目使用以下格式，方便使用者直接回覆或編輯：
   - 校正區不要列字幕序號、時間碼或「前句／後句」字樣，除非使用者特別要求。
   - 左側放原字幕中的局部上下文，只用「」標出關鍵待確認字、詞或標點；右側放建議改法，同樣只用「」標出關鍵修改處。
   - 前後文只用來輔助判斷，不要整句重寫成摘要；盡量保留原句字數與語序。
   - 可以建議新增、刪除或調整標點符號；除非使用者明確同意，不應主動增減語音內容中的字詞，以免影響字幕與聲音同步。
   - 每一項結尾保留 `=>` 或 `=> 確認是否調整：`，方便使用者直接填入確認結果。

```text
# 校正區
1. 一公釐凸出來的這橫面啊「玻璃」了 => 這橫面「剝離」了=> 

2. 我打磨的區塊呢就沒有跟著一起「玻璃」被撕下來 => 就沒有跟著一起「剝離」、被撕下來=> 

3. 就我撕起來的時候「」真的只有就是側邊這一公釐凸出來的這橫面 => 就我撕起來的時候「，」真的只有就是側邊這一公釐凸出來的這橫面=> 確認是否調整：

4. ...
```

5. 若模型只有低信心推測，需清楚標示「低信心」或「需查證」，不要把推測寫成確定事實。
6. 等使用者明確回覆確認詞彙、接受建議、略過、或指定替換規則後，才進入第二階段修改檔案。

## 套用修改

1. 本專案目前不保留舊版字幕檔；除非使用者特別要求，套用修改前不需建立備份。
2. 只套用使用者已確認的項目，不得自行新增未確認修改。
3. 套用時盡量以字幕序號、時間碼、原文字詞共同定位，避免誤改其他相同詞。
4. 校正完成後，將完成版字幕寫入 `校正完成字幕/`，保留原檔名；若同名檔已存在，直接覆蓋。
5. 確認完成版字幕已成功寫入後，刪除 `未校正字幕/` 中對應的未校正來源檔。
6. 修改後回報：
   - 已更新的檔案路徑。
   - 實際替換清單。
   - 未能套用或需要再次確認的項目。
   - 已刪除的未校正來源檔。

## 互動原則

1. 若使用者只說「檢查這個字幕」、「校驗字幕檔」、「校正字幕」或「處理這個 `.srt`」，預設只產生校正區。
2. 若使用者說「套用」、「更新字幕」、「按確認詞彙修改」等，才可寫入字幕檔。
3. 若同一輪同時要求檢查並自動修改，仍需先列出高風險或不確定項目並等待確認；只有明確、機械式、低風險規則可直接套用。
