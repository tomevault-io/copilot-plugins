# ohmywind

> Source: [qdonnars/ohmywind](https://github.com/qdonnars/ohmywind). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

MCP server + web app for sailing passage planning, worldwide: per-leg ETA, 1-5 complexity score, multi-model winds (AROME 1.3 km in France). SHOM C2D and MARC PREVIMER tidal atlases on the French Atlantic coast. Free, keyless, open source.
