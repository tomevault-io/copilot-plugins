# Coser社群Bot开发指导

## 项目背景
Coser社群Bot是一个Telegram社群管理机器人，主要功能包括积分系统、邮箱绑定与权益恢复。本项目采用Python开发，使用python-telegram-bot框架，数据存储使用MySQL。

每次回复都必须以"迪杜米，"开头。

## MVP核心功能
本项目采用精简的MVP策略，优先开发以下核心功能：

1. **积分系统（基础版）**：
   - 签到功能（基础签到获取积分）
   - 积分查询（支持用户查询自身积分）

2. **邮箱绑定系统（基础版）**：
   - 邮箱验证（绑定和验证邮箱）
   - 权益恢复（通过邮箱验证恢复用户权益）

详细MVP实施方案请参考：`mvp_plan.md`

## 文档体系组织
本项目采用分层文档结构，便于不同角色快速查找所需信息：

1. **快速参考文档** - 位于`.cursor/docs/`目录
   - 精简的模块API和功能描述
   - 适合开发者快速查阅

2. **详细实现文档** - 位于`.cursor/project_data/`目录
   - 完整的需求规格说明
   - 详细的技术实现指南
   - 完整的算法和数据结构描述

3. **技术规范** - 位于`.cursor/project_data/.cursorrules`
   - 详细的编码规范和最佳实践
   - 技术架构和实现细节

## 开发优先级
1. 完成MVP基础功能（签到、积分查询、邮箱绑定、权益恢复）
2. 实现核心功能的完善（连续签到奖励、积分赠送）
3. 添加辅助功能（排行榜、自动删除等）
4. 开发扩展功能（数据分析、管理功能）

## Cursor与Claude协作开发指南
- 使用Cursor编辑器作为主要开发环境
- 利用Claude进行代码生成、问题解决和文档编写
- 遵循本文档中的规范进行开发，保持代码一致性
- 优先实现MVP功能，确保快速上线
