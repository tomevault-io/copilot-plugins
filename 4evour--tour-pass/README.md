# Tour-Pass

> Tome by [4evour](https://github.com/4evour/Tour-Pass) — distributed by [TomeVault](https://tomevault.io)

Tour Pass 是一个 AI 行程规划系统。项目结合多 Agent 协作、帮助用户根生成可解释、可编辑、可保存的多日旅行方案。项目支持 AI 对话规划、结构化表单规划、热门行程推荐、行程保存与分享、小红书笔记/截图解析等功能。
