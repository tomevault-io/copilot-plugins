# VideoLingua

> Source: [skindhu/VideoLingua](https://github.com/skindhu/VideoLingua) — distributed by [TomeVault](https://tomevault.io)

视频字幕处理工具 - 一站式视频字幕提取、翻译、烧录和内容总结解决方案。基于OpenAI Whisper和Google Gemini API，支持多语言处理、双语字幕、自定义烧录和智能视频内容总结。模块化设计，既可独立使用各功能，也可一键完成全流程处理。适合内容创作者、翻译人员和视频编辑工作者使用。
