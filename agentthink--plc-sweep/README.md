# plc-sweep

> Source: [agentthink/plc-sweep](https://github.com/agentthink/plc-sweep). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

做上位机/网关开发时找设备地址用的 Windows 工具。不联网也能靠内置的 53964 条离线 MAC 前缀认出西门子、汇川等厂商；禁 ping 的设备靠 ARP 应答抓；扫完按 S7(102)、Modbus TCP(502)、EtherNet/IP(44818)、OPC UA(4840) 端口指纹直接标出"这台是 PLC"。
