Automatically synthesize code harnesses for LLM agents  AutoHarness is a Rust library that automatically generates and optimizing code harnesses for LLM agents, following the approach described in the AutoHarness paper. It uses tree search with Thompson sampling to iteratively refine harness code, achieving an average of 14.5 iterations to reach 10
