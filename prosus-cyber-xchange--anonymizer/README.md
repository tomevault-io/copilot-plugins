# anonymizer

> Source: [Prosus-Cyber-Xchange/anonymizer](https://github.com/Prosus-Cyber-Xchange/anonymizer). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

A REST API service and embeddable Go library for PII detection and anonymization — email, CPF, credit cards, phone numbers, and more. Uses leakspok for analysis with Valkey/Redis caching.
