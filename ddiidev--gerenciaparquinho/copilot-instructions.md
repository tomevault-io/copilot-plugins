# Agent Instructions

## Design Guidelines

- **Botões e Componentes**: Use sempre botões com um formato mais quadrado com arredondamento agressivo (ex: `RoundedCornerShape(12.dp)`). **Nunca** utilize botões totalmente redondos (`CircleShape`). Isso deve ser o padrão para toda a interface onde houver botões, caixas de destaque ou chips.
