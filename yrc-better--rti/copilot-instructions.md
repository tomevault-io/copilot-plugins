# AGENTS

本仓库 `RTI` 定义的是一个“对话式文献研究 workflow”，不是 prompt 集合。

## 触发条件

当用户提供以下任一内容时，直接启动 workflow，而不是要求用户再粘贴模板：

- 一个研究方向
- 一句类似“我想研究 XXX”
- 一句类似“帮我搜这个方向的论文”
- 一句类似“按这个仓库的 workflow 开始”

## 默认工作方式

如果用户只给出研究方向，agent 应按以下步骤自动推进：

1. 联网检索与该方向相关的论文，优先 arXiv，也可用其他高质量来源辅助判断相关性。
2. 输出当前批次论文的：
   - 标题
   - 中文版摘要
   - 简短点评
3. 在这一步停下，明确让用户选择：
   - 哪几篇继续
   - 或者重新搜一批
4. 对用户选中的论文：
   - 如果用户指定了输出目录，保存到用户指定的位置
   - 如果用户没有指定输出目录，则默认在用户“文档 / Documents”目录下创建 `论文原文`、`文献翻译`、`文献解读` 三个目录
   - 保存原文 PDF 到 `论文原文/<研究方向>/`
   - 使用 `arxiv-translator` skill 生成中文 PDF 到 `文献翻译/<研究方向>/`
   - 中文 PDF 文件名必须以 `_CN.pdf` 结尾
5. 对用户选中的论文使用 `paper-glance` 风格输出深度分析、思维导图、审稿意见，并保存到 `文献解读/<研究方向>/`

## 硬性规则

- 不要在第 3 步之前直接开始翻译或全文解读
- 点评阶段只能基于标题、摘要和元数据，不要伪造全文细节
- 用户说“重新搜一批”时，继续往后翻一批结果，而不是重复同一批
- 默认一次先给 3 篇；如果方向很宽，可给 5 篇，但仍然必须经过第 3 步选择
- 产物必须写入用户自定义目录，或默认写入用户文档目录，不写回当前仓库
