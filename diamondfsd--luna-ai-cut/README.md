# luna-ai-cut

> Source: [diamondfsd/luna-ai-cut](https://github.com/diamondfsd/luna-ai-cut) — distributed by [TomeVault](https://tomevault.io)

Luna AI Cut 是一款面向 Insta360 Luna Ultra 相机的桌面媒体管理工具。PC 通过 Wi-Fi 连接相机后，可以浏览、选择、下载相机中的照片和视频，支持水印导出、批量操作、边到边预览等丰富功能。
