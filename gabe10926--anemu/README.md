# anemu

> Source: [gabe10926/anemu](https://github.com/gabe10926/anemu). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Android based emulator front end that interacts directly with the eden switch emulator an the retroarch retro gaming emulator without needing to interact with those emulators UI's at all.
