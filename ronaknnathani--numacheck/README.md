# numacheck

> Source: [ronaknnathani/numacheck](https://github.com/ronaknnathani/numacheck) — distributed by [TomeVault](https://tomevault.io)

A CLI that analyzes NUMA topology for a process — shows CPU affinity, core/socket mapping, NUMA node distribution, and GPU locality. Built for diagnosing container CPU/GPU placement on Kubernetes nodes.
