# MCP Python Bitcoinlib

MCP server exposing python-bitcoinlib functionality.

## When to use this skill

Use this skill when you need to:
- Generate Bitcoin keys and addresses
- Create and sign transactions
- Work with Bitcoin scripts
- Perform ECDSA operations on secp256k1

## Tools

- **Key Management**: Generate private keys, WIF/hex conversion
- **Address Generation**: P2PKH, P2SH, P2WPKH, P2WSH
- **Transaction Building**: Create and sign transactions
- **Script Operations**: Parse and create Bitcoin scripts
- **Cryptography**: SHA256, RIPEMD160, Hash160, Hash256, ECDSA

## Install

```bash
pip install mcp-python-bitcoinlib
```
