# Java Practice

## What is it?
A Java practice and learning project for building skills through hands-on coding exercises.

## Tech Stack
- Java (JDK)

## How to Compile and Run
```bash
javac Main.java
java Main
```

To compile all Java files at once:
```bash
javac *.java
```

## Project Structure
```
java-practice/
  Main.java       # Main entry point and practice exercises
  CLAUDE.md       # This file
  PROJECT.md      # Project goals and progress
  .gitignore      # Java build artifacts to ignore
  .claude/
    settings.json # Claude Code project settings
```

## Notes
- Each exercise or experiment lives in Main.java or its own file
- Compiled `.class` files are ignored by git (they're build artifacts)
