# metrognome

> Tome by [uphold](https://github.com/uphold/metrognome), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

The autonomous performance engineer for React Native - An AI Plugin that views the screen, reads Hermes, and applies effective RN fixes. Built to run locally or on CI, it can generate a 3D performance map of all your RN components, and keep a per-repo memory that learns from your app's patterns over time.
