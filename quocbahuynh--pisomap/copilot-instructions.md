# PISO SaaS v2 — Monorepo Guide

5 independent projects under `/`. Each has its own stack, dependencies, and scripts — no shared tooling.

## Projects at a Glance

| Path | Stack | Entrypoint |
|------|-------|------------|
| `my-backend/PISO` | .NET 8, C# | `dotnet run --project PISO.WebApp` |
| `my-cronjob` | Node 22, TS 6 | `npm run harvest-sessions` (tsx, no build) |
| `my-frontend` | Next.js 16, React 19 | `npm run dev` |
| `my-docs` | Next.js 16, Fumadocs | `npm run dev` (static export) |
| `my-lab` | Python 3.14 | `python extract_search.py` |

## Commands

### Backend (`my-backend/PISO`)
- `dotnet build` — build solution
- `dotnet run --project PISO.WebApp` — run API
- `dotnet watch run --project PISO.WebApp` — hot-reload
- `dotnet format` — auto-fix whitespace, unused usings
- Middleware pipeline order: `ApiKeyMiddleware` → `RateLimitingMiddleware` → `UsageTrackingMiddleware` → Controller
- Error responses: always `ApiErrorResponse { Success = false, StatusCode, Message }`
- Missing `Data/google-sessions.json` or `Data/proxy.txt` throws (fail-hard)

### Cronjob (`my-cronjob`)
- `npm run harvest-sessions -- --count N [--headed]` — harvest sessions
- `npm run test-proxies` — benchmark & auto-cleanup proxies
- `npx tsc --noEmit` — typecheck only (no build, tsx runs .ts directly)
- `module: "nodenext"` + `verbatimModuleSyntax` → imports need `.js` extension, type-only imports use `import type`
- CloakBrowser binary downloads to `~/.cloakbrowser/` (~200MB, NOT in node_modules)
- Import from `cloakbrowser/puppeteer`, not `puppeteer-core`
- JSON Lines logging (`console.log(JSON.stringify({...}))`), exit 0 if ≥1 sessions, 1 if all fail
- `store.ts` only has `writeSessions` (overwrites) — no read/append/dedup

### Frontend (`my-frontend`)
- `npm run dev` / `npm run build` / `npm run start` / `npm run lint`
- No `typecheck` script exists — use `npx tsc --noEmit` if needed
- No test framework
- Next.js 16 App Router, React 19, CSS Modules (NOT Tailwind), Redux Toolkit
- `@/*` → `./src/*` (tsconfig paths)
- Firebase Auth: client-side only, no Admin SDK. `__session` cookie is sole auth signal.
- `AuthProvider` only wraps `/dashboard` layout (cost-saving, Firebase SDK never initializes on landing/docs/login)
- `globals.css` + `*.module.css` for styling. CSS custom properties from `DESIGN.md` (Runwai monochrome palette)
- Button variants: `primary`, `primary-on-dark` (hyphen→underscore class), `ghost`, `ghost_on_dark`, `text-link`

### Docs (`my-docs`)
- `npm run dev` / `npm run build` / `npm run start` (serves `out/` via `serve`)
- `npm run types:check` — runs `fumadocs-mdx && next typegen && tsc --noEmit` (in order)
- Static export (`output: 'export'`), bilingual EN/VN
- `.source/` is generated by `fumadocs-mdx` (gitignored) — run `npx fumadocs-mdx` after content changes
- Postinstall runs codegen automatically
- `collections/*` alias → `.source/*`

### Lab (`my-lab`)
- Stdlib only, no external deps, no `requirements.txt`
- `data.json` needs `)]}'` prefix stripped before parsing
- `extract_search.py` handles invalid JSON escapes via `fix_invalid_escapes()`

## Cross-Cutting

- **No test framework** configured in any project
- **Docker**: only backend has a Dockerfile (`PISO.WebApp/Dockerfile`) + `compose.yaml`
- **CI**: only cronjob has GitHub Actions (`.github/workflows/harvest.yml`, 6h schedule)
- **Env files**: each project uses its own `.env` or `.env.local` — none are committed
- **Root `.gitignore`** aggregates all sub-project ignores
