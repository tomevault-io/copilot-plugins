# Musubi project rules (Cursor)

The contract for every coding agent and contributor on this repo is [AGENTS.md](mdc:../../AGENTS.md).
Read it top to bottom before any edit. It is the only copy of the rules, so this file stays a pointer.

The short version: work from a GitHub issue, open a draft PR early, write the spec's Test Contract as
tests first, keep the canonical API frozen, run `make check` and `make agent-check`, and let someone
else review and merge.
