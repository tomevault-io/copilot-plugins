# faro-flutter-sdk

> Source: [grafana/faro-flutter-sdk](https://github.com/grafana/faro-flutter-sdk) — distributed by [TomeVault](https://tomevault.io)

The Grafana Faro Flutter SDK, part of the Grafana Faro project, is a highly configurable flutter SDK for real user monitoring (RUM) that instruments flutter applications to capture observability signals. Flutter frontend telemetry can then be correlated with backend and infrastructure data for full-stack observability.
