# Kindly-Web

> Source: [ClauBloom/Kindly-Web](https://github.com/ClauBloom/Kindly-Web). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Kindly Web 是一款开源的 Chrome 浏览器插件。它会在你浏览网页时自动扫描评论区（目前已适配 Bilibili），并调用大语言模型将带有攻击性、阴阳怪气或负面情绪的评论，实时重写为和谐、友善且理性的表达。让你在享受内容的同时，不被戾气影响心情。
