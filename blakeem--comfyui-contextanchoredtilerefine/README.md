# ComfyUI-ContextAnchoredTileRefine

> Source: [Blakeem/ComfyUI-ContextAnchoredTileRefine](https://github.com/Blakeem/ComfyUI-ContextAnchoredTileRefine). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Seamless tiled refinement and upscaling for ComfyUI. The VL nodes step all tiles on one shared latent, conditioned by vision tokens and per-tile captions instead of a prompt, so objects never repeat across tiles. Refine whole images or just a masked region. Any GUIDER model on the base node; Krea 2 on the VL nodes. Tested at 8K+.
