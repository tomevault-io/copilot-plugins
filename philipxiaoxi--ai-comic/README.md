AI 漫画创作平台 是一个 AI 驱动的漫画自动生成工具。用户通过角色库管理角色设定，AI 自动生成分镜脚本和漫画图像，支持多章节连载模式。平台提供经典漫画分格布局、漫画预览与 PDF 导出功能，支持本地存储、腾讯云 COS、咸鱼云等多种存储方案。管理员可在后台灵活配置 AI 模型（如 OpenAI、MiniMax）和图片生成服务。技术栈采用 Vue 3 + Vuetify 前端和 Egg.js + SQLite 后端，轻量易部署。
