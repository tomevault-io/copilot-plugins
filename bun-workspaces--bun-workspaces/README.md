# bun-workspaces

> Source: [bun-workspaces/bun-workspaces](https://github.com/bun-workspaces/bun-workspaces) — distributed by [TomeVault](https://tomevault.io)

A tool for managing monorepos using Bun. Not a framework but an enhancement to native workspaces. Develop JavaScript and TypeScript projects with the bun-workspaces CLI and API.
