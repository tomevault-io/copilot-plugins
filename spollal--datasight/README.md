# datasight

> Source: [SpollaL/datasight](https://github.com/SpollaL/datasight). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Fast terminal viewer (TUI) for CSV, TSV, Parquet, JSON, and NDJSON files. Vim-style keybindings, instant filtering, multi-column sort, group-by aggregations, multi-series plots, and automatic date detection. A modern command-line data explorer built in Rust with ratatui.
