# nestjs-fastify-nx

> Source: [chuanghiduoc/nestjs-fastify-nx](https://github.com/chuanghiduoc/nestjs-fastify-nx) — distributed by [TomeVault](https://tomevault.io)

Production-grade NestJS 11 + Fastify 5 + Nx 22 monorepo boilerplate. DDD/CQRS, Better Auth cookie sessions, GraphQL (Mercurius), Socket.io, BullMQ, Prisma 7, OpenTelemetry, Sentry. Four runnable apps (api/worker/scheduler/migration) with hardened Docker images, SBOM + SLSA provenance, and Cosign keyless signing.
