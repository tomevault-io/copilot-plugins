# Versanasium 维偲苑

AI 驱动的教育生态平台，通过「维偲化」方法论将课程资源拆解为结构化知识单元体系，实现个性化学习路径规划。

## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/<feature-slug>/issues/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` — recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root + `docs/adr/`. Always read `CONTEXT.md` before any task — it defines the Versanasium domain vocabulary and Avoid lists. See `docs/agents/domain.md`.
