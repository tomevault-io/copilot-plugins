# DigiFrame

> Source: [manoharc07/DigiFrame](https://github.com/manoharc07/DigiFrame). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

A wall frame for a 64×64 HUB75 LED matrix, turning it into a smart clock. It shows an NTP clock, live weather, a living ambient scene, looping GIFs, scrolling messages, and themed celebrations on your special days — controlled from a web dashboard, Bluetooth, a Telegram bot, or Home Assistant.
