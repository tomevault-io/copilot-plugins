# 改根因，勿堆兜底

1. 在真正出错处做最小修正（换序 / 改核心分支）。
2. 禁止用 enrich、伪造字段、重复 helper、堆 if 掩盖问题。
3. 根因修好后删临时补丁；变量紧贴使用处。
