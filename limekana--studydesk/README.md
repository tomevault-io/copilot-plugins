# StudyDesk

> Source: [Limekana/StudyDesk](https://github.com/Limekana/StudyDesk). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

StudyDesk is a study planner designed to combat procrastination. It includes a minimal but functional UI with an exam calendar, pomodoro timer and most importantly the next up page, that suggests things to do based on your courses and assignments. StudyDesk is an android mobile app
