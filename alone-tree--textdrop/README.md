# TextDrop

> Tome by [alone-tree](https://github.com/alone-tree/TextDrop) — distributed by [TomeVault](https://tomevault.io)

TextDrop 是一个轻量级跨设备输入工具。  用户可以在手机浏览器中输入文字，或使用手机输入法的语音输入能力将语音转成文字，然后点击发送按钮，将文本直接发送到 Windows 电脑当前光标所在位置。
