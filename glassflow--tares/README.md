# tares

> Tome by [glassflow](https://github.com/glassflow/tares), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

The open-source platform for always-on AI agents. Connect anything that emits events; Tares puts every event on one timeline per thing, wakes an agent the moment it matters, and keeps the answer for the next reader. Works with Claude Code, Cursor and your own agents over MCP.
