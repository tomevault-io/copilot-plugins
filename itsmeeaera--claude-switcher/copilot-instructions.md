# CLAUDE.md

This file provides guidance to Claude Code when working with this repository.

## Build & Run

```bash
go test ./...
make build
make install
```

`make install` writes the binary to `~/.local/bin/claude-switcher` by default.

## Architecture

`claude-switcher` is a Go CLI for switching Claude Code API profiles (endpoint + key). The user-facing command is `cw`, a shell function generated by `claude-switcher init`.

Key constraint: TUI output must render to `stderr`, and shell export commands must be the only content printed to `stdout`. The shell wrapper evals stdout to set environment variables in the current shell session.

## Packages

- `cmd/` — subcommand routing and command handlers.
- `tui/` — Bubbletea models. `app.go` is the main profile hub, `check.go` is the animated check screen, `form.go` is the add/edit profile form, and `styles.go` owns Lipgloss styles.
- `config/` — profile metadata in `~/.config/claude-switcher/profiles.json`, atomic saves, endpoint normalization.
- `keychain/` — macOS Keychain access for API keys.
- `shell/` — shell-safe export generation for `ANTHROPIC_BASE_URL` and `ANTHROPIC_API_KEY`.
- `api/` — connectivity checks against Anthropic-compatible `/v1/messages`.
- `assets/` — README visual previews.

## Endpoint Rule

Claude Code appends `/v1/messages` internally. Store and export base hosts such as:

```bash
https://api.example.com
```

The config and shell layers normalize accidental `/v1` suffixes.

## Secret Storage

API keys are stored in macOS Keychain through `keychain/`. The profile JSON stores `key_ref`, not raw keys. Older configs with `api_key` are migrated by `cmd/loadConfig()` and then saved without raw keys.

## Shell Integration

The user's shell should contain:

```bash
eval "$(claude-switcher init)"
```

That defines `cw()`, which evals only the binary's stdout.
