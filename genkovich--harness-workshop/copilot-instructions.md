Відповідай українською. Починай дайджест словами «Огляд обговорень HN».
Тема: harness engineering, coding agents, tool calling, контекст і перевірка результатів.
Для кожної теми вкажи посилання на обговорення та використані коментарі.
Не називай думку автора коментаря доведеним фактом. Не вигадуй відсутні заперечення.
