# CLAUDE.md — 法考网课字幕结构化笔记

## 项目目标

把法考网课字幕整理成三个版本的学习笔记,对应**预习 → 深入 → 冲刺**三个复习阶段。

使用者复习节奏很紧(每科 1–3 天,每天最多 10 小时)。笔记的价值在于**快速定位考点**和**避免背错**,不在于完整复述课程。**篇幅超标等同于失败**——读不完的笔记价值为零。

本 vault 同时是 Obsidian 库,输出的 md 要符合下方 Obsidian 约定。

> 本文件只规定**产出什么**。分组、排序、幂等跳过、输入校验、并发控制由外部驱动脚本负责,不在本文件范围内。

---

## ⚠️ 五条铁律(优先级高于本文件其他一切规定)

违反任一条,产出即作废重跑。这五条**不接受任何理由的例外,包括"补充的内容确实是对的"**。

1. **字幕里没有的,笔记里就没有。** 知识点、法条编号、例题、口诀、答题模板、金句——一律只能来自输入字幕。你的法律知识只用于**读懂**字幕,不用于**补全**字幕
2. **数字只能抄,不能想。** 期限、比例、年龄、金额、条文号、要件个数,照字幕写。字幕含混或自相矛盾时标 `【?】` 并附原文片段,**不得用你记得的正确答案覆盖**
3. **表述宁笨不改。** 字幕的法律表述哪怕拗口、不像教科书,也保留其原意。不得"顺手改成标准说法"——这是最难发现的一类错误
4. **不确定就标,不要圆场。** 拿不准一律 `【?】`。空缺可以事后补,错误会被当成对的背下去
5. **只有篇幅上限,没有下限。** 输入短就输出短,不得为凑长度扩写

使用者**尚未学过**这些科目,没有能力识别错误。一处错误会被原样背进考场。**空缺的代价远小于错误。**

## 分科规范

本文件只写**八科通用**规则。每科的差异(篇幅上限、专属输出要求、学理处理、专属 ASR 错字表)写在:

```
00_规范/<部门法>.md
```

处理某科时**必须同时读取本文件与该科规范文件**。两者冲突时,**以分科文件为准**。

⚠️ **本次运行未实际读到分科规范文件时,中止并报告,不得用通用规则代跑。**
缺了分科文件会丢掉篇幅上限、专属输出要求、专属 ASR 错字表,而**产出看起来完全正常**——
这是最容易发生、也最难事后察觉的一种失败。开始处理前先声明你读到了哪两个文件。

## 主线老师

**每科只有一条主线(一位老师)**,记录在该科规范文件中。

- 该字段为 `【待填】` 且该科存在多位老师素材时,**中止并询问**,不得自行选择,不得同时读取多个目录
- 该科只有一位老师时,此字段可留空
- 其他老师的素材仅在**显式指定单个专题**时处理,产出到 `<部门法>/补充/`,文件名加老师标识

⚠️ 补充笔记**不参与** `_预习.md` 和 `_冲刺.md` 的汇总。并入会让双老师的体系差异和口诀冲突重新污染主线。

## 输入

通常由驱动脚本按专题拼接后传入。若需自行分组,规则如下。

素材文件名实例:

```
001_国际法 - 专题01：导论_clean.txt
002_国际法 - 专题02：国际法主体和国际法律责任（一）_clean.txt
003_国际法 - 专题02：国际法主体和国际法律责任（二）_clean.txt
```

⚠️ **不要解析整个文件名。** 分隔符风格不统一(下划线 / 空格 / 短横 / 全角冒号),分部号可能是中文括号、也可能不存在。只抽两个数字:

| 抽取项 | 规则 |
|---|---|
| **集号** | 文件名开头的连续数字 |
| **专题号** | 字符串 `专题` 之后的连续数字 |

**集 ≠ 专题。一个专题可能跨多集。**

1. 按**专题号**分组
2. 组内按**集号升序**排列,一起读入,合并产出**一个**专题笔记
3. 专题名取自组内第一个文件
4. 不要逐集产出笔记,也不要把多个专题合并成一个文件

### ⚠️ 一个目录内含多个学科时必须二级分组

**三国法一个素材目录里混装了国际公法、国际私法、国际经济法三个子学科**,
靠文件名区分,而**三个子学科各自都有「专题01」**。

只按专题号分组会把三份不相干的内容合并成一个文件——而合并后的笔记
**看起来仍然是完整的**,这种错误极难察觉。

处理三国法时按 **子学科 + 专题号** 分组,判断规则见 `00_流程/目录映射.md`
(⚠️ 匹配顺序不可颠倒)。

⚠️ 自行分组时**先输出分组结果**(专题号 → 文件列表)供确认。分组错误会产出残缺笔记且难以察觉:某专题只处理了前半部分时,笔记本身看起来是完整的。

### 输入格式已知情况

- `_clean.txt` **有单行版也有多行版**(部分素材已按句末标点断行,便于处理)。
  两种都不代表内容残缺
- ⚠️ **换行是清洗产物,不是语义分段。** 不要把断行当成段落或话题切换,按语义连读即可
- 句子可能被字幕切割点打断,同样是拼接产物
- 溯源片段照抄原文时**不要跨行截取**;若必须跨行,片段中不保留换行

### ⚠️ 字数的统计口径

**本文件所有「字数」一律指字符数(一个汉字算 1 个),不是字节数。**

UTF-8 下一个汉字占 3 字节。把字节数当字数,会让**篇幅上限虚高约 3 倍**、
**输入校验阈值放松约 3 倍**,而且两处都朝着最坏的方向错。

> 实测案例:国际公法专题03 三集合计实际 **39,344 字**,按字节统计报出 **123,173**,
> 38% 上限从 14,951 虚增到 46,806 —— 按后者产出的"笔记"会比原始字幕本身还长,
> 直接反掉「读不完的笔记价值为零」这个前提。

统计时排除换行与空白:

```
tr -d '\n\r' < 文件 | wc -m       # ✅ 字符数
wc -c < 文件                      # ❌ 字节数
```

⚠️ 报出字数后**先自查量级**:一集网课字幕通常 8,000–25,000 字。
若单集报出 7 万以上,几乎一定是把字节当成了字数。

### 输入校验

> **任一输入文件字数 < 2000,中止并报告文件名,不生成笔记。**

上游清洗脚本存在"广告词整行删除 + 单行文件 = 命中即整集清空"的缺陷。若不校验,会拿着空文件产出一份**结构看起来完整但内容缺失**的笔记——这是静默失败,事后极难发现。

## 生成顺序

```
第一步:逐专题产出深入版(专题之间无依赖)
   ↓ 该部门法全部深入版完成(屏障)
第二步:从深入版汇总 _预习.md 和 _冲刺.md
第三步:回填分科规范文件
```

预习版和冲刺版是**部门法级汇总文件**,**只从深入版提炼,不回头读字幕**。这样三版内容一致,也省 token。

汇总时若发现深入版之间**结论冲突**(同一概念不同表述、结论不一致),标 `#冲突` 并列出双方出处,**不要自行选择一方**。

## 考点分级(三版通用)

| 级别 | 判定依据 |
|---|---|
| ★★★ | 老师明说"必考""年年考";或考情显示已连续多年考察 |
| ★★ | 老师明说这是考点("这是考点""勾一下""考试会考") |
| ★ | 老师提及但未标注重要性 |

⚠️ **老师完全未表态的不标星。** 重要性判断必须来自老师或考情,**不得来自你的先验知识**。

三版沿用同一级别,不得出现级别不一致。

## 主观题相关内容(条件产出)

> 本科是否涉及主观题,见分科规范文件。

**唯一规则:老师讲了就写,老师没讲就整节省略。**

- 老师给出**答题步骤、答题结构、答题模板、主观题提示** → 深入版末尾设 `## 主观题` 小节保留
- 老师给出**适合采分的表述、要求原样记住的句子** → 收入冲刺版「必背金句」
- ❌ 老师未讲的,**不得自编答题模板,不得自造采分句式**。自编的答题结构无法验证,会让使用者形成错误答题习惯,危害大于空缺
- 没有主观题内容时**不出现该小节**,也不要写"本专题未涉及主观题"之类的占位说明

## 三版规格

### 深入版 `<部门法>/专题NN <专题名>.md`

主力材料,一个专题一个文件。

- 保留所有**考点**,每个考点标注星级。非考点的背景解释、理论溯源可压缩或省略;确有助于理解的用引用块保留,不超过三行
- **法条依据置于该考点开头**。老师给出法条编号或条文表述的提到最前;⚠️ 老师未给出的**不得自行补充**,可标 `【原文未引法条】`
- 保留考点提示、真题及选项解析
- 保留精讲书页码,统一格式 `P9`、`P13`(字幕中的"第九页"须转换),并在 frontmatter 记录范围
- 老师举的案例:**保留案例本身,压缩叙述**。一到两行说清,不复述完整故事
- 易混淆点一律用对比表格
- 老师明确说"这是考点""考试会考""勾一下""口诀""易错"的,全部保留并标注
- 考情信息("这个考过两年了""这几类还没考过")视为重点内容,必须保留
- 详略按考点重要性分配,不追求各专题篇幅一致
- 老师讲了主观题方法时设 `## 主观题` 小节;未讲则不设
- 文件末尾附「字幕校对说明」

**篇幅上限:该专题输入总字数的 X%(X 见分科规范文件)。**

⚠️ **计算基数只含正文考点内容。** 下列不计入字数,**不得为压字数而删减它们**:

| 不计入 | 原因 |
|---|---|
| frontmatter | 元数据 |
| 「字幕校对说明」 | **回填分科错字表的唯一数据源**,删了这条链就断,且事后无法察觉 |
| `_自检/专题NN.md` | 独立文件,本就不在笔记内 |

⚠️ 超标时的删减次序,不得颠倒:

1. 先删**规范没要求、自己额外加的结构**(章节回顾表、内容小结、学习建议之类)
2. 再压缩案例叙述(保留案例,压到一两行)
3. 再压缩非考点的背景解释
4. **仍然超标 → 停下报告,不要自行舍弃考点。** 按「篇幅上限的调整判据」由使用者决定是否上调上限

⚠️ **只有上限,没有下限。** 不得为凑长度补充内容——输入短就输出短。任何"至少多少字"的要求都会直接诱发编造。

⚠️ 但**「没有下限」不等于越短越好**。压缩比**低于上限的 2/3** 时,必须在自检报告中
说明原因,并**逐节列出本专题的知识点清单与笔记的对应情况**。

> 实测案例:国际公法专题03 输入 39,344 字(比专题02 多 29%),上限 38%,
> 实际只产出 4,838 字 = **12.3%**,仅用掉上限的 32%。表现为:整份没有真题、
> 「公海六大自由」未列举、「三主动两被动」说了却只列三项、
> 老师明说是难点的海洋法只有一千五百字。
>
> **输入长而输出畸短,通常是漏抽考点,不是压缩得好。**
> 这个方向的失效比篇幅超标更危险——超标你读不完但内容在,漏抽你根本不知道丢了什么。

真题保留在原位,不做跨专题汇总(使用者另有真题练习册)。价值在于老师对**选项为何错**的解析,而非题目本身。

⚠️ **只收录字幕中实际出现的真题。字幕里没有例题的专题就没有例题**,不得自编模拟题、不得自造小案例。使用者尚未学过该科,一道答案微妙错误的自编题会被直接记成错的,危害大于空缺。

### 预习版 `<部门法>/_预习.md`

整个部门法一个文件,快速通读用。**篇幅 = 全部深入版之和的 15–20%**。

- 开头一句话点明本科考试定位(分值、命题特点)
- 每个专题一个 `##` 小节,标题下加一行指向深入版的双链
- 每节:一句话核心问题 → 骨架树(代码块)→ 只给**结论**,不给论证、不给案例
- 结论后带星级;骨架树中 ★★★ 节点加粗
- ⚠️ 结论必须是**能站住的判断句**,不是名词罗列
  - ✅ "不动产变动以登记生效,但继承和法院判决除外"
  - ❌ "讲了不动产物权变动的规则"
- 结尾附全科「预习完成标准」清单

### 冲刺版 `<部门法>/_冲刺.md`

整个部门法一个文件,考前速记。**篇幅上限 = 全部深入版之和的 8%**。

- 顶部单列「⚠️ 待核清单」,汇总各深入版中标 `【?】` 的条目
- 核心是**选项级速判表**:"这句话对不对" + 一句话理由。法考失分主要发生在选项辨析上。格式:

  | 表述 | 判 | 一句话理由 |
  |---|---|---|
  | 同意适用中国法律即视为放弃管辖豁免 | ❌ | 未涉诉,与"诉"行为无关 |
  | 商劳赔财知不享有管辖豁免,故可执行其任何财产 | ❌ | 管辖豁免 ≠ 执行豁免 |
  | 承认新政府同时撤销对该地旧政府的承认 | ✅ | 一领土不容两合法政权 |

  ⚠️ **「表述」列不得自行编造。** 来源只限这三处,每条都要能指回深入版:

  | 来源 | 说明 |
  |---|---|
  | 深入版中标 `#易错` 的辨析点 | 把辨析的两边各写成一条 |
  | 真题选项原文 | 直接取用,连同深入版里的选项解析 |
  | 老师明说"这样是错的""容易搞反"的地方 | 照其所指改写成陈述句 |

  自造的错误表述**若其实是对的,使用者会把正确结论记成错误**——而速判表本就是
  半对半错的设计,他没有任何办法凭直觉分辨。**造不出来就少列几条**,
  宁可表短,不可有一条是编的。

- 必背结论清单(表格,可遮答案自测)——★★★ 与 ★★ 全部收录,★ 可省略
- **必背金句**(仅主观题科目):5–8 句,**只收录老师原话或法条原文**并标明出处。⚠️ 不得改写、不得自造;老师没给就不设此节
- 默写填空(可选,仅主观题科目):15–20 空,挖空对象限于法条术语、要件名称、期限数字。与自测表功能重叠,**以自测表为主**,不得因此突破 8% 上限
- 口诀、易错点、对比表
- 该科专属速查表(见分科规范文件)
- 单列一节「尚未考过但重复可考性强」的考点
- 结尾「最后十分钟扫一眼」
- 不要出现完整句子的解释性段落

## Obsidian 约定

### frontmatter

```yaml
---
部门法: 民法
专题: "07"
阶段: 深入
老师: 张
来源: [021, 022]
书页: P88-P103
输入字数: 24000
输出字数: 5100
---
```

- `专题` 用字符串保留前导零;预习版和冲刺版省略 `专题`、`书页`、字数字段
- `阶段` 取值:深入 / 预习 / 冲刺
- `输入字数` / `输出字数` 用于事后一眼看出哪份膨胀了
- 分科规范中 `精讲书: 无` 时,**停用全部页码规则**(不提取页码、不写 `书页`)

### 双链

- 正文出现跨专题引用时写成 `[[专题02 国际法主体和国际法律责任]]`,链接文本必须和目标文件名完全一致
- **只在真正的知识关联处链接,不要为了链而链。** 一个专题笔记通常 0–3 个链接就够(分科文件可放宽)

### 标签

只用这四个,写在需要标注的行末:

- `#易错` — 老师明确点出的、或选项设计容易踩的
- `#高频` — 老师说近年反复考察的
- `#未考过/2026` — 老师说过"这几类还没考过"的,冲刺时一键筛出
- `#冲突` — 汇总阶段发现深入版之间结论不一致

⚠️ `#未考过` 必须带年份后缀。这是时效信息,不标年份明年会误导。

不要发明新标签,不要给每个知识点都打标签。

## 内容处理原则

### 删除

- 口头禅、语气词、寒暄、自我重复
- 课程推销、听课方法论的长篇展开(可压缩成背景区几行)
- 与考点无关的闲聊、时政感慨

### 必须保留

- 法条编号、条约名称、机构名称
- 一切数字:分值、年份、期限、比例、要件个数
- 例外规定、"除外"条款
- 老师明示的考点、易错点、口诀
- 真题原文与选项解析

### 禁止

- 不得补充字幕里没有的知识点,**即使你知道是对的**
- 不得改写法律实质内容,只做重组和提炼
- 不得把老师的假设性举例当作事实陈述(须标明是假设)
- 不得为满足篇幅而扩写

## ASR 错字处理

字幕来自语音识别,法律术语同音字错误较多。**改错字是整理笔记的一部分,不单独做清洗步骤**——因为对错取决于法律语境。

### 各科错字表

**可直接替换的错字表在各科规范文件中维护。** 处理时读取该表并应用;本次发现的新错字记入本专题末尾的「字幕校对说明」,**不要直接写进规范文件**(并行写入会互相覆盖,统一由回填步骤合并)。

不要跨科套用错字表——一科的表对另一科无效且会污染判断。

### 禁止全局替换(通用,八科都适用)

这几组两边都是真词,替换错了会改变法律含义,**必须靠语境逐处判断**:

| 词 | 说明 |
|---|---|
| **司法 / 私法** | 两者在同一讲里都可能出现 |
| **漠视 / 默示** | "漠视"是真词;但在意思表示、放弃、承认语境下几乎都指"默示" |
| **明示 / 民事** | ASR 常把"明示"识别为"民事",而"民事"本身是高频真词 |
| **法定 / 发的 / 法的** | —— |
| **实体 / 事体**、**要件 / 要见** | —— |

### 数字零容忍

凡涉及**期限、比例、年龄、金额、条文号、要件个数**:

- 表述含混、前后矛盾、或明显不合常理的,标 `【?】` 并附字幕原文片段
- **绝不猜,绝不用"我知道正确答案是什么"去覆盖字幕**

### 存疑标注

拿不准的一律用 `【?】` 就地标出。

⚠️ **存疑标注只写两样:字幕的原表述 + 建议核实的位置。不得写出你认为的正确答案。**

- ✅ `老师称"老公约了2002年"【?】,前后不合常理,建议对书 P46 核实`
- ❌ `老师称"2002年"【?】——巴塞尔公约实际通过于 1989 年、1992 年生效,建议核实`

后者把**你的记忆**当成"正确答案"写进了笔记正文。使用者会把它当作已核实的事实背下去,
而这条信息既不来自字幕、也不来自精讲书 —— 你记错了他无从判断。

**笔记正文只放字幕来源的内容。** 核实方向可以写进**自检报告**的存疑条目
(那是工作记录,不是学习材料),不要写进笔记。

### 字幕校对说明(每个深入版末尾)

1. 本专题实际改动的字词对照表
2. 存疑未改的条目,注明建议对书核实

预习版和冲刺版不附校对表(存疑条目汇总到冲刺版顶部待核清单)。

## 格式规范

- 标题层级:`#` 专题名 / `##` 章节 / `###` 知识点 / `####` 细节
- 重点加粗,不用斜体
- **一切对比、分类、要件枚举一律用表格**,不用嵌套列表
- 判断题式内容用 ✅ ❌ 标记
- 口诀单独成行加粗
- 需要提醒的坑用 `⚠️` 起头
- 背景性、非考点内容用引用块 `>` 包裹,与考点视觉区分
- 不要在正文里写"老师说",直接陈述结论;确需标明出处时用引用块

## 工具使用约定

统计字数、核对小节标题、检索内容这类事,**优先用内置的读取与检索工具**
(read / grep / glob),**不要写临时脚本**。

脚本要走 shell,使用者每次都得手动批准。一个专题跑七八次脚本,打断非常严重。

确实需要脚本时:

- **一次把所有统计做完**,不要为每个数字单独跑一次
- 临时文件命名为 `_tmp_*`(已被 `.gitignore` 排除),**用完立即删除**
- 不要用 shell 修改文件 —— 改文件用编辑工具,便于使用者审查改动

⚠️ 任何情况下不得用 shell 触碰 `00_素材/`。那是只读输入,且是不可再生的。

## 参考样本的使用

若随本文件提供了样本笔记(`00_样本/`),按以下规则使用:

- 样本用于**对齐格式**:表格用法、星级位置、frontmatter 字段、引用块、校对说明的写法、语言颗粒度
- ❌ **不得从样本中取用任何法律内容。** 样本中的知识点、法条、例题只属于它自己的专题
- ❌ **不得照搬样本的小节构成。** 样本里有 `## 主观题` 不意味着本专题也要有——小节的有无只取决于当前字幕讲了什么
- ❌ **样本篇幅不是目标篇幅。** 篇幅只由「本专题输入字数 × 分科上限」决定
- 若同时提供了 `反例/` 样本,那是**标注了错误的笔记**,用于识别典型幻觉形态,不得模仿其内容

## 处理完的自检(必须写成文件)

**自检报告写入独立文件,不是只输出在对话里:**

```
<部门法>/_自检/专题NN.md
三国法/<子学科>/_自检/专题NN.md
```

固定格式见 `00_流程/自检报告模板.md`。自检报告**不计入笔记篇幅上限**。

**"已自检"三个字不算自检,必须列出下面四张表的实际结果。**

⚠️ 溯源表会被 `./verify.sh` **逐字检索复核**(纯 grep,零成本)。填假数据必被查出,
比留空严重得多。

### 1. 触发词覆盖表(可机械核验)

在输入字幕中**实际计数**下列触发词,并说明笔记中的对应情况:

| 触发词 | 字幕出现次数 | 笔记已收录 | 未收录者及原因 |
|---|---|---|---|
| 这是考点 / 考试会考 / 勾一下 |  |  |  |
| 必考 / 年年考 |  |  |  |
| 口诀 |  |  |  |
| 易错 / 容易错 / 陷阱 |  |  |  |
| 还没考过 / 没考过 |  |  |  |

### 2. 高风险项溯源表

下列四类内容**每一条都要能指回字幕**,附字幕原文片段。

⚠️ 片段规则(`verify.sh` 靠这三条工作):

- **原样照抄字幕,包括 ASR 错字。** 字幕写"管辖惠民"就照抄"管辖惠民",
  **不要**抄成笔记里改正后的"管辖豁免"——否则逐字检索必然失败
- 长度 **8–20 字**,取一段连续、能唯一定位的文字,不省略、不缩写
- **用反引号包裹**,脚本靠反引号提取
- ⚠️ **片段必须包含被溯源的那个信息本身。** 要验证一个数字,片段里就得出现这个数字

  | | 要验证 | 片段 |
  |---|---|---|
  | ✅ | 2002 年 | `老公约了2002年有一个` |
  | ❌ | 2002 年 | `危危险废物跃境转移的巴塞尔公约` |
  | ✅ | 领土构成四部分 | `由领陆领水领空和底土四部分组成` |
  | ❌ | 领土构成四部分 | `最后一句话由领陆领水` |

  **片段命中 ≠ 内容有据。** 挑一句附近确实存在的话也能让脚本通过,但什么都没证明。
  `verify.sh` 检测不到这种情形——它只知道片段在字幕里,不知道片段该证明什么。

片段是"这句话在字幕何处"的坐标,不是"笔记写得对不对"的证明。

| 类型 | 笔记中的表述 | 字幕原文片段 |
|---|---|---|
| 法条编号 |  |  |
| 数字(期限/比例/金额/年龄/要件个数) |  |  |
| 真题与选项解析 |  |  |
| 口诀 / 必背金句 / 答题模板 |  |  |

覆盖要求**按类区分**:

| 类型 | 覆盖要求 |
|---|---|
| **数字**(期限/比例/金额/年龄/个数/海里/年份) | ⚠️ **必须全覆盖,不设上限。** 数字是法考核心命题点,错一个就选错一题,且最容易被 ASR 破坏——铁律二专门为它单列了一条 |
| 法条编号 | 超过 20 条时列前 20 条,注明该类总数 |
| 真题与选项解析 | 全覆盖(一个专题通常 0–3 道) |
| 口诀 / 必背金句 / 答题模板 | 全覆盖 |

⚠️ **溯源表前先报「各类总数 / 本表覆盖数」**,否则无法判断表填全了没有。

> **`verify.sh` 只能验「填进来的对不对」,验不了「该填的填没填」。少填不是通过,是绕过。**
>
> 实测:某专题笔记正文出现 **134 处数字**,溯源表只填 **16 条**。16 条全部命中,
> 脚本输出 `✓ 全部片段都能在字幕中定位` —— 而 88% 的数字从未被校验。
> 脚本现已同时报出「笔记中出现数字 N 处,溯源表 M 条」并在失衡时警告。

- ⚠️ **找不到出处的条目,回到笔记里删掉它**,不要留在表中做解释

### 3. 篇幅

输入字数 / 输出字数 / 压缩比 / 分科上限 / 是否超标。

### 4. 被舍弃的考点

因篇幅上限舍弃了哪些考点——逐条列出,没有则写"无"。

## 回填分科规范文件

由使用者显式发起,不在专题处理中自动进行。

回填内容:

1. **专属 ASR 错字表**——合并各深入版「字幕校对说明」中的实际改动,去重,按出现频次降序;出现 ≥3 次的标 `高频`
2. 属于"两边都是真词"性质的,**不要放进可直接替换表**,追加到该科"高危同音组"清单
3. **校准记录**——填入实测输入/输出字数与压缩比,以及触及上限的专题清单

⚠️ 建议在**首批 3–5 个专题之后**回填一次,而不是等全科结束。若只在结束时回填,该科已无后续专题可受益,错字表对本次运行毫无作用。

⚠️ 跑批期间不要改动本文件与分科规范文件——前缀变动会使 prefix cache 失效,成本显著上升。

## 篇幅上限的调整判据(机械规则,不依赖主观判断)

| 自检报告情况 | 处置 |
|---|---|
| 考点覆盖 100%,压缩比在上限内 | 上限合适,不动 |
| 为满足上限舍弃了考点 | 上限过紧,**上调 3 个百分点后重跑该专题** |
| **压缩比低于上限的 2/3** | ⚠️ **默认判定为漏抽考点**,不是压缩得好。要求逐节列出知识点清单与笔记的对应情况,确认无损后才保持 |
| 删完自创结构与冗余叙述后**仍超标,但未舍弃考点** | 先看是否有自创结构未删净;确认已删净则**上调 3 个百分点** |
| 首次遇到**跨多集的大专题**就明显超标 | 正常。分科上限的实测样本多为单集或半个专题,跨集专题考点密度更高 |

⚠️ 使用者不需要逐字比对字幕,判据来自自检报告。

## 模板验收顺序(批量前必须走完)

```
1. 三国法单集专题        → 验收格式
2. 三国法跨多集专题      → 验收合并逻辑
3. 民法或刑法一个专题    → 验收高密度学科是否适用
4. 才开始批量
```

⚠️ 第 3 步不可跳过。三国法"考得浅"是其自身特点,在三国法上验收通过的模板不能直接推给民法刑法。

## 附:上游 pipeline 已知问题(排查用,不需处理)

`modules/text_cleaner.py` 两个潜在坑,当前 72 集未触发,新增课程时需注意:

1. **单行输出**导致按行处理的三步(句首语气词、过短行、空行压缩)基本失效。建议按句末标点断行后再走后续步骤
2. **广告词整行删除 + 单行文件 = 命中即整集清空**。词表中「押题」「配套讲义」「客服」在法考正文里是正常词汇。建议改为更长的模式匹配,并加输出体量校验(输出/输入 < 0.8 时报警不写文件)
3. 因有断点续跑,被清空的集不会被自动重跑。批量前先核对 `.srt` 与 `_clean.txt` 数量一致、且无异常小文件
