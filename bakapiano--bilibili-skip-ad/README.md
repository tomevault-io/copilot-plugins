 BiliSkip 用于识别并跳过 B站视频中的植入广告。扩展通过字幕分析广告区间，在原生播放器进度条上标记，并按用户设置提供自动跳过、边界试听和撤销功能。本地及共享缓存用于复用广告识别结果。
