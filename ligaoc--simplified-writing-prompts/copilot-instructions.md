# CLAUDE.md

这是一个小说创作辅助工具项目，包含结构化的创作提示词系统和规范工作流程。

## 项目结构

```
写作项目/
├── .spec-workflow/          # 规范工作流系统
│   ├── templates/           # 默认文档模板
│   ├── user-templates/      # 用户自定义模板
│   ├── specs/              # 功能规格文档
│   ├── steering/           # 项目指导文档
│   ├── approvals/          # 审批记录
│   └── archive/            # 归档文档
├── 提示词/                  # AI提示词模板库
│   ├── 创意策划师.md        # 创意构思专用提示词
│   ├── 故事架构师.md        # 故事结构设计
│   ├── 角色设计师.md        # 人物设定创建
│   ├── 世界观构建师.md      # 世界背景设定
│   ├── 细纲创作.md          # 详细章节大纲
│   ├── 正文创作.md          # 正文内容生成
│   ├── 质量审查.md          # 内容质量审核
│   └── 上下文加载器.md      # 上下文管理
├── 设定/                    # 小说设定资料存储
├── 细纲/                    # 章节细纲存储
├── 正文/                    # 正文内容存储
└── 小说创作助手.md          # 项目说明文档
```

## 核心工作流程

### 1. 创作流程标准化
使用 `提示词/` 目录中的专业提示词模板，确保创作过程的系统性和一致性：

- **创意策划阶段** → `创意策划师.md`
- **架构设计阶段** → `故事架构师.md` + `世界观构建师.md` + `角色设计师.md`
- **细纲创作阶段** → `细纲创作.md`
- **正文写作阶段** → `正文创作.md`
- **质量审核阶段** → `质量审查.md`

### 2. 规格化工作流 (Spec Workflow)
使用 `.spec-workflow/` 系统管理功能开发和文档化：

```bash
# 创建新的功能规格
/spec-workflow requirements "功能名称"

# 创建设计文档
/spec-workflow design "功能名称"

# 创建任务清单
/spec-workflow tasks "功能名称"

# 查看状态
/spec-workflow status
```

## 提示词系统架构

### 提示词设计原则
- **模块化**: 每个提示词专注特定创作环节
- **标准化**: 统一的格式和变量系统
- **可扩展**: 支持自定义和个性化调整
- **上下文感知**: 通过 `上下文加载器.md` 管理创作连贯性

### 核心组件
1. **创意策划师**: 核心创意构思，包含市场分析、受众定位、创意评估等完整流程
2. **故事架构师**: 负责整体故事结构和情节设计
3. **角色设计师**: 专业的人物设定和角色弧光设计
4. **世界观构建师**: 完整的世界背景和规则体系构建
5. **细纲创作**: 章节级别的详细规划
6. **正文创作**: 基于细纲的高质量内容生成
7. **质量审查**: 多维度内容质量评估和改进建议

### 数据流向
```
创意输入 → 创意策划师 → 故事架构师 → 角色设计师 + 世界观构建师 → 细纲创作 → 正文创作 → 质量审查
```

## 文档管理系统

### 目录用途说明
- **设定/**: 存储世界观、人物设定等基础设定资料
- **细纲/**: 按章节或部分存储详细大纲
- **正文/**: 最终完成的小说正文内容
- **.spec-workflow/**: 管理项目相关的功能规格和开发文档

### 模板系统
- 默认模板位于 `.spec-workflow/templates/`
- 用户自定义模板可放在 `.spec-workflow/user-templates/`
- 支持需求文档、设计文档、任务文档等多种模板类型

## 开发和维护

### 添加新提示词
1. 在 `提示词/` 目录创建新的markdown文件
2. 遵循现有的命名规范和结构
3. 包含完整的角色定义、工作流程、输出格式等
4. 更新此文档的提示词系统架构部分

### 修改工作流程
1. 使用spec-workflow系统创建变更规格
2. 更新相关模板和提示词
3. 测试新流程的有效性
4. 更新文档说明

### 质量保证
- 所有提示词都应包含明确的角色定位和职责
- 每个模块都应有清晰的输入输出定义
- 定期审核和优化提示词效果
- 保持向后兼容性

## 使用注意事项

### 提示词使用
- 严格按照提示词中的角色定义执行
- 保持创作过程的连贯性和一致性
- 定期使用 `上下文加载器.md` 同步创作状态
- 根据实际效果调整和优化提示词

### 数据管理
- 定期备份创作内容
- 保持良好的文件命名规范
- 及时归档完成的创作资料
- 注意版本控制和变更追踪
