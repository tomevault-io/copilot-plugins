# CLAUDE.md

Contributor and AI-agent guidance for this repository lives in **[AGENTS.md](AGENTS.md)** — read it before proposing changes or opening a pull request.

The canonical submission rules are in **[CONTRIBUTING.md](CONTRIBUTING.md)**.

In short: awesome-swarm is a curated list of free, open-source, Swarm-related projects. Add one project per pull request, in the correct section, using the entry format `[Name](url) - description under 160 characters, sentence case`. Before opening a PR, verify the project is public, openly licensed, actively maintained, not a duplicate, and that its link resolves. See [AGENTS.md](AGENTS.md) for the full checklist and the audit method the list is maintained against.
