# swift-sheet-music

> Source: [jiyimeta/swift-sheet-music](https://github.com/jiyimeta/swift-sheet-music). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Swift package for engraved music notation: MuseScore (.mscx/.mscz) & MusicXML import/export, a typed score model, MIDI rendering, SwiftUI/PDF rendering, AVFoundation playback, and an Android-compatible core.
