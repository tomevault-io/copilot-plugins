# AGENTS

## Web

- Do not use Tailwind `leading-*` utilities directly. Line-height lives in the type tokens.
- Do not use ad-hoc Tailwind tracking values. If tracking must be set directly, use only `tracking-normal`, `tracking-tight`, or `tracking-tighter`.
