# dmm-tools

> Source: [antoinecellerier/dmm-tools](https://github.com/antoinecellerier/dmm-tools). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Multimeter logging and graphing app for Linux, Windows, macOS and Raspberry Pi. Works with UNI-T, ZOYI/ZOTEK, ANENG, Brymen, EEVblog, OWON and Voltcraft meters over USB and Bluetooth. Open-source GUI and CLI. UT61E+, UT181A, UT161, UT71, UT60BT, UT804, AN9002, ZT-300AB, BM869s, 121GW, VC890 and more.
