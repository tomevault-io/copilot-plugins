## Commit Message Convention

Commit messages must use a `[Type]` prefix, e.g.:

- `[Feat]` — new features (project page, new sections, assets)
- `[Fix]` — bug fixes
- `[Chore]` — maintenance, tooling, non-code housekeeping
- `[Docs]` — documentation-only changes
- `[Refactor]` — restructuring without behavior change
- `[Test]` — test changes

Format: `[Type] short imperative summary`, followed by a blank line and a body with bullet points describing what and why.
