# Agent Instructions

When working in this module, use the `ai-carbon-sync` skill for tasks that create or modify deliverable files.

At the beginning of a session, activate it with `$ai-carbon-sync` and choose an `.AI_carbon` archive. After each generated or modified file, synchronize the file, its context, and the relevant Agent conversation into that archive. Before optimizing an existing artifact, read its historical context and revisions first.
