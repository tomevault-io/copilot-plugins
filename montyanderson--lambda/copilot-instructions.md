# lambda

lambda is a minimal, portable, agent harness written in c.

it must be:
* portable across posix compliant linux & mac os
* statically compiled with dependencies chosen for minimalism and checked in-repo
* extremely fast startup time, minimising time from user entering lambda in shell and being able to start typing
* have a pretty claude code style tui
