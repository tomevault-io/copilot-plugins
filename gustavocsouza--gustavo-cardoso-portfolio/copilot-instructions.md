## 📋 Descrição do Projeto

Portfólio profissional moderno e responsivo de **Gustavo Cardoso de Souza**, um desenvolvedor Full-stack com experiência em PHP/Laravel, Vue.js e React.js. O projeto visa apresentar suas habilidades, experiências profissionais, projetos em destaque e informações de contato de forma elegante e profissional.

## 🚀 Como Usar

1. **Instalar dependências:**
```bash
npm install
```

2. **Iniciar servidor de desenvolvimento:**
```bash
npm run dev
```

3. **Build para produção:**
```bash
npm run build
```

4. **Preview da build:**
```bash
npm run preview
```
