# Default browser: ego lite + jev-ego

Do not add Playwright, Puppeteer, Chrome, or a second browser. Agents drive pages with `jev-ego` (`serve` / `observe` / `act` / `suggest` / `step`). Raw `ego-browser` is only for uploads, tabs, dialogs, canvas, shadow DOM, and iframes.
