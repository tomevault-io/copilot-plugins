# KitePlayer

> Source: [yuroyami/KitePlayer](https://github.com/yuroyami/KitePlayer). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

A native media playback library for Kotlin Multiplatform, Android, iOS, desktop (JVM) and web. As powerful as VLC and fine-tuned to perfection with Kotlin coroutine-first syntax. No expect/actual, no build scripts/NDK. It is 100% Kotlin core (no third-party players underneath). Can render directly into Compose multiplatform using Skiko API
