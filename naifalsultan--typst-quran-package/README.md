# typst-quran-package

> Source: [NaifAlsultan/typst-quran-package](https://github.com/NaifAlsultan/typst-quran-package). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

A Typst package for Quranic text rendering using authentic King Fahd Complex fonts. Supports Hafs and Warsh Qira'at with a bilingual API (English/Arabic). Offers granular control to render specific suras, verses, or words according to the Madinah Mushaf.
