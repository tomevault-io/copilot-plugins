# Alt

> Tome by [Kaikei-e](https://github.com/Kaikei-e/Alt), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Alt is a Compose-first knowledge platform built for turning information into reusable knowledge. Starting from RSS ingestion, Alt runs a local-first AI pipeline for summarization, tag extraction, search, recap, and RAG-powered Q&A, then brings the results together in Knowledge Home.
