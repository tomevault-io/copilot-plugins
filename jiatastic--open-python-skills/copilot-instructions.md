```
open_python_skills/

├── excalidraw-ai/       # Diagram generation
├── ty-skills/           # Python type checking with ty
├── unit-testing/        # pytest patterns
├── docker-builder/      # Dockerfile generation
├── web-scraping/        # Scraping patterns
├── api-testing/         # API testing with schemathesis

├── formatting/          # Code formatting

├── error-handling/      # Error handling patterns
```

## WHERE TO LOOK

| Task | Location |
|------|----------|
| Skill catalog | `open_python_skills/*/SKILL.md` |
| Reference docs | `open_python_skills/*/references/*.md` |
| Data files | `open_python_skills/*/data/*.json` |
| Scripts | `open_python_skills/*/scripts/*.py` |

## CONVENTIONS

- Each skill has a `SKILL.md` with front-matter metadata
- Reference docs live in `references/` subdirectory
- JSON data lives in `data/` subdirectory
- Excalidraw libraries live in `assets/` subdirectory
