# AGENTS.md

These instructions apply to this public Second Brain starter.

## Purpose

Keep this repository a small, local-first Markdown starter. It demonstrates
structure and process; it is not the owner's private Second Brain.

## Source and privacy boundary

- Treat `library/` as canonical only for the records a user deliberately adds.
- Treat `input/` as ignored local staging. Do not inspect or publish it without
  explicit scope and permission.
- Treat `private/` as ignored restricted material. Never add private values to
  tracked files, examples, commits or chat summaries.
- Keep examples fictional, non-identifying and clearly labelled.
- Do not claim a local model, automation, schedule, publication or retrieval
  result occurred without evidence.

## Working method

1. Read `START-HERE.md`, then the relevant process or template.
2. Preserve source, status, uncertainty and human approval boundaries.
3. Prefer the smallest usable folder and record structure.
4. Before public release, use `system/checklists/public-safety.md` and review
   the staged tree as well as unpublished commits.

## Folder roles

Use `docs/` for reader-facing explanation, `system/` for operating aids,
`skills/` for portable tool instructions, `templates/` for copyable record
shapes and `examples/` for tracked fictional demonstrations. See
`docs/folder-roles.md` for the full rationale.

## Personal instructions

An owner may keep personal working preferences and privacy boundaries in an
ignored custom-instructions record. Follow it when it is explicitly provided,
but do not treat it as proof of project status, source authority or permission
to publish. See `docs/custom-instructions.md`.
