# motrix-fnos

> Source: [RockerHX/motrix-fnos](https://github.com/RockerHX/motrix-fnos). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Motrix FNOS 是面向飞牛 fnOS 的下载管理应用，内置 Aria2 Next 下载引擎，以 FPK 形式安装和运行。用户通过同一套 Web UI 在桌面浏览器、手机浏览器或飞牛 App 中管理下载任务。提供RPC远程推送能力。
