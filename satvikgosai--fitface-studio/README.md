# fitface-studio

> Tome by [satvikgosai](https://github.com/satvikgosai/fitface-studio), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Android app for browsing, editing and installing Galaxy Fit3 (SM-R390) watch faces — edit the face's own binary on a canvas, validate it, then send it to the watch over Bluetooth.
