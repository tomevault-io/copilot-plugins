# Repuso Monitoring API

Tools for the Repuso reviews API: list/discover/add review profiles (50+
platforms), fetch normalized plain-text reviews, tag them, pull rating history
and reports, and manage signed webhooks. Every call runs on the user's own
Repuso account via their API key.

If a tool returns an auth error, ask the user to set REPUSO_API_KEY_B64
(base64 of ":THEIR_API_KEY" - key available at
https://repuso.com/developers/console/).
