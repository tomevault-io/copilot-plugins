# Rumpus-Engine

> Tome by [jarredksmith](https://github.com/jarredksmith/Rumpus-Engine), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

A single-file browser game studio — build worlds, play them (FPS, driving & racing, top-down, side-scroll), and share them with peer-to-peer multiplayer and a community level library. Everything — engine glue, editor, netcode, assets pipeline — ships in one html file. No build step, no server.
