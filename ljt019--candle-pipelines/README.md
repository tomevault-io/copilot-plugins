# candle-pipelines

> Source: [ljt019/candle-pipelines](https://github.com/ljt019/candle-pipelines) — distributed by [TomeVault](https://tomevault.io)

Candle Pipelines provides a simple, intuitive interface for Rust developers who want to work with Large Language Models locally, powered by the Candle crate. It offers an API inspired by Python's Transformers.
