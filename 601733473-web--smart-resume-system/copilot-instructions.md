# 简历助手 V2 项目规则

## 简历任务开始前

在执行简历分析、清洗、改写、岗位匹配、评分或素材提炼前，先阅读：

- `简历知识库/00_使用与更新说明.md`
- `简历知识库/01_语言风格规范.md`
- `简历知识库/02_岗位能力词典.md`
- `简历知识库/05_量化指标词典.md`
- `简历知识库/06_风险写法与真实性检查.md`

需要调用案例或项目素材时，再检索：

- `简历知识库/03_经历素材卡片库.xlsx`
- `简历知识库/04_同人多岗位改写对照.md`

## 事实与风险

- 原始简历是事实来源，知识库是派生资料。
- “待人工抽检”“待核验”的素材不能直接作为已确认事实使用。
- 不得把其他候选人的公司、项目、职责或结果移植给当前候选人。
- 不得为了匹配岗位修改正式岗位名称、任职时间或业绩数字。
- 涉及数据冲突、占位符、强所有权动词或不明口径时，先向用户核实。
- 未经用户要求，不修改 `优秀简历案例` 中的原始文件。

## 知识库更新

用户要求更新知识库时：

1. 扫描 `优秀简历案例`。
2. 通过文件名和 SHA-256 指纹识别新增、修改与重复文件。
3. 只增量处理新增或被修改的来源。
4. 更新来源索引、经历素材卡、同人多岗位对照、待核验问题和更新记录。
5. 重建 `简历知识库/07_RAG索引.json`，确保来源指纹与最新 Excel 一致。
6. 保留历史变更，不静默覆盖已确认事实。
