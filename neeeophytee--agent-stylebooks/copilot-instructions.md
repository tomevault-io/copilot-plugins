# Repository instructions

- Preserve the set of 11 skills unless the task explicitly changes the catalog.
- Run `python3 scripts/validate_repo.py` after modifying skills, manifests, catalog
  docs, provenance, or validation code.
- Do not copy source-guide passages or examples into this repository.
- Do not upgrade a reference-only source to open-license status without an
  authoritative license URL.
- Keep facts, legal meaning, commands, and code unchanged when testing a style.
- Do not push, publish, create a release, or create a remote unless the user asks.
- Keep model eval infrastructure out of v0.1.
