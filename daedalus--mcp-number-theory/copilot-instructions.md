# MCP Number Theory

MCP server exposing number theory functions and factorization algorithms.

## When to use this skill

Use this skill when you need to:
- Compute GCD and related functions
- Factorize integers
- Perform number theory computations
- Use factorization algorithms (Fermat, etc.)

## Tools

- `gcd` - Greatest common divisor
- Various number theory functions from `mcp_number_theory.algos`

## Install

```bash
pip install mcp-number-theory
```
