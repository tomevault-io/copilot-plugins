# AI-Interview

> Tome by [nzy0510](https://github.com/nzy0510/AI-Interview) — distributed by [TomeVault](https://tomevault.io)

InterWise 是一个可自部署的、面向技术面试训练的 AI 模拟面试平台，支持文字/视频面试、简历画像、动态 RAG 追问、岗位/题库管理、面试复盘与 AI Mentor。项目将模拟面试与数据库题库打通，通过 MySQL 管理知识原子、Qdrant 构建语义索引，并使用 multilingual-e5-base 为不同岗位生成更贴近真实面试的追问链路。
