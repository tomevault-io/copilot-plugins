# docs 配下のドキュメント作成ルール

`docs/` ディレクトリに**新規ドキュメント**を追加するときは、必ず次のルールに従うこと。

## ファイル名

- **先頭に日付の接頭辞を付ける**: `YYYYMMDD-名前.md`
- **例**: `20260201-SOURCE_CODE_REVIEW.md`、`20260215-API.md`

日付はドキュメントを作成する日（YYYYMMDD）を用いる。既存の `docs/README.md` はルール説明用のため対象外。

このルールは、今後のドキュメント作成時に必ず適用すること。
