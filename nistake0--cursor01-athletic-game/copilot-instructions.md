# TODO 更新時のルール（日報追記・完了タスク削除）

このプロジェクトでは、**ユーザーが「TODO を更新する」「TODO を整理する」などと依頼したとき**は、次の手順に従う。

## 適用する依頼の例

- 「TODO を更新して」「TODO を更新する」
- 「TODO の整理」「TODO を整理する」
- 「完了した TODO を片付ける」「TODO から完了を削除」
- 「TODO の状況を反映して整理する」

上記に限らず、**TODO の内容を整理・更新する**意図の依頼であればこのルールを適用する。

## 手順

### 1. 作業日報に完了作業を追記する

1. **当日の日付を確認する**  
   `date +%Y%m%d` などで当日の YYYYMMDD を取得する。
2. **当日の日報ファイル**  
   `diary/YYYYMMDD.md` を開く（存在しなければ新規作成する）。
3. **完了した TODO の内容を「作業内容」として追記する**  
   - どの項目を完了したか（優先度・高／中／低のどれか）
   - 実施した内容の要約（何を変更・追加したか）
   - 関連する不具合修正があればそれも記載する。
4. 必要に応じて「所感・メモ」を 1〜2 行追記してよい。

### 2. TODO から完了タスクを削除して整理する

1. **`docs/TODO.md`** を開く。
2. **完了している項目（チェックが `[x]` の項目）を削除する。**
3. その優先度セクションに項目が残っていなければ、**「（現在なし）」** のように明記する。
4. 未完了の項目（`[ ]` のままのもの）は残し、優先度ごとの見出しと運用ルール（ファイル末尾の「運用」）は維持する。

## 注意

- 日報のファイル名は必ず **当日の YYYYMMDD** とする（日報ルール `diary-daily-report.mdc` に従う）。
- TODO の「運用」セクション（確認のタイミング、チェックの更新、新規追記の仕方）は削除しない。

このルールは、TODO の更新・整理を依頼されたときに必ず適用する。
