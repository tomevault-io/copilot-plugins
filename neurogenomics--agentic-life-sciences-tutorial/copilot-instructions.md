# Agentic Life Science Tutorial

## What This Package Does

Provides agent context for life-science and genomics projects:
- Coding conventions for R and Python bioinformatics workflows
- Data validation rules for genomics datasets
- Pre-built agent configs (e.g., prototyping agent for large MAGMA celltyping data)
- Skill templates for code review, reproducibility, and analysis workflows

## Getting Started

```bash
apm install neurogenomics/agentic-life-science-tutorial-private
apm compile
```

## Available Primitives

- **Agents**: `agents/prototyping-agent.yaml` — rapid data prototyping with sampled datasets
- **Skills**: `personal-level/` and `project-level/` — coding standards, testing, security, genomics best practices
- **Instructions**: Data standards, analysis workflow conventions, scientific reproducibility rules
