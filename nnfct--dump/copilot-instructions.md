## 처리 방식
- 이 공간에 들어온 메모는 별도 저장 요청 없이 해당 턴에 Markdown으로 저장한다. 단순 질문·잡담·일회성 작업 지시는 무조건 메모로 만들지 않는다.
- 원문은 `inbox/YYYY-MM-DD.md`에 입력 순서대로 추가한다. 기존 원문을 덮어쓰거나 요약으로 대체하지 않는다. 날짜는 Asia/Seoul 기준이다.
- 정리본은 `notes/주제.md`에 저장한다. 관련 문서가 있으면 먼저 읽고 갱신하며, 원문 파일과 항목을 링크한다. 폴더는 첫 기록 때 만든다.
- 내용에 맞는 항목만 사용한다: 핵심 요지, 배경, 아이디어, 결정 사항, 할 일, 미확인 사항. 빈 항목을 채우려고 내용을 만들지 않는다.
- 사용자 발언과 에이전트 해석·제안을 구분한다. 아이디어를 확정된 결정으로 바꾸거나 담당자·기한·우선순위를 임의로 정하지 않는다.
- 후속 발언이 기존 내용과 충돌하면 원문과 변경 이력을 보존하고, 명시적인 정정만 최신 상태에 반영한다. 불명확하면 미확인으로 남긴다.
- 정리를 진행할 수 있으면 먼저 저장한다. 의미나 결정 여부에 영향을 주는 모호함만 짧게 질문한다.
- 기록한 할 일은 실행 지시와 구분한다. 사용자가 실행까지 요청한 경우 해당 작업 규칙에 따라 수행한다.
- 민감정보는 자동으로 파일에 복제하지 않는다. 필요한 경우 민감한 값을 제외한 요지만 남긴다.
