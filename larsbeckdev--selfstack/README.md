# selfstack

> Source: [larsbeckdev/selfstack](https://github.com/larsbeckdev/selfstack). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Selfstack is a free and open-source, self-hosted dashboard builder for organizing your bookmarks, services, and homelab tools into customizable boards with categories, groups, and tiles — a lightweight alternative to heavier homelab dashboards, designed to be deployed in a single container.
