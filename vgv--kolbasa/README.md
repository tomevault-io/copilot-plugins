# kolbasa

> Source: [vgv/kolbasa](https://github.com/vgv/kolbasa). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

A reliable message & job queue for Java & Kotlin, built on PostgreSQL — use the database you already have, no Kafka or RabbitMQ. Transactional sends, deduplication, delays, retries, dead-letter & archive queues, and batching.
