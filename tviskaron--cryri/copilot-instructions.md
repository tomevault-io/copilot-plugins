## linting

> - Add 2 new lines before function or class defenition. Example:

# Following Pylint and Flake8 Config

- Add 2 new lines before function or class defenition. Example:
```python
import os


class Class1:
    pass


class Class2:
    pass


def func1():
    pass


def func2():
    pass
```
- NEVER leave trailing whitespaces at the end of line
- Always leave a new line at the end of file
