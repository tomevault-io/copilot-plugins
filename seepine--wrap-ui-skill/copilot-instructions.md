# Wrap UI Skill

wrap-ui 是一套面向 uni-app 场景的组件库，强调开箱即用、风格统一和移动端交互体验。

## 特点

- 适配 uni-app 常见业务场景，覆盖基础展示、表单输入、反馈与布局能力。
- 组件命名统一，示例直观，适合快速查找用法和组合页面。
- 支持通过示例代码快速理解 Props、Slots 与 Events 的实际配合方式。
- 文档结构按组件分类拆分，便于持续补充和单独维护。
