# xops-cli

> Source: [wentf9/xops-cli](https://github.com/wentf9/xops-cli). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

基于 Go 的高性能、跨平台运维 CLI 工具。集成了多后端防火墙管理 (firewalld/ufw/iptables/nftables)、SSH 批量执行、MCP 服务以及远程文件管理 (SCP/SFTP)。旨在通过一个二进制文件，提供轻量、安全且自动化的服务器管理方案。
