# agent-vision-mcp

> Source: [kitlau86/agent-vision-mcp](https://github.com/kitlau86/agent-vision-mcp). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

An MCP server that gives non-vision LLMs the ability to "see" images. Plug in any OpenAI-compatible vision API (Gemini, Qwen-VL, OpenAI, or self-hosted) and your text-only model — like DeepSeek in Claude Code — can analyze screenshots, OCR text, read charts, and more.
