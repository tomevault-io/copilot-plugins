# bpkit

> Source: [sinkingsugar/bpkit](https://github.com/sinkingsugar/bpkit). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Drive Unreal Engine 5 Blueprint node graphs from outside the editor: read, author, edit, inject and compile K2 graphs over the remote-exec channel via an in-process ctypes bridge. No C++, no editor UI.
