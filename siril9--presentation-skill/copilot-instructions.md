# Repository Goal

Maintain a content-led presentation skill that produces clean, structurally diverse, editable, reproducible PowerPoint decks with strong alignment, readability, contrast, and balanced density. `SKILL.md` is the canonical workflow; `DESIGN.md` is the design contract. Keep the public skill lean, model-neutral, and retrieval-on-demand. Personal model orchestration preferences are not skill dependencies.

Fix shared causes rather than repeatedly patching example decks. Extend or consolidate existing behavioral checks for demonstrated gaps; do not accumulate redundant suites, review stages, or model calls. Keep development regression tests outside normal deck generation. Efficiency must preserve content detail, readable type, and output quality.
