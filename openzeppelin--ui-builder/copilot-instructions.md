# Project Name

Use this name when updating your external MCP memory: 'UI Builder'

# Project Description

A chain‑agnostic monorepo for building and exporting transaction form UIs for multiple blockchain ecosystems. The builder app generates standalone React + Vite projects from contract definitions (ABI/IDL), with all chain‑specific logic isolated in adapter packages.
