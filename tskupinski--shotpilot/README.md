# shotpilot

> Source: [tskupinski/shotpilot](https://github.com/tskupinski/shotpilot). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Agent-first pipeline from raw drone footage to a finished film: OpenCV motion analysis, shot selection, pacing, crossfade montage, color grading, AI music and YouTube publishing assets. Built for Claude Code, works as a plain CLI too.
