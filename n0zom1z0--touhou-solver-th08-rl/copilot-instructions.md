# TH08-RL Working Rules

Read `START_HERE.md` before changing code. The shipped TH08 executable,
connected IDA database, and bounded physical probes are primary evidence.
There is no authoritative source tree. Do not use REA or LeanToken.

The old `../th08` and `../th06-rl` repositories are read-only donors. Do not
copy their games, traces, corpora, build products, or generated artifacts.

## Runtime boundary

1. capture one stable physical snapshot;
2. project only already-observed bullets and lasers for a fixed horizon;
3. construct a safety-owned legal action set;
4. let the stage-isolated learner rank only that set;
5. repeat the selected Hard certificate and require the same native frame
   immediately before publication;
6. publish a complete movement mask through the reversible exact-PID bridge.

Bomb bit `0x02` is forbidden at every layer. Unknown, incoherent, stale, or
empty safety authority fails closed by releasing movement. Menu control and
battle control are separate. No stage, boss, spell, frame, or RNG keyed
movement scripts are permitted; such labels may only partition observations.

## Physical safety

- TH08 may run beside TH06: each bridge owns a distinct exact-PID cave. Never
  patch, send input to, or stop a TH06 PID from this repository.
- Never launch the Windows game through a PTY.
- Restore hooks, release the complete input mask, and stop only the exact
  trial PID on every exit.
- A target identity or hook-byte mismatch is a hard stop.
