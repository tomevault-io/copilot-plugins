# SKILL编写指南

## 分析易语言代码

在编写时，通常需要查看某些.e或者.ec中的源代码，请使用e-packager直接拆包后进行分析，使用方法详见[e-packager.md](references/e-packager.md)

优先使用命令来判断当前系统环境中是否存在e-packager，如果存在则直接使用即可：

```cmd
e-packager version
```
