# Copilot instructions

This repository keeps all agent instructions in `AGENTS.md` files, so that no rule is visible to one
coding agent and invisible to another. Start with [`AGENTS.md`](../AGENTS.md) at the root, which
covers the engine and the repository as a whole.

Subdirectories with their own conventions carry a nested `AGENTS.md`:

- [`validator/AGENTS.md`](../validator/AGENTS.md) — scores the engine against other execution stacks
- [`visualizer-web/AGENTS.md`](../visualizer-web/AGENTS.md) — generated by `next dev`, not ours to edit

Read the one nearest the code you are editing, in addition to the root file.

Do not add project rules to this file; add them to the nearest `AGENTS.md` instead.
