Assignment 2 (Interactive Data Visualisation in R) - High Distinction Rules
rules:
  - id: data-correspondence
    description: >
      Interface must have a strong, coherent theme/message that reveals insightful
      patterns in the data. The design must be neat, consistent, and crystal-clear,
      highly tailored to the audience. Innovative approaches should be applied.

  - id: data-integrity
    description: >
      No data integrity issues allowed. Visualisation types must always be appropriate,
      accurate, and implemented with care. Units, labels, and missing values must be
      clearly handled.

  - id: data-density-aesthetics
    description: >
      Dashboard must be fresh, creative, innovative, and striking, yet highly effective
      and not overly complex. Layout must be well-balanced, with data density neither
      too high nor too low. Attention to detail must be flawless, near-professional
      quality.

  - id: technical-challenge
    description: >
      Advanced Shiny features must be used masterfully, with intuitive and professional
      interaction design. Dashboard should clearly demonstrate independent research and
      be an outstanding example of what is possible with Shiny.

  - id: design-summary
    description: >
      Design summary must be well-structured and crystal-clear, strongly justifying all
      design choices. Layout should be creative and demonstrate deep understanding of
      lecture concepts with practical application. Must fit on one A4 page.
