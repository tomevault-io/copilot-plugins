The Pulse CLI lives in this extension: `bin/pulse`. Gemini extensions
are installed under `~/.gemini/extensions/<name>/`, so run it as
`~/.gemini/extensions/<name>/bin/pulse` wherever the rules or a Pulse
skill say `pulse`.
