# SNS永久機関 — 運用ルール（CLAUDE.md テンプレ）

このファイルは AI（Claude Code）が常に守る「憲法」。
毎回のプロンプトに書かなくても、ここに書いたルールは全タスクに適用される。
`<<...>>` の箇所を自分用に書き換えてから使うこと。

## このワークスペースの目的

<<あなたのチャンネル名>> の YouTube 動画を素材に、
X / note / Tips / Threads / Instagram / TikTok 向けのコンテンツを自動生成する。

## ルール（トリガー → アクション）

### 生成

- コンテンツを生成するとき → 対応するスキル（/x-post /note-post /tips-post）を必ず使う
- 文体に迷ったとき → `memory/` の該当ファイルを正典とする
- 成果物を保存するとき → `output/YYYY-MM-DD/` 配下に媒体名付きで保存する

### 検証（必須・省略禁止）

- 文章を完成させたとき → 文字数・構成・フォーマットをセルフチェックする
- 固有名詞・数字・日付を書いたとき → 確証がなければ「未確認」と明示する。それっぽい穴埋めをしない
- URLを記載したとき → 実際に開けるか確認する

### 公開の境界（最重要）

- YouTube への投稿 → **絶対に自動でしない**。生成＋保存までで止める（BAN対策）
- X の公開 → 下書き・テキスト保存まで。公開ボタンは人間が押す
- note → 下書き保存まで自動でよい。公開は人間が判断する
- 取り消せない操作（削除・上書き・外部送信・公開・課金） → 必ず確認を取る

### 記憶

- 同じ修正指示を2回受けたとき → `memory/feedback_*.md` に追記して、二度と繰り返さない
- 新しい失敗パターンが発生したとき → 該当する memory ファイルに追記する

### ループ運用

- ループの上限 → 1回の /loop につき最大 <<例: 10>> 周・<<例: 3>> 時間まで
- 進捗報告 → 各周回の終わりに「生成物・検証結果・次にやること」を1行ずつ残す
- 全タスク完了時 → `output/` に成果物一覧レポートを書いて終了する

## 禁止事項

- APIキー・トークンをファイルにコミットしない
- 既存ファイルがあるのに新規ファイルを作らない（原本を更新する）
- 検証ステップを飛ばして「完成しました」と報告しない
