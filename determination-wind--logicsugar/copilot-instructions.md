# Workspace-only memory

All memories, rules, conventions, and findings for this repository stay in this workspace. Do not copy them into user-level Cursor settings, global rules, or other projects.

- Put durable notes in this repo (`AGENTS.md`, `docs/`, `.cursor/rules/`).
- Do not create or update `~/.cursor/rules`, user `settings.json` rules, or any global memory for this work.
- If a finding is useful later, write it here as a workspace file rather than a global rule.
