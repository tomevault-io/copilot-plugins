# 本项目 Agent 规则

先阅读 README.md、PUBLICATION_STATUS.md、SOURCE_REVIEW.md 和 DIRECTORY_LAYOUT.md。

- 本项目是独立的非官方公开源码项目；当前没有可安装发行包。
- 只在当前用户选择的工作区内施工。外部源码只作明确授权的只读参考，不修改来源项目。
- 不整库复制历史材料。待审候选必须标记来源和未确认事项；只有来源与适用许可核清的文件才能进入最终公开清单，并保持必要的第三方声明。
- 不自动提交、推送、创建远端或更改仓库可见性；准备本地候选不等于发布授权。
- 不连接相机、改变设置、升级、刷写或执行其他真实设备动作，除非获得对应的明确授权。
- 明确区分原厂输入、自写代码、模拟数据、设备证据和用户观察，不把缺依赖、跳过验证或来源未明的文件标为通过。
- 文档用中文，协议名、标识符及文件名保留原文；确需多语言时维护同一验证边界。
- 任何构建和测试都应有明确的本地输出位置；不把生成物、厂商资源、未知许可素材或个人信息带入公开清单。
