# The map

Before you touch anything, open Context.md and read it.

Context.md says 4 things: what we are working on, what is already decided,
which folder holds the material, and what happens next.

Work only inside the folder Context.md points to. Do not go hunting.

When the work moves, update Context.md before you stop.
That file is the truth. This one is only the map to it.
