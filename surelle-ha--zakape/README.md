# zakape

> Tome by [surelle-ha](https://github.com/surelle-ha/zakape), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

An open-source pixel-art and sprite-animation workbench for the desktop. It keeps the dependable parts of a traditional sprite editor—precise tools, layers, frames, onion skinning, palettes, and production exports—while adding an optional bring-your-own-model assistant that proposes reviewable pixel operations.
