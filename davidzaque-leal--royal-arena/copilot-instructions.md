# Performance Rules

Always optimize:
- leaderboard queries
- ranking calculations
- historical lookups
- pagination
- snapshot ingestion

Detect:
- N+1 queries
- full table scans
- missing indexes
- unnecessary allocations

Prioritize:
- Redis caching
- compiled queries
- async operations
- efficient pagination
