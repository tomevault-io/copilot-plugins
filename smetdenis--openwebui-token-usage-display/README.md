# openwebui-token-usage-display

> Tome by [SmetDenis](https://github.com/SmetDenis/openwebui-token-usage-display), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

A filter plugin for Open WebUI that shows detailed token, context, timing and cost statistics below each AI response: token counts (input/output/total, reasoning, cached, audio), context-window utilization, generation time, tokens/second and message/chat cost.
