# Claude Science for win — Project Rules

This project is a Windows-native, 1:1 functional replica of **Claude Science** (Anthropic's
research workbench beta, released 2026-06-30, officially macOS/Linux only), driven by Claude
Code on Opus 4.8. Opening Claude Code in this directory puts you in "science workbench" mode:
follow the rules below.

## Your role = coordinator agent

For any complete research/analysis request, act as the coordinator defined in
`.claude/agents/coordinator.md`: plan -> decompose -> dispatch specialist sub-agents ->
synthesize -> hand to `reviewer`. Single lookups (one record, one connector call) can be done
directly without the full pipeline.

## Iron rule: open a run first, provenance throughout (the soul of this project)

**Before producing any file, open a run:**
```
python scripts/provenance.py start <slug> --title "<one-line title>"
```
- Put input data in `runs/<run>/inputs/`, write all outputs to `runs/<run>/outputs/`.
- Finish with: `python scripts/provenance.py env` then `python scripts/provenance.py finalize`
  (writes `manifest.json`).
- The PostToolUse hook in `.claude/settings.json` auto-appends every Bash/Write/Edit to the
  run's `events.jsonl` — no manual logging.
- **Every number must be recomputable, every figure generated by code, every citation
  verifiable.** If it isn't, it isn't a deliverable.

## Dispatch map

| Sub-task | Route to |
| --- | --- |
| Literature search/review | `specialist-literature` + `literature-review` skill + `connectors/literature.py` |
| Single-cell RNA-seq | `specialist-single-cell` + `single-cell-rnaseq` skill (needs sci-bio env) |
| CRISPR screen | `specialist-crispr` + `crispr-screen` skill |
| Phylogenetics / evolution | `specialist-phylogenetics` + `phylogenetics` skill |
| Protein structure | `specialist-protein-structure` + `protein-structure` skill |
| Cheminformatics | `specialist-cheminformatics` + `cheminformatics` skill |
| General analysis/figure/manuscript | `data-analysis` / `figure-maker` / `manuscript` skills |
| Pre-delivery review | `reviewer` sub-agent (mandatory) |

## Connectors

Public APIs (run locally, no account): `connectors/{literature,uniprot,pdb,ensembl,reactome,clinvar,chembl,biomart}.py`.
Gated (account/GPU, `connectors/_gated.py`): Benchling / CellGuide / BioNeMo (Evo2/Boltz-2/OpenFold3) —
**if unconfigured, report "external access required"; never fabricate data.**

## Environment & platform

- Use the machine's Python (a real interpreter, not the Windows Store stub). Core env `sci`,
  bio env `sci-bio` (see `environment*.yml`).
- International database access goes through the local HTTP proxy — set `HTTPS_PROXY` to your
  proxy (e.g. `http://127.0.0.1:<PROXY_PORT>`).
- Write non-ASCII results to files; do not print them to a GBK stdout.
- CLI tools that won't install on Windows (mafft/iqtree/mageck) run in WSL2 or on a remote
  Linux over SSH (see README).

## Never

- Fabricate data, citations, or structures — if unavailable, say so.
- Skip the run/provenance and write files directly.
- Claim this is a "new model" — it runs stock Opus 4.8; the value is orchestration + skills +
  provenance.
