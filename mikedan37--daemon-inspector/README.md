# daemon-inspector

> Tome by [Mikedan37](https://github.com/Mikedan37/daemon-inspector) — distributed by [TomeVault](https://tomevault.io)

daemon-inspector is a read-only forensic CLI for macOS that observes launchd daemons over time. It collects snapshots, derives lifecycle events, tracks instability, and inspects on-disk binaries without executing code.
