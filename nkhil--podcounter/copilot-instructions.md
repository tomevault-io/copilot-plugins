Guidelines for front-end development

Using the Chrome Devtools MCP to explore the following websites:

- https://peanut.me/
- https://panda-css.com/
- https://www.mozilla.org/en-US/firefox/family/

I would like you to use these to inform the design of this site. 

- Strong lines and drop shadows
- bold colours
- no border radius
- monospace fonts (Menlo as preference)

## TASK

I'd like a one page application which has a stopwatch controls with 00:00:00 being displayed at the start.

The user can press a "Start" button to start the stopwatch.

At any point while the stopwatch is going, the user can hit a "Add note" button, which will display the timestamp at which the button was pressed, the user can then add some notes.

The user should be able to add multiple notes.

Once done, the user should be able to press 'Download' and download a text file with all of their notes
