# Fig-Draw

> Source: [xuedong-z/Fig-Draw](https://github.com/xuedong-z/Fig-Draw) — distributed by [TomeVault](https://tomevault.io)

Browser-based post-processing editor for scientific figures — arrange panels, recolor from a 120-palette library, resize like figsize, and export publication-ready PNG/SVG. Runs entirely client-side.
