# AGENTS.md

The operating manual for this repo is **`CLAUDE.md`**. Read that.

This file used to be a 607-line copy of an older `CLAUDE.md`. It had drifted
out of sync and described an architecture that does not compile: `src/mania/`
and `src/rsdk/` as the live code (neither links), a 1,965-line `src/main.c`
(it is 683 lines and mostly dead in every shipping image), and a mandatory
startup procedure pointing at a Windows path and a `D:` drive that do not
exist on every seat.

Two entry-point documents that disagree are worse than one, so this is now a
pointer. The old contents are in git history.
