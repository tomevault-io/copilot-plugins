## tailscale-mikrotik

> This is an Open Source project that should follow best practices.

This is an Open Source project that should follow best practices.
Everything should be documented in a clear, simple and concise manner.
The project contains a lightweight Docker image for Tailscale, a tool for secure, private network connectivity.
The container should be as small, secure, fast, reliable and easy to understand as possible, targeting under 30MB.
