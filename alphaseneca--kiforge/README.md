# kiforge

> Source: [alphaseneca/kiforge](https://github.com/alphaseneca/kiforge). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

KiForge is a build pipeline for KiCad projects, automating export of PCB renders, BOMs, SVGs, STEP models, and release artifacts for manufacturing and documentation.
