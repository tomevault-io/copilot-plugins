# amipilot

> Source: [sidick/amipilot](https://github.com/sidick/amipilot). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

AmiPilot: object-level GUI automation for classic AmigaOS — point at, locate, click, type, drag, launch, screenshot, and wait on real windows/gadgets by role, label, or manifest ID over a wire protocol or MUI's own ARexx port, driven from Python or pytest, not by pixels
