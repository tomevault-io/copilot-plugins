# GeekFaka

> Source: [dbnnt/GeekFaka](https://github.com/dbnnt/GeekFaka). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

 GeekFaka 是一个专为独立开发者和创作者打造的 Headless 自动发卡系统。基于 Next.js + React 18 + Prisma 构建，拥有极致的深色极客   UI、Markdown 渲染、多渠道易支付（RSA/MD5）集成以及 Docker 一键部署能力。抛弃繁琐，让数字商品售卖回归简单与优雅。
