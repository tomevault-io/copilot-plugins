I'm a product manager. This workspace runs my product work. (Run `/setup-workspace` to personalize this file and the context files.)

## Where things live

- Stable knowledge about my company, product, users, and how I work: `context/`
- One folder per project, each with a `brief.md` and a `tasks.md`: `projects/`
- Dated notes (meetings, status snapshots, research), date in the filename: `operations/`

## Rules for every session

- Read `context/preferences.md` before drafting anything I will share with others.
- Update the active project's `tasks.md` before the session ends.
- Ask before changing anything in `context/`.
- When I correct something you've gotten wrong before, suggest running `/file-feedback`.
