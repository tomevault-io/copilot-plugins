## spring-test-ci

> - JDK17, Spring Boot 4.1.x 버전에서 개발 중이므로 해당하는 가장 최신 문법을 적용

- JDK17, Spring Boot 4.1.x 버전에서 개발 중이므로 해당하는 가장 최신 문법을 적용
- 단위 테스트를 클린 아키텍처 레이어 단위로 해서 진행해줘
- JUnit, Mockito, AssertJ 등을 사용해서 단위 테스트를 작성해줘
- 각각의 테스트는 BDD 방법론으로 작성해줘
- 각각 로직에 대해서는 한글 주석으로 32자 이내의 개념적/절차적 설명을 넣어줘
