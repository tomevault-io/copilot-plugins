# M5-Tab5-ESPHome-LVGL

> Source: [Axellum/M5-Tab5-ESPHome-LVGL](https://github.com/Axellum/M5-Tab5-ESPHome-LVGL). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Home Assistant wall screen for the M5Stack Tab5 (ESP32-P4), built with ESPHome and LVGL. Home Assistant pushes, the tablet never polls. Screen in 7 languages (FR, EN, DE, NL, ES, IT, TR). Local wake word, weather, climate, rooms of devices, plants, 8 offline games. Web installer. Made with AI.
