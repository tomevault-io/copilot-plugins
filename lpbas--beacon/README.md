# Beacon

> Tome by [lpbas](https://github.com/lpbas/Beacon) — distributed by [TomeVault](https://tomevault.io)

Beacon is a native macOS menu bar app that re-broadcasts selected Bonjour/mDNS services from your Mac, making Docker or OrbStack-hosted services like Home Assistant and HomeKit bridges discoverable across your local network.
