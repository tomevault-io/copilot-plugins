# imgui-studio

> Tome by [mr1337robot](https://github.com/mr1337robot/imgui-studio), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

ImGui Studio is a local-first, AI-native development environment for creating custom Dear ImGui menus in real C++. It gives an agent the same practical loop that makes website vibe coding work: change code, render the result, inspect what happened, interact with it, and refine the design.
