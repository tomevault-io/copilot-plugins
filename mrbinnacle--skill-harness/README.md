# skill-harness

> Source: [MrBinnacle/skill-harness](https://github.com/MrBinnacle/skill-harness). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

How do you KNOW if a 'skill' is any good - deterministically? This runs controlled skill-vs-no-skill experiments. It doesn't just ask, “Did the skill work?” It asks “Did we actually give the skill to the model, did the comparison remain fair, what changed, what did it cost, and do we have enough evidence to say that confidently?”
