# Lincan-Travel-Assistant-Agent

> Source: [LC-di-yan/Lincan-Travel-Assistant-Agent](https://github.com/LC-di-yan/Lincan-Travel-Assistant-Agent) — distributed by [TomeVault](https://tomevault.io)

基于大语言模型的多智能体旅行规划系统，采用 Plan-and-Execute 架构，提供智能化的差旅出行助手服务。  核心特性包括：基于 LLM 语义理解的 6 大类意图识别（准确率 90%+）、两层记忆架构（Redis 短期缓存 + PostgreSQL 长期持久化）、RAG 知识库检索（准确率 95%）。  性能方面，优先级并行调度使响应时间从 30 秒优化至 15 秒；插件化架构支持懒加载，启动仅需 3 秒。  技术栈：AgentScope、豆包大模型、PostgreSQL、Redis、Milvus、BGE Embedding。
