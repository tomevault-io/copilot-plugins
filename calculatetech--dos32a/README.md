# dos32a

> Source: [calculatetech/dos32a](https://github.com/calculatetech/dos32a) — distributed by [TomeVault](https://tomevault.io)

A patched and optimized version of DOS/32A for real DOS environments. Original 9.1.x versions had changes that served dosbox use cases but broke linear framebuffer write combining. This release aims to fix that.
