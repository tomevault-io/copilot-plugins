## Commands

```bash
bun run dev          # Start all apps/packages in dev mode (runs turbo dev)
bun run build        # Build all packages (runs turbo build)
bun run lint         # Lint all packages
bun run format       # Format all packages with prettier
bun run typecheck    # TypeScript type checking across all packages
```

To run commands for a specific workspace:

```bash
# Run dev server for web app only (port 3000)
cd apps/web && bun run dev

# Add a shadcn component
bunx shadcn@latest add <component> -c apps/web
```

## Architecture

Turborepo monorepo with bun workspaces. Two workspace roots: `apps/*` and `packages/*`.

### `apps/web`
TanStack Start (React 19) app using Vite + Nitro for SSR. File-based routing via TanStack Router — routes live in `src/routes/` and the route tree is auto-generated in `src/routeTree.gen.ts` (do not edit this file manually). Router config is in `src/router.tsx`.

Path aliases: `@/*` maps to `./src/*`, `@workspace/ui/*` maps to `packages/ui/src/*`. App-specific components live in `src/components/` (e.g. `src/components/spec/`).

### `packages/ui`
Shared UI library using shadcn/ui (base-lyra style) with Base UI, Tailwind CSS v4, and Remixicon. Exports via package.json `exports` field:
- `@workspace/ui/components/*` → `src/components/*.tsx`
- `@workspace/ui/hooks/*` → `src/hooks/*.ts`
- `@workspace/ui/lib/*` → `src/lib/*.ts`
- `@workspace/ui/globals.css` → `src/styles/globals.css`

## Key Conventions

- **No semicolons**, double quotes, trailing commas (es5), 2-space indent (see `.prettierrc`)
- shadcn components are installed into `packages/ui/src/components/`, not the app
- Use `cn()` from `@workspace/ui/lib/utils` for className merging (clsx + tailwind-merge)
- Tailwind CSS v4 — styles configured via CSS (`globals.css`), not `tailwind.config.*`
- Prettier plugin `prettier-plugin-tailwindcss` auto-sorts Tailwind classes; `cn` and `cva` calls are also sorted
- `rsc: false` — not using React Server Components; this is a client-rendered SSR app
