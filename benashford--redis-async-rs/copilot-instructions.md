# redis-async-rs

An asynchronous Redis client for Rust, using Tokio and futures.

## Tech Stack & Architecture
- **Language**: Rust (stable, beta, nightly compatibility)
- **Asynchronous Runtime**: Tokio
- **Ecosystem**: Futures crate, RESP (Redis Serialization Protocol)
