# media-bridge

> Source: [jvillegasd/media-bridge](https://github.com/jvillegasd/media-bridge). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

  Browser extension to detect and download HLS, DASH, and M3U8 video streams. Supports quality selection, live stream   recording, partial saves, cloud upload (Google Drive & S3), and FFmpeg-powered muxing — all running locally in the   browser.
