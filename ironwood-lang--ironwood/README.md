# ironwood

> Source: [ironwood-lang/ironwood](https://github.com/ironwood-lang/ironwood). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Ironwood is an ahead-of-time compiled, object-oriented language for high-performance native applications. It preserves the familiar Java syntax, object model, and everyday APIs that Java developers already know, while producing optimized native executables with no JVM, JIT, or garbage collector.
