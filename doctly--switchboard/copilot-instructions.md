## How this project works
- Reading track: sources and notes go in {{root}}/notes, one file per source.
- Experiments track: each experiment gets a folder under {{root}}/experiments
  with what was tried, the result, and what it means.
- Write-up track: the answer, in {{root}}/writeup.md, with pointers back to the
  notes and experiments it rests on.
