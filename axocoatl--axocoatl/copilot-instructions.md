# Marketing-site instructions

These rules extend `sites/AGENTS.md`.

Claims must be supportable by current code and a reachable product journey. The current
privacy position is `local-first by default; you choose the sandbox`, because remote
isolation is opt-in. Do not use an unqualified claim that work never leaves the machine.

Do not name competitors, use hype, fabricate proof, expose internal launch plans, or publish
volatile metrics. Do not call a product mock exact or 1:1 unless it is regenerated and
visually compared to the current app in the same change.

For a site change, serve the static site and inspect the affected page at desktop and mobile
widths. Check local assets, theme behavior, console errors, and all changed links.
