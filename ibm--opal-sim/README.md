# opal-sim

> Tome by [IBM](https://github.com/IBM/opal-sim) — distributed by [TomeVault](https://tomevault.io)

Opal (O.P.A.L. - Open simulator Platform for distributed AI and LLM workflows) is an LLM platform-level simulator written purely in Python. It can be used to explore policies, deployment configurations, optimizations, and what-if scenarios for scalable, distributed inference services like llm-d.
