# It Girl Aesthetic System

## Overview

This skill turns the May 17 deep research into a reusable taste system for **It Girl aesthetic design**.

The mission is simple:

```text
make product, brand, UI, social, editorial, and marketing decisions that feel current, feminine, premium, self-possessed, and culturally fluent
```

This is not a production pipeline. It is a **taste and direction skill**.

Use it to decide:

- what something should feel like
- what references matter
- what typography fits
- what palette fits
- what layout language fits
- what copy tone fits
- why a design feels cheap, childish, generic, sterile, or off-vibe
- how to move it closer to the researched aesthetic

Core phrase:

```text
private discipline, public polish
```

The aesthetic works when it feels like discipline without desperation, status without logos, wellness without woo-woo, fashion without costume, and culture without trend-victim noise.

## First Principles

The It Girl aesthetic is not a list of clothes. It is a **social signal**.

It says:

```text
she is current, socially fluent, desired, composed, healthy, self-owned, and hard to impress
```

The signal comes from controlled contradictions:

- casual, but expensive
- minimal, but not plain
- soft, but not childish
- healthy, but not gym-coded
- feminine, but not frilly
- polished, but not corporate
- approachable, but not needy
- current, but not trend-victim

If the design screams, it is wrong.
If it whispers but still feels intentional, it is closer.

## The Status Code

The aesthetic is built from subtle markers:

1. Fit and fabric over logos.
2. One recognizable premium object, not ten.
3. Clean hair and skin, not heavy glam.
4. Relaxed expression, not influencer smile.
5. Simple forms with precise silhouette.
6. Negative space and editorial restraint.
7. Slight imperfection: walking crop, mirror angle, natural shadow, hair movement, off-center frame.
8. A composed mood: she is not asking to be liked.

Deep read:

```text
It is less “look at me” and more “you noticed anyway.”
```

## Core Visual Formula

The strongest researched direction is:

```text
off-duty model + boutique Pilates + quiet luxury + slight downtown edge
```

Use that mix as the default. Do not collapse it into only “clean girl.” Clean girl alone becomes beige, soft, and forgettable.

Default blend:

- 35% boutique Pilates / wellness studio
- 30% model-off-duty proportion and attitude
- 20% quiet luxury restraint
- 10% editorial fashion hierarchy
- 5% downtown edge so it does not become sterile

## Visual Archetypes

Feeling:

```text
moisturized, calm, rich-adjacent, emotionally regulated
```

Visual codes:

- slick bun, center-part blowout, claw clip
- white, cream, black, chocolate, oat base palette
- ribbed tanks, fitted long sleeves, linen trousers, silk shorts
- gold hoops, sunglasses, structured bag
- natural light, stone, cream architecture, apartment mirror, café
- neutral expression, calm face

Use for:

- restraint
- skin/hair polish
- lighting
- accessory logic
- premium calm

- too beige
- too bland

### 2. Model-Off-Duty / Street-Style It Girl

tall, unfussed, photographed between things

- oversized denim, trench coats, loose pants, tiny/fitted tops

## Typography System

Typography should make the product feel premium without making it hard to use.

### Default structure

Use:

1. **One invisible UI sans** for interface, body, labels, controls.
2. **One editorial accent** for brand moments, campaign headlines, hero screens.
3. **Optional mono** only for metrics, dates, timers, reps, sets, and numbers.

Never use more than two families plus optional mono.

### Practical pairs

Best Google/free direction:

- **Inter + Instrument Serif**: clean app plus editorial softness.
- **Geist + Instrument Serif**: more modern, sharper app feel.
- **Manrope + Cormorant Garamond**: softer premium wellness.
- **DM Sans + Newsreader**: approachable editorial.
- **Space Grotesk + IBM Plex Mono**: cooler performance minimalism.

Premium/paid direction:

- Neue Haas Grotesk / Suisse / Switzer + Canela / Editorial New / Adobe Garamond style.
- Apercu-style sans + serif accent for beauty/wellness cultural polish.
- Condensed grotesk only for campaign/class intensity, not body UI.

### Type rules

Do:

- use small uppercase labels with tracking
- use generous line-height for body copy
- keep UI copy readable on mobile
- let numbers look intentional
- use serif sparingly as taste, not decoration
- use lowercase for softer brand phrases when appropriate

Do not:

- use Poppins-only, Montserrat-only, or Roboto-only identity systems
- use cute rounded/bubble fonts
- use script/signature fonts
- set body or instructions in fragile fashion serifs
- use thin Didot/Bodoni in functional UI
- overuse condensed uppercase until it feels like a boxing gym

## Palette System

Default base:

```text
warm ivory, paper white, cream, oat, taupe, stone, soft grey, espresso, washed black
```

Good accents:

```text
powder blue, deep navy, butter yellow, muted sage, burgundy, silver, rare clean red
```

Rules:

- Keep the base restrained.
- Use one accent at a time.
- Let contrast come from crop, typography, and spacing, not loud color.
- Blue is useful when the design needs distinction without going pink.
- Black can work, but soften it with cream, skin, fabric, and daylight.

Avoid:

- hot pink as the default
- neon fitness palettes
- generic purple SaaS gradients
- oversaturated pastels
- muddy beige with no hierarchy
- rainbow wellness clutter

## Layout Language

The layout should feel editorial, mobile-native, and calm.

Use:

- full-bleed image moments
- strong but simple crop
- large type paired with tiny labels
- thin dividers
- warm neutral backgrounds
- generous margins
- fewer, stronger modules
- one dominant visual idea per screen
- product UI that stays legible

Avoid:

- card soup
- sticker-sheet chaos
- dense dashboards with no hierarchy
- generic startup hero gradients
- stock icon rows
- excessive rounded rectangles
- decorative flourishes that do not carry meaning

Rule:

```text
Do not add clutter to make it feel designed. Improve hierarchy, spacing, crop, and type first.
```

Use imagery that feels:

- candid but composed
- softly lit

- tactile
- skin/fabric/daylight aware
- adult

Good subjects/settings:

- boutique studio mirror
- reformer or mat detail
- apartment wall daylight
- city street after class

Good composition:

## Copy Tone

Voice:

```text
short, calm, self-possessed, direct, premium, quietly confident
```

Good phrases:

- “private discipline”
- “public polish”
- “today’s focus”
- “quiet strength”
- “soft discipline”
- “the Pilates edit”
- “core, controlled”
- “sculpt, then recover”
- “3 moves. 12 minutes.”
- “a cleaner way to train”
- “a little burn. a lot of payoff.”

Bad phrases:

- “crush your goals”
- “no excuses”
- “bikini body”
- “shred fat fast”
- “slay your workout”
- “girlboss your fitness”
- “hot girl sweat sesh” unless deliberately ironic
- generic motivational sludge

## Decision Filters

### If it feels generic

Add:

- stronger editorial crop
- more whitespace
- sharper type contrast
- warmer neutral background
- one premium accent color
- smaller tracked labels
- better hierarchy

Remove:

- stock wellness icons
- generic gradients
- SaaS-purple glow
- emoji energy
- obvious templates

### If it feels childish

Make it:

- less pastel
- less rounded
- less bubbly
- less smiley
- quieter
- more editorial
- more adult
- more expensive

### If it feels too clean and boring

Do not add clutter. Add controlled tension:

- downtown edge
- a darker crop
- condensed label
- sharper black/cream contrast
- one unexpected accessory/detail
- stronger type scale

### If it feels too harsh or gym-bro

Make it:

- warmer
- more lifestyle/studio
- less red/black
- less metallic
- less command-language
- more tactile: fabric, skin, daylight, cream, floor shadows

### If it feels too fashion and not useful

Make it:

- more legible
- more mobile-first
- fewer overlapping type treatments
- clearer CTA
- clearer product state
- metrics readable
- editorial moments reserved for headers/campaigns

## Output Recipes

### Mobile app home screen

```text
Background: warm ivory or paper white
Header: tiny tracked label + calm greeting/focus
Primary module: one strong workout/session card
Typography: UI sans, medium weights, strong spacing
Metric treatment: optional mono for time/reps/streak
Accent: one powder blue/navy/butter/sage chip
Avoid: dense dashboard, confetti, noisy streak gamification
```

### Workout/session card

```text
Visual: clean crop or tactile studio detail
Title: short, direct, calm
Details: 3 x 12 / 12 min / core / beginner
CTA: one obvious action
Tone: controlled, not motivational yelling
Avoid: trainer stock photo, neon, “destroy your abs” language
```

### Landing page hero

```text
Headline: editorial but clear
Subcopy: short, self-possessed, no hype
Visual: one strong lifestyle/studio crop
Palette: cream, washed black, taupe, one accent
Layout: negative space, one CTA, mobile-first
Avoid: generic SaaS gradient, icon row, overexplaining
```

### Social moodboard carousel

```text
Slide 1: editorial crop + serif/condensed headline
Slide 2: routine/program cards in clean sans
Slide 3: outfit/detail/lifestyle collage
Slide 4: simple metrics or checklist
Slide 5: quiet CTA
Rule: curated, not scrapbook chaos
```

### App Store screenshot direction

```text
Phone mockup large but not noisy
Short premium headline
Warm neutral or deep navy background
One product idea per screenshot
Small labels only when useful
Avoid sticker-sheet chaos and loud gradient wallpaper
```

## Critique Format

When reviewing a design, be blunt and specific.

Use this structure:

```text
Verdict: [on-vibe / close / off-vibe]
Why: [2-4 concrete observations]
Biggest failure: [one thing]
Fix: [specific design moves]
Reference to pull from: [moodboard/source/archetype]
```

Do not say “make it more premium” without naming the exact levers: type, crop, spacing, palette, tone, imagery, hierarchy, or material.

## Common Pitfalls

1. **Contaminating the aesthetic skill with production mechanics.** Wrong. This skill is the source-backed taste system: mood, references, typography, palette, layout, copy, and critique. Do not add image-generation tools, model names, LoRA/ControlNet workflows, character sheets, app-specific product logic, or one project's internal references here. Put production mechanics in the relevant image/design implementation skill.

2. **Reducing It Girl to pink Pilates.** Wrong. Pink Pilates is one weak surface expression. The deeper system is status, restraint, polish, and controlled contradiction.

3. **Making clean girl the whole brand.** Clean girl alone becomes beige and forgettable. Add model-off-duty proportion, quiet luxury restraint, and slight downtown edge.

4. **Confusing premium with empty.** Minimalism still needs hierarchy, tension, and an ownable detail.

5. **Using fashion type where product clarity matters.** Editorial type belongs in hero/campaign moments. Functional UI must stay readable.

6. **Going too cute.** Rounded fonts, bubbly copy, stickers, bows, and excessive pastels kill adult aspiration.

7. **Going too gym-bro.** Red/black aggression, punishment copy, fake sweat, and “crush it” language break the aesthetic.

8. **Copying references literally.** Steal principles, not costumes.

9. **Forgetting mobile.** If it only works as a desktop moodboard, it fails as a product system.

## Verification Checklist

Before finalizing direction, verify:

- [ ] The moodboard or research report was checked.
- [ ] The design has one clear dominant idea.
- [ ] The palette is restrained and intentional.
- [ ] Typography uses one UI sans plus one editorial accent at most.
- [ ] Layout has enough whitespace and mobile clarity.
- [ ] Copy is calm, short, and self-possessed.
- [ ] It avoids childish, neon, gym-bro, template-wellness, and generic SaaS drift.
- [ ] It contains at least one taste marker: crop, fabric, silhouette, negative space, type hierarchy, or premium object detail.
- [ ] The final direction can be described as “private discipline, public polish.”
