# OpticStudioMCPServer

> Source: [zym1998year/OpticStudioMCPServer](https://github.com/zym1998year/OpticStudioMCPServer) — distributed by [TomeVault](https://tomevault.io)

修复了mcp连接zemax3秒超时自动崩溃的问题，zemax冷启动超过3秒导致mcp无法正常连接已修复，并且添加了实现光学系统的设计、分析与优化。本次新增四个工具：ExportAnalysisTool 支持 17 种分析类型的 BMP 图像及   TXT 数据导出，含二维数据网格的分析（PSF、波前图等）自动渲染为热力图；GeometricImageAnalysisTool 提供   25+ 参数的几何像分析，支持辐照度数据返回与设置持久化；SetSurfaceParameterTool   支持面型参数的单个/批量/全量读写，兼容 Double 与 Integer 类型；SetSurfaceTypeTool  实现面型切换，大小写不敏感，支持所有 ZOSAPI 面型。
