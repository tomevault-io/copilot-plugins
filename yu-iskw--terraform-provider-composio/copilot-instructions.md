# Examples

The `examples` directory contains runnable and documentation examples for the Composio provider.

Documentation generation reads:

- `examples/provider/provider.tf`
- `examples/resources/<resource_name>/resource.tf`
- `examples/data-sources/<data_source_name>/data-source.tf`

Keep examples focused on control-plane objects. Do not show tool execution or OAuth browser flows.
