本项目主要面向集群分布式开发，旨在解决分布式场景下后端服务的稳定性与可用性（如 AI 调用去重、长会话状态恢复、并发一致性保障）。项目不依赖任何 Agent 框架，面试流程通过本地状态机 + DeepSeek API 直接编排，是一个纯后端基础设施项目，面试业务场景是这些分布式机制的载体。
