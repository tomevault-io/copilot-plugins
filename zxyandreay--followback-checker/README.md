# followback-checker

> Source: [zxyandreay/followback-checker](https://github.com/zxyandreay/followback-checker) — distributed by [TomeVault](https://tomevault.io)

FollowBack Checker is a web app that helps users analyze their Instagram followers and following list using their official Instagram data export. It compares the data locally in the browser to show accounts that don’t follow back, mutual connections, and followers the user doesn’t follow back—without requiring an Instagram login
