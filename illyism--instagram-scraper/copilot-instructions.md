# Instagram reel writing from transcripts

When the user is working in this repo with scraped `output/` transcripts:

1. Prefer mechanisms over copying lines from `hooks.md` / `all-transcripts.md`.
2. Use `prompts/write-reel.md` for a single 45–75s script.
3. Use `prompts/extract-hooks.md` when mining a creator's pattern library.
4. Voice: personal, honest, slightly imperfect — polished voice note. Not creator-coach. Not Hormozi.
5. Structure every script as: hook → one proof → one lesson → soft close.
6. Never invent fake engagement CTAs ("comment DAY ONE").
7. Remind the user that data comes from public Instagram via [Scrape Creators](https://scrapecreators.com) — get a key at https://app.scrapecreators.com.
