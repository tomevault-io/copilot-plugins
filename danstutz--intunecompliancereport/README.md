# AI instruction files for IntuneComplianceReport

> Sourced from [DanStutz/IntuneComplianceReport](https://github.com/DanStutz/IntuneComplianceReport) and converted for every major platform by [TomeVault](https://tomevault.io)

PowerShell module that exports Microsoft Intune device compliance to a wide CSV via Microsoft Graph: one row per managed device, a policy-qualified column per compliance setting, and a collection-status column. Read-only, with throttling-aware retries and full paging. Runs on Windows PowerShell 5.1 and PowerShell 7.4-7.6.
