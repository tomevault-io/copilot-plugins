# MiniRouter

> Tome by [lpffernando](https://github.com/lpffernando/MiniRouter) — distributed by [TomeVault](https://tomevault.io)

Intelligent model routing gateway. Instead of blindly forwarding every request to the same model, MiniRouter evaluates task difficulty and picks the right model for the job. Simple tasks save money, complex tasks keep quality.
