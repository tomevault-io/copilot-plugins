# radio-gateway

> Tome by [ukbodypilot](https://github.com/ukbodypilot/radio-gateway), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Multi-radio, multi-machine Linux gateway: ham/GMRS radios → Mumble, Broadcastify, Winlink, APRS, Telegram, live web UI. Visual drag-and-drop audio routing, plugin radios (TH-9800, D75 BT, KV4P, FTM-150, IC-7100, RSPduo dual SDR), distributed Moonshine + Whisper transcription pool, AI fleet manager, 95+ MCP tools.
