# caldav-mcp

> Tome by [gelse](https://github.com/gelse/caldav-mcp), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

An MCP server that bridges AI assistants to CalDAV calendars. 14 tools for listing, creating, updating, deleting, and searching events across Nextcloud, Radicale, Baikal, iCloud, and more. Stateless, Dockerized, two-layer auth. Python 3.13.
