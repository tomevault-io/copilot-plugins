# p2wlan

> Source: [yhan-sun/p2wlan](https://github.com/yhan-sun/p2wlan). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

跨平台 P2P 虚拟局域网(VirtualLAN)工具，让异地设备像在同一局域网中互联。支持 NAT 穿透、IPv6 直连、房间组网与 Relay 回退，覆盖 Windows / macOS / Linux / Android。
