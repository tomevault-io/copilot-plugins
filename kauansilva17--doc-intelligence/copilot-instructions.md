# Instruções para agente

- Respeitar a especificação em `docs/specification.md`.
- Não adicionar dados reais de clientes.
- Priorizar uma fatia vertical pequena e funcional.
- Separar UI, serviços e tipos.
- Não esconder limitações; registrar decisões e trade-offs.
- Antes de alterar arquitetura, verificar os ADRs.
- Explicar qualquer divergência da especificação.
- Registrar os prompts utilizados durante o desenvolvimento em `prompts/`.
- Validar alterações executando a aplicação e a build quando aplicável.
