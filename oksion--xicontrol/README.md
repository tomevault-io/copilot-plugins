# XiControl

> Source: [Oksion/XiControl](https://github.com/Oksion/XiControl). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Tray utility for Xiaomi / Redmi laptops (Redmibook, Xiaomi Book Pro): battery charge limit 40-100%, performance modes, auto refresh rate, OSD and Mi button remapping - driver-free, via the stock firmware WMI interface (MIFS). Available in winget.

## GitHub Copilot Config

The `copilot-instructions.md` file in this directory is the project config converted for GitHub Copilot.
