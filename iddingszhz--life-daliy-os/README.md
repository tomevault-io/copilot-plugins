# Life_Daliy_OS

> Source: [iddingszhz/Life_Daliy_OS](https://github.com/iddingszhz/Life_Daliy_OS) — distributed by [TomeVault](https://tomevault.io)

Life_Daliy_OS 是一个开放框架的日记操作系统。它将每日日记从零散的文字记录升级为分层级的自我认知系统：AI 与你对话式填日记 → 周模式识别 → 月趋势追踪 → 按需深度挖掘。模块可插拔（心理分析 / 战略推演 / 闪念孵化 / 复利见证），数据全归你，支持 Obsidian Dataview 实时图表。
