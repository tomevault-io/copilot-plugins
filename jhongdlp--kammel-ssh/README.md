# Kammel_ssh

> Source: [Jhongdlp/Kammel_ssh](https://github.com/Jhongdlp/Kammel_ssh). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

SSH client for Android & Linux built for driving AI coding agents (Claude Code, Codex, Aider, Gemini CLI…) from your phone: multi-session terminal that survives backgrounding, notifications when the agent needs you, SFTP explorer, code editor, git panel and a Docker/DB server console. Flutter, MIT.
