# float-android

> Source: [shiaho777/float-android](https://github.com/shiaho777/float-android). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

一部装在 Android 里的 AI 虚拟手机：拟真桌面、聊天、朋友圈、查手机、地图定位、语音/视频通话、日记日历。AI 角色有作息、日程、位置和长期记忆，会主动发消息、发帖互动。数据全在设备本地，联网只调你自己配置的 LLM/生图/语音 API。
