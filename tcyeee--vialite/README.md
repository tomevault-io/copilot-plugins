# vialite

> Source: [tcyeee/vialite](https://github.com/tcyeee/vialite). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

A native web configurator for Vial-protocol keyboards — edit keymaps, macros, tap dance, combos and lighting straight from Chrome/Edge over WebHID. No Qt, no WebAssembly, no install.
