# ciaobot

> Source: [raffaelefarinaro/ciaobot](https://github.com/raffaelefarinaro/ciaobot). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Ciaobot is an opinionated interface for using Claude Code and/or Codex as a personal assistant and second brain. It is a local web app around agentic work: chats, projects, files, schedules, memory, and archived knowledge all live in one interface instead of being scattered across terminal sessions.
