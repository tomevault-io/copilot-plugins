# Powabase

This repository ships the **powabase** agent skill at
[`skills/powabase/SKILL.md`](skills/powabase/SKILL.md) — it teaches you to build on
Powabase, the AI Backend-as-a-Service (RAG / knowledge bases, agents, multi-agent
orchestration, workflows) and its Supabase-style BaaS layer (PostgREST, auth,
storage, realtime, direct Postgres).

When a task involves Powabase — a `*.p.powabase.ai` project, the `/api/*` surface,
knowledge bases, agents, orchestrations, workflows, or the BaaS layer — load and
follow that skill.
