# AGENTS.md

## 프로젝트 개요
Emotion Camp는 사용자의 텍스트를 감성 분석하여
긍정 / 부정 / 중립 결과를 제공하는 감성 분석 웹 서비스이다.

기술 스택:
- Front-end: HTML, CSS, JavaScript
- Back-end: Node.js
- AI: OpenAI API
- DB: Supabase
- Deployment: Vercel
