# flutter-wallet

> Source: [zhangxiang0316/flutter-wallet](https://github.com/zhangxiang0316/flutter-wallet) — distributed by [TomeVault](https://tomevault.io)

基于 Flutter 和 GetX 构建的多链加密钱包应用。项目当前定位为本地热钱包 Demo/测试应用，已覆盖钱包创建、导入、多钱包切换、多链余额查询、USD 估值、转账、收款、交易记录、内嵌区块浏览器、资产显示管理、自定义代币、网络管理、语言切换和主题切换等核心流程
