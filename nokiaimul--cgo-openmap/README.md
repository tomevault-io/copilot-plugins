# CGo-OpenMap

> Source: [NokiaimuL/CGo-OpenMap](https://github.com/NokiaimuL/CGo-OpenMap). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

现代轻量开源城市轨道交通交互线路图引擎。纯矢量 SVG 渲染，零构建依赖，PWA 离线与深色模式自适应。核心引擎与数据彻底解耦，任何人均可快速移植任意城市；采用 GNU AGPLv3 + ODbL 双轨开源协议，支持多城市主理人专属署名与长期引擎平滑升级保障。
