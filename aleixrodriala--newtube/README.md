# newtube

> Tome by [aleixrodriala](https://github.com/aleixrodriala/newtube), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Unofficial YouTube client for Android phones and tablets, built on SmartTube. Sign in with your Google account using a code (no microG), background play, picture-in-picture, save for offline, SponsorBlock, DeArrow, Return YouTube Dislike. Material Design. MIT.
