## Stack

- **Frontend**: TanStack Start (React 19 + TanStack Router) via Vite + Nitro (not Vinxi).
- **Backend**: Convex (`convex/`).
- **Styling**: Tailwind CSS v4 via `@tailwindcss/vite` plugin; theme config lives in `src/styles/app.css`. No `tailwind.config` or PostCSS config.
- **Forms**: react-hook-form + Zod + @hookform/resolvers.
- **Deploy**: Vercel (`nitro` preset `vercel` in `vite.config.ts`).

## Commands

```
npm run dev        # vite dev
npm run build      # vite build
npm run start      # node .output/server/index.mjs
npm run typecheck  # tsc --noEmit
```

No test, lint, or Prettier npm scripts are configured.

## Dev workflow

- `VITE_CONVEX_URL` and `VITE_CONVEX_SITE_URL` must be set in `.env.local` (see `.env.example`). `.env*.local` is gitignored.
- Run `npx convex dev` alongside `npm run dev` to sync Convex functions and regenerate `convex/_generated/`.
- `src/routeTree.gen.ts` is auto-generated by the TanStack Start Vite plugin.

## Architecture

- `src/entry.client.tsx` – client entry.
- `src/router.tsx` – TanStack Router setup.
- `src/routes/` – file-based routes; route files are `.tsx`.
- `src/providers/ConvexProvider.tsx` – Convex client setup.
- `src/providers/AuthProvider.tsx` – current auth is localStorage-only fake auth; there is no `convex/auth.config.ts`.
- `convex/schema.ts` – re-exports schema from `convex/schema/index`.
- `convex/queries/`, `convex/mutations/`, `convex/actions/` – function organization.
- `convex/_generated/` – auto-generated; do not edit.
- `@/*` path alias resolves to `./src/*`.

## Conventions

- Strict TypeScript: `noUnusedLocals`, `noUnusedParameters`, `noFallthroughCasesInSwitch` are enforced.
- `package-lock.json` is gitignored; run `npm install` to regenerate it.
