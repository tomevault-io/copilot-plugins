# beacon

> Tome by [angaziz](https://github.com/angaziz/beacon), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

A dark and futuristic companion on a 2.16" AMOLED touch device — built on the Waveshare ESP32-S3-Touch-AMOLED-2.16. It sits next to your keyboard and, at a glance, shows your Claude Code / Codex usage, live markets, weather, and a Claude coding "buddy" you can approve tool-prompts on.
