# Megick-Studio

> Tome by [zeeklog](https://github.com/zeeklog/Megick-Studio) — distributed by [TomeVault](https://tomevault.io)

Megick Studio is a creative image and video generation studio that supports various image models such as gpt-image-2, seedream, and Qwen, as well as various models like seedance and wan-2.7. It's an out-of-the-box AI image and video generation application that supports web, Mac OS, and Windows clients.
