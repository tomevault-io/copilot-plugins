这是一个面向 AI 学习者的智能体工作流系统，可以从抖音链接、临时想法、聊天记录等碎片信源，自动完成解析、转写、整理，并写入 Obsidian Inbox。  系统通过 Obsidian MCP 调用知识库模板，将原始内容策展为结构化知识卡片，并自动生成摘要、关键知识点、分类建议、标签、归档位置和项目关联。  它不仅能沉淀 AI 术语、模型、工具、工作流和案例，还能形成持续更新的项目记忆，让用户在产生新想法时调用过往知识，联想到可用工具、工作流和落地路径。
