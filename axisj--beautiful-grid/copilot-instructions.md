## Development

Before changing any site page or shared component, read `../docs/site-design-style-guide.md` and follow its design tokens, layout selection, route-integrity, responsive, and visual-QA rules.

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
