# 👏 Conventions

- Folder name -> kebab-case . ex: base-tag
- Components name -> PascalCase . ex: BaseTag.vue
- Class name -> PascalCase . ex: Question.ts
- Variables or Const names -> camelCase . ex: firstName: string
