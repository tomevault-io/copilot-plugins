# PicForge

> Source: [DejavuMoe/PicForge](https://github.com/DejavuMoe/PicForge) — distributed by [TomeVault](https://tomevault.io)

a local-first browser app for batch image compression and resizing. It uses Canvas, Web Workers, and WebAssembly codecs to process images on your device. There are no accounts, uploads, or server-side image processing.
