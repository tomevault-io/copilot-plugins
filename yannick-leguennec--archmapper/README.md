# archmapper

> Source: [yannick-leguennec/archmapper](https://github.com/yannick-leguennec/archmapper) — distributed by [TomeVault](https://tomevault.io)

ArchMapper — A powerful, resumeable, bottom-up reverse engineering framework for large codebases. Automatically scans folder/file structure, builds a complete hierarchical architecture.json with ideal metadata, connections, and improvement suggestions. Designed for clean-room analysis and any complex repo.
