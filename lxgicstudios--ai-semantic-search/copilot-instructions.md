# Semantic Search

Embeddings-based semantic search for AI applications.

## Quick Start

```bash
npx ai-semantic-search init
```

## What It Does

- Search by meaning, not keywords
- Hybrid search (BM25 + semantic)
- LLM-based reranking
- Custom filtering

## Usage

```bash
npx ai-semantic-search init
npx ai-semantic-search info
```
