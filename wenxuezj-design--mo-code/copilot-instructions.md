# 项目目标

- 本项目以快速复现 Agent 的核心和重要功能为目标，而非追求工程级实现；设计与实现应优先保持核心机制清晰、可运行，避免在非必要细节上投入精力。
- 禁止 AI 自动提交代码，除非用户主动要求。
- AI 禁止自动修改已有的单元测试用例；确需修改时，必须先获得开发者明确确认。
