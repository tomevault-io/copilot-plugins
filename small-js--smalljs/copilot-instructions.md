## smalljs

> This project is mainly written in the programming language SmallJS, a Smalltalk dialect.


This project is mainly written in the programming language SmallJS, a Smalltalk dialect.
SmallJS source files have the extension: .st
Examples of SmallJS code are in the file: ./smalljs.txt.
This file is a source dump that does not need to be changed.

This app is a test application for the SmallJS wrapper for the Electron framework.
The wrapper classes are located in the folder ../../Smalltalk.

The goal now is to expand the SmallJS framework coverage of Electron.
And create unit and GUI tests for the added functionality.
