Plutainer is a Docker image that simplifies running dedicated game servers (IW4x, AW-T7x, P-T4, P-T5, P-T6, P-IW5). It streamlines server setup and management through environment variables, automatic updater scripts, and a robust RCON healthcheck. Just bring your game files, configure the docker-compose.yml, and get your server online.
