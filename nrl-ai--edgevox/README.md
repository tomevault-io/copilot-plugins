# edgevox

> Source: [nrl-ai/edgevox](https://github.com/nrl-ai/edgevox) — distributed by [TomeVault](https://tomevault.io)

Offline voice agent framework for robots — agents, skills, workflows, sub-second voice pipeline, 2D/3D simulation (IR-SIM + MuJoCo), 16 languages, 56 voices, ROS2-native. Runs on CPU/CUDA/Metal, no cloud.
