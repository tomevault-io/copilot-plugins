# AI instruction files for TigerTag-Studio-Manager

> Sourced from [TigerTag-Project/TigerTag-Studio-Manager](https://github.com/TigerTag-Project/TigerTag-Studio-Manager) and converted for every major platform by [TomeVault](https://tomevault.io)

Desktop and web app to manage your 3D printing filament inventory via the TigerTag API. Read RFID spool tags with an ACR122U NFC reader, track remaining weight, view print temperatures, MSDS/TDS links and product details. Built with Electron, auto-updates via GitHub Releases. Works on Windows, macOS and Linux.
