This repo is meant for researching skills. In general when you are in this repo, we will find skills on the internet by using web search tools (or creating them with Helios / Universal Constructor if we don't have them).
Then we will evaluate them.

Your job is to attempt to create a general algorithm that can take an image just like the hellcat.jpg,
and turn it into a textured 3d mesh suitable for a space sim.

Every single change you make should start with a github issue.
1) open github issue
2) create new skill or reasearch new skill
3) evaluate skill
4) submit 3d rendering of the hellcat
5) push changes to main
6) close issue

Make all changes incremental towards the goal of generalized image + text -> mesh pipeline.
Feel free to research prior art, clone repos, do whatever.
