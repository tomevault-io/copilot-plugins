# TomeVault GitHub Copilot Plugins

AI instruction files in `.github/copilot-instructions.md` format, packaged as VS Code / GitHub Copilot agent plugins. Each is graded against the public Tome Standard and kept in sync across every major AI platform by [TomeVault](https://tomevault.io).

## Install

Browse the per-plugin directories and copy a plugin's `.github/copilot-instructions.md` into your project, or follow the per-plugin README for VS Code marketplace install steps.

## Browse

Search, filter, and discover instruction files across every platform at [tomevault.io](https://tomevault.io).
