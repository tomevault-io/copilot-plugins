# TomeVault GitHub Copilot plugins

Instruction files in `.github/copilot-instructions.md` format, packaged as VS Code and GitHub Copilot agent plugins by [TomeVault](https://tomevault.io).

Every plugin here was indexed from a public GitHub repository, scanned for credential leaks, prompt injection, and unsafe shell patterns, and graded before publication. The same files are converted and published in parallel for Claude Code, Codex, Cursor, the Gemini CLI, and Windsurf, so behaviour authored for one agent runs on all of them.

## Install

Browse the per-plugin directories and copy a plugin's `.github/copilot-instructions.md` into your project, or follow the per-plugin README for setup steps.

## Browse

Search, filter, and check the scan grade for any file at [tomevault.io](https://tomevault.io).
