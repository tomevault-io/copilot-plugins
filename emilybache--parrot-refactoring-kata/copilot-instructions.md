This repository contains an exercise translated into several programming languages, each in their own folder. All the language versions are inspired by the original (Java) and provide equivalent behaviour and tests. At the same time each version should feel familiar to regular users of that programming language and use the normal idioms, code layout and standard libraries.

* **ALWAYS** start replies with the project emoji: 🦜. Append further emojis to show which skills you are using.
* This repository has agent skills under the folder .agents/skills
