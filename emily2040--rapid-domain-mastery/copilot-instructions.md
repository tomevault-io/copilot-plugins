# Rapid Domain Mastery Rule

Use this guidance for source-heavy learning tasks:
- start with corpus audit
- prefer mental models over summary
- separate consensus from disagreement
- find assumption gaps
- generate diagnostic questions
- switch to tutor mode when the user answers interactively
