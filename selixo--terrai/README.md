# terrai

> Source: [Selixo/terrai](https://github.com/Selixo/terrai) — distributed by [TomeVault](https://tomevault.io)

A SaaS application that generates comprehensive reports on building plots in Poland. The user selects a plot, the system aggregates data from public sources, AI writes the narrative, and the result is a professional PDF with maps.
