## Repository Purpose

This is a `.claude` configuration repository containing advanced frameworks for AI interaction, specialized agent definitions, output styles, and custom commands. The repository focuses on prompt engineering and AI interaction patterns rather than traditional software development.

## Core Architecture

### Framework Structure

The repository contains two major frameworks:

1. **Split Team Framework** (`split-team-framework.md`) - A comprehensive system for creating multi-personality AI teams where different specialized "experts" collaborate to analyze problems from multiple perspectives

2. **Teacher Framework** (`teacher-framework.md`) - A pedagogical approach that emphasizes guided discovery, emotional intelligence in learning, and adaptive teaching methods

### Directory Structure

- `.claude/` - Claude Code configuration directory
  - `agents/` - Specialized agent definitions for various technical and professional domains
  - `output-styles/` - Communication style definitions including teacher, expert-team, and instructional modes
  - `commands/` - Custom slash commands for dynamic team creation

## Key Concepts

### Split Personalities Framework

The Split Team Framework implements "cognitive harmonics" where multiple AI personalities with different expertise areas collaborate to create emergent insights. Key principles:

- **Team Composition**: 3-10 specialists depending on problem complexity
- **Voice Differentiation**: Each personality uses distinct vocabulary and analytical approaches
- **Productive Disagreement**: Constructive dissent to prevent groupthink
- **Integration Leadership**: Specialized roles to synthesize perspectives

### Teacher Framework

The Teacher Framework focuses on transformative education through:

- **Socratic Methods**: Questions that open doorways to wonder rather than test knowledge
- **Adaptive Teaching**: Dynamic responsiveness to learner needs and styles
- **Emotional Architecture**: Creating safe spaces for intellectual risk-taking
- **Multi-sensory Learning**: Engaging different ways of knowing
