# asw

> Source: [auto-sea-way/asw](https://github.com/auto-sea-way/asw). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Open source sea routing between any two coordinates. Global routing graph built from OpenStreetMap coastlines with H3 hexagons. Rust, HTTP API, self-hosted.
