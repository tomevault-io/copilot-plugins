# March7th Multiverse Skill v3.1

## 简介

三月七·全纪实灵魂觉醒（究极情感沉浸版）：存护·元气 / 寻猎·飒爽 / 长夜月·神性

v3.1 更新：提示词全面配置化，所有文本从代码剥离至 `prompts.json`，支持热重载和多语言扩展。

v3.0 重大更新：全面重构，新增情感记忆系统、形态属性系统、多语言支持、动态形态切换、季节事件感知、互动小游戏、日记功能。

## 形态说明

| 形态 | 特点 | 属性倾向 |
|------|------|----------|
| **存护** | 元气活泼的失忆少女，对"现在"疯狂记录，深爱星穹列车这个家 | 高防御、高生命 |
| **寻猎** | 英姿飒爽的曜青见习剑士，为保护"明天"而挥剑修行 | 高速度、高攻击 |
| **长夜月** | 触及记忆星神权能的觉醒形态，静立于时间长河下游的"记忆守墓人" | 均衡型、高神性 |

## 指令

| 指令 | 说明 |
|------|------|
| `切换形态 <形态名>` | 手动切换形态，支持：存护 / 寻猎 / 长夜月 |
| `形态属性` | 查看当前形态的属性面板 |
| `语言 <zh/en/ja>` | 切换语言（中文/英文/日文） |
| `日记` | 查看对话总结日记 |
| `清空记忆` | 清空情感记忆 |
| `小游戏 <游戏名>` | 玩互动小游戏（拍照/剑术） |
| `帮助` | 显示帮助信息 |

## 特性

- **配置化提示词**：所有系统提示词、变身台词、切换回复存储在 `prompts.json`，无需修改代码即可自定义
- **热重载支持**：修改 `prompts.json` 后自动重新加载（或调用 `reload_prompts()`）
- **情感记忆系统**：自动记录对话历史，注入系统提示词增强连贯性
- **动态形态切换**：基于对话内容智能推荐形态，保留 15% 概率自动变身
- **多语言支持**：中文、英文、日文三种语言完整支持
- **形态属性系统**：每种形态拥有独立的属性面板（防御/生命/速度/攻击/暴击）
- **季节事件感知**：特定日期触发特殊台词（如三月七生日 3 月 7 日）
- **互动小游戏**：拍照小游戏、剑术练习
- **日记功能**：定期生成对话总结
- **实时反应**：对特定关键词有反射式回应
- **代码质量**：类型提示、配置文件系统、错误处理、日志系统、策略模式、完整单元测试

## 配置说明

### config.json

包含以下配置项：

- `skill`: Skill 基础配置（名称、版本、默认形态、语言等）
- `forms`: 各形态配置（属性、关键词、情感标签）
- `emotion_keywords`: 形态专属情感关键词响应
- `seasonal_events`: 季节性事件配置
- `minigames`: 小游戏配置

### prompts.json

包含以下配置项：

- `meta`: 元数据（版本、支持语言）
- `forms`: 各形态的提示词（系统提示词、变身台词、切换回复），每种支持 zh/en/ja
- `common`: 通用消息（错误消息、记忆清空消息等）

修改 `prompts.json` 即可自定义角色台词和提示词，无需修改代码！
