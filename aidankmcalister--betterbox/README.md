# betterbox

> Source: [aidankmcalister/betterbox](https://github.com/aidankmcalister/betterbox). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Gmail inboxes, GitHub PRs, and issues as draggable panels on one screen, so the stuff that needs you isn't buried across a dozen tabs. Built on the Gmail API; your mail stays in Google. Open source, self-hostable.
