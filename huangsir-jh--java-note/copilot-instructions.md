## 仓库用途

这是一个 **Java 学习笔记仓库**，包含 Markdown 格式的 Java 相关技术主题笔记。不是代码项目，没有构建命令、测试或包管理器。

## 目录结构

笔记按主题分为顶层目录：

| 目录  | 内容  |
| --- | --- |
| `java基础/` | Java 核心内容（泛型、设计模式、反射、IO 等） |
| `java集合/` | Java 集合框架 |
| `java多线程/` | Java 并发与多线程 |
| `java虚拟机/` | JVM 内部原理（GC、内存管理） |
| `mysql/` | MySQL 数据库（索引、事务、日志、InnoDB） |
| `redis/` | Redis（数据结构、缓存、集群、分布式锁） |
| `spring/` | Spring 框架（IoC、AOP、MVC、事务） |
| `mybatis/` | MyBatis ORM |
| `cloud/` | 微服务概念 |
| `操作系统/` | 操作系统（内存管理、锁、进程） |
| `计算机网络/` | 计算机网络 |
| `agent/` | AI Agent、RAG 系统、MCP、工作流引擎 |
| `场景题/` | 系统设计场景题 |
| `思维导图/` | Markdown 格式的思维导图 |
| `其他/` | 其他内容 |

## 笔记操作

-   所有内容都是 Markdown 格式，无需构建即可查看
    
-   修改现有笔记时可添加纠正或补充
    
-   新笔记命名遵循现有规范（如 `Java线程状态详解.md`）
    
-   所有笔记内容使用中文（与现有笔记保持一致）
    

## Git 工作流

本仓库使用 git 进行版本控制：

-   提交时使用清晰的描述，说明新增或修改了什么
    
-   遵循现有的提交信息风格（简短的中文描述）
