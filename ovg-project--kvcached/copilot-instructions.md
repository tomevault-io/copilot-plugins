# Working on kvcached

Guidance for potential contributors using an AI coding assistant on this repo.

## Drafting with AI is fine. Pasting the draft is not.

Yes, you can use AI to draft a PR description, an issue, or a review comment. BUT! You **MUST read it yourself and cut it down before you post it.** Unedited AI text is very easy to spot and expensive to review: it is long and complex, and it asserts things nobody checked.
