# flora-music-bot

> Tome by [gabrielmaialva33](https://github.com/gabrielmaialva33/flora-music-bot) — distributed by [TomeVault](https://tomevault.io)

Flora Music Bot is a powerful music and video bot for Telegram, built with Python using Pyrogram and Py-Tgcalls. With it, you can stream music, videos, and even live broadcasts in group calls from various sources. 🚀
