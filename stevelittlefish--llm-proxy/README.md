# llm_proxy

> Source: [stevelittlefish/llm_proxy](https://github.com/stevelittlefish/llm_proxy). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

LLM logging and translation proxy - exposes an ollama + openai compatible API and proxies requests onto either an Ollama server or an OpenAI compatible server (i.e. llama.cpp).  Logs all messages and allows easy integration of Home Assistant with llama.cpp.
