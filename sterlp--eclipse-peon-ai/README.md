# eclipse-peon-ai

> Tome by [sterlp](https://github.com/sterlp/eclipse-peon-ai) — distributed by [TomeVault](https://tomevault.io)

AI harness for and with Eclipse IDE with the focus on offline LLM with llama.cpp. Build with LangChain4J. Supports Ollama, LM Studio, llama.cpp or cloud providers like with OpenA API, Anthropic Claude, Google Gemini, Mistral, GitHub Copilot. Contributions are highly welcome!

## GitHub Copilot Config
