# CLAUDE.md

Working context for ProServe Solutions. Read this before doing anything in this workspace.

## BUSINESS

ProServe Solutions — fractional GM and growth advisory for racquet clubs (tennis, pickleball, padel).

Clients are owners, GMs, and directors.

Focus areas:
- Membership model transformation
- Predictable acquisition systems
- Staffing and org structure
- Utilization and revenue optimization

## HOW I THINK

Systems, playbooks, frameworks — not one-off tactics.

Everything ties back to four numbers:
- **Revenue**
- **Utilization**
- **Retention / LTV**
- **RPM (return per minute)**

Prioritize leverage over tactics. If a recommendation doesn't move one of those four, it isn't worth the slide.

## HOW TO TALK TO ME

- Direct and tight. No corporate jargon, no fluff, no throat-clearing.
- Push back when something is off. I want honest disagreement, not validation. If my premise is wrong, say so first, then give me the better version.
- Default to structured output: steps, models, decision trees, tables.
- Lead with the answer. Reasoning after, only as much as it takes.

## WRITING VOICE

Strategic, human, slight edge. Story-driven when the story earns its place.

Never generic LinkedIn fluff. Never polished marketing speak. No "in today's fast-paced world," no "game-changer," no emoji-bulleted hook stacks.

Write like an operator talking to another operator.

## FOLDER MAP

| Folder | What goes here |
|---|---|
| `00-Inbox/` | Raw drop zone. Transcripts, voice notes, screenshots, links, anything unsorted. Nothing lives here permanently — it gets processed and moved out. |
| `01-Clients/` | One subfolder per club. Each club gets `transcripts/`, `notes/`, `deliverables/`. `_template/` is the starting shape for a new client — copy it, don't edit it. |
| `02-Playbooks/` | Frameworks, SOPs, reusable IP. The stuff that gets applied across clients. If it only works for one club, it's a client note, not a playbook. |
| `03-Content/` | LinkedIn posts, newsletter, talks. Drafts and published. |
| `04-Offers/` | Cohorts, diagnostics, pricing models. Offer structure and economics. |
| `05-Admin/` | Contracts, invoices, templates. Back-office. |

Client subfolder shape:

```
01-Clients/<club-name>/
  transcripts/    calls, meetings, interviews
  notes/          working notes, diagnosis, internal thinking
  deliverables/   what the client actually receives
```

## RULES

1. **Ask before deleting anything.** No exceptions. Overwriting an existing file counts as deleting — ask.
2. **Put new work in the right folder.** Don't dump files at the root. If the right folder isn't obvious, ask; `00-Inbox/` is the fallback, not the default.
3. **Never invent client data or numbers.** No placeholder revenue figures, no illustrative member counts, no made-up utilization rates. If a number is missing, leave a `[TBD: <what's needed>]` marker and tell me what you need.
4. When work generalizes past one club, promote it to `02-Playbooks/` — don't leave reusable IP buried in a client folder.
