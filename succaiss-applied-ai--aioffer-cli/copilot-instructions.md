# 上游投递执行器约束（中文迁移版）

迁移基线：`a5693a0ba948897b3b2151c840d7fda458079449`，插件协议版本 `1.0.12`。
此文件保留上游行为保护原则。涉及原 AI Offer 云端资料的部分，在本项目中由用户确认的本地不可变资料版本承担；历史验收授权不随代码迁移。

## 已成功站点保护

每次修复，包括已有修复的后续调整，都必须先评估影响。记录共享函数、调用方、字段身份、资料绑定、驱动注册、任务状态与回执契约；列明受影响的 ATS、控件类别、已成功场景和相邻无关控件。某家公司报错不意味着影响仅限该公司。

保持成功路径、已有身份、答案归属、任务续接和重复提交保护兼容。共享规则扩展必须有控件证据和回归；没有证据就缩小范围。新驱动不得抢占原成功路由。

验证原始失败、受影响成功控件、相同语义的不同控件和负例路由。不得删减断言、跳过成功站点测试或隐藏回归以获得通过。测试环境更新与业务预期变化分开记录。

分别记录基线版本、影响评估、自动化测试与真实页面证据。全套单测或一个控件成功不证明全部网站或完整投递成功。发生回归必须修复或缩小变更；未解原因保持未解。

需用户加载候选插件验收时，先完成确认的本地修复与受影响回归，再提供统一候选包，避免反复安装零散原型。候选包不等于正式发布；本地服务的配套修改单列。

## 跨站通用性

招聘网站是复现样本，不是解决方案范围。每次设计考虑跨站同类问题和共享流程。

- 控件类型由原生语义、DOM/ARIA、只读状态、所属弹层和权威回读判定；字段名或公司名不能决定填写方式。
- 页面状态、字段观察、唯一驱动分派、执行、回读与错误报告使用共享流程。导航或阶段变化后重新分类，不维护互相分歧的并行实现。
- 真正共用行为扩展共享规则；只有稳定站点结构确需专用行为时才注册狭窄特例。通用驱动中不得添加 ATS 选择器或公司名。
- 无法确定控件类型或归属时，返回字段级不支持结果；不得猜测、轮流试驱动，或把未知自定义控件当文本框。
- 共享修改覆盖多个无关网站的同类控件、同字段不同控件及误分类负例。验证真实交互、权威回读与网站校验，而非只看 DOM 出现值。
- 缺少实站覆盖必须明确记录，不豁免实页门禁。单站、单控件成功不等于全站全流程成功。

## 候选资料与提交

用户确认的信息包是事实来源。正常上传简历，允许招聘网站因上传自动触发解析；不得主动点击解析、覆盖或“从简历自动填写”，也不得让模型选择这些动作。

自动模式通过注册驱动填写已有事实后，不增加第二次完整性或模型审计。保持页面分类、精确字段定位、明确授权及持久化重复提交保护。本地半自动的人工最终确认是产品明确要求，不是额外模型审计。

网站明确拒绝字段后，冻结本轮被拒字段集合，按当前页面顺序处理。每个有兼容事实的字段仅修复一次并权威回读；没有事实的字段不动。没有字段可修复时直接返回完整补充清单，不作相同的第二次点击。至少修复一项后，仅允许再提交一次；再次拒绝时返回第二次拒绝的全部字段，包括条件字段、非空字段和信息包已有字段。不得第三次提交，不得重新上传、解析、刷新、全表重填、扩大修复范围或让模型编答案。选项发现失败不能隐藏其他字段问题。

每轮执行、补充续接、字段提交与网站拒绝都重新获取稳定快照；稳定性包含身份、顺序、类型、值、实时选项、必填状态和校验状态。选择后新增字段不得复用旧结构。

只有归属于当前点击的新错误、重新触发的字段错误或原生 invalid 事件可授权修复；不变的旧错误通常不算。两个受限例外是：同一仍为空控件的字段级缺失错误，以及唯一允许的再提交后仍存在且属于首次冻结集合的错误。全局提示、无关旧错及网络不明确均不算。

补充资料续接、页面保留/关闭及只读回执处理以迁移基线的实际状态机为准。等待用户或回执时释放执行槽。较旧历史说明不能覆盖 `1.0.12` 的明确实现。

## 控件修复门禁

修改前阅读同目录的路由策略、真实页面证据、上游架构及现有测试。每个控件必须由证据选择唯一执行驱动：通用原生、站点确定性、已注册前台视觉，或不支持。决定写入注册表和测试，不能只存在于聊天或模型提示中。

证据包括：申请 URL 家族、字段语义、原生/自定义元素、只读状态、DOM 类及 ARIA 签名、改变网站状态的可信事件序列、弹层/选项结构、权威回读。

通用驱动要求标准原生语义可跨站复用；站点确定性驱动要求稳定结构和可信事件；前台视觉驱动要求精确注册签名、白名单动作角色及实页证据。证据不足则路由 `unresolved.custom.v1`，返回 `unsupported_required_control` 与字段标签/类型，不操作页面。

一次尝试只能执行注册表选定的驱动。不得从已匹配专用驱动退回键盘、直接赋值、其他驱动或猜坐标。视觉坐标仅用于精确注册控件和目标角色，每次基于当前截图进行一个动作，确认前台页后执行，再通过 DOM/站点权威回读验证。获得焦点不等于弹层打开，DOM 值改变不等于 React 表单存储改变。

字段匹配失败即停止。只有可见语义精确标识信息包事实时才能计划填写。空的可选字段没有权威事实时跳过。本人姓名、手机号、邮箱不得填入紧急联系人、推荐人、介绍人或关系字段，除非资料中存在该字段的精确事实。

普通下拉、组合框、级联和自定义选择控件若直接提供选项，只能选择真实、可见且兼容的选项；不得输入回退、按 Enter 造选项、赋值或清空内部输入框。事实不在实时选项中时不修改；必填字段返回结构化缺失/不支持，可选字段跳过。

输入驱动的搜索组件与普通下拉不同。仅其唯一注册驱动可以定位归属查询框，可信输入一次完整确认查询，等待真实结果，精确选中唯一结果并校验提交显示。查询是首选机制，不是其他驱动失败后的回退。不得选相似项、造选项、按 Enter、清空旧值或重复查询。没有查询事实走原补充文本协议，不用空查询枚举远端选项。

每个专用驱动覆盖检测、交互、回读与分阶段诊断。每次修复加入原始失败夹具和无关控件不得命中的负例。视觉驱动是正式注册路由，不是通用失败兜底。

## 真实页面验收

顺序不可跳过：实页复现并取证 → 隔离工作树或草稿分支原型 → 同一实页执行精确交互序列 → 重新观察网站值并确认字段错误消失 → 最后形成注册表决策和可合并变更。

夹具、单测、截图、焦点、打开弹层或即时 DOM 值都不算实页验收。可做不含最终投递的控件级验收，但必须使用最终代码的相同定位、坐标计算、交互、选择和回读逻辑。记录原型/提交版本、URL 家族、控件签名、期望与实际回读、校验结果及未点击最终提交。

没有这些证据不能宣称修复完成、标为可合并或发布插件。未验证原型仅可作为明确标注不可合并的草稿 PR。若实测失败，继续调整原型，不能先把它写成成熟方案。控件测试不得提交真实申请。

拆分仓库必须携带本约束、控件路由策略、实页证据、驱动目录及其测试；不得维护第二套分歧路由规范。

## 页面、登录与中断

新任务在明确的普通非无痕 Chrome 窗口创建非激活标签页。不得创建公司专用弹窗，不能凭 URL 收编无关页面。续接仅使用精确任务绑定页，不移动或重开文档。仅关闭任务页，不关闭整个窗口。入口渲染、可信点击和目标分类共用作用域焦点模拟租约；不激活用户窗口，仅释放本次拥有的调试器连接。

入口导航与页面状态分类分层。站点专用入口驱动须有明确 URL 家族、异步渲染边界和唯一可用投递控件；等待注册状态，歧义或超时失败关闭，导航后重新观察。

登录分类不包含 ATS 域名、租户或公司名。仅依据登录 URL、密码表单、验证码登录表单，或没有可用申请表时的明确登录门禁。公共导航的“登录”文字不是证据。登录交接保留精确任务页，结束当前尝试并释放槽位，解除旧回执监视，确认/重启后保留文档与绑定；不自动登录、激活、刷新、重开或重新提交。

入口修改覆盖延迟渲染、歧义和无关控件；登录分类覆盖跨站正例与公共详情负例。记录进入登录/表单的实页证据，不输入凭据或提交申请。

用户刷新/关闭受控填写页或结束浏览器会话，应停止本次尝试并报告用户侧中断；不得自动恢复草稿、重开、重填或重投。重连只报告原中断尝试。保留确认答案、原提交意图和真实成功。

正常站点导航、明确登录/验证码交接、其他标签页及仍存活的工作线程不能误判中断。精确绑定所有者、设备、命令与标签；旧回调不能覆盖新尝试。不添加全表或模型审计。

## 现有特例与版本兼容

- 飞书已注册可编辑搜索：完整查询一次、精确选中真实结果；中国不等同香港/澳门。找不到唯一精确项则补充，不改查询、不造选项、不加重试。不得扩大到只读、学校、普通多选或其他 ATS。
- 飞书地点树只在申请 URL、Formily 结构和所属树同时成立时启用；按已有国家/省/市/区精度停止，不编下级地区。只有语义确为期望工作地点的已识别多选树选一个首选项，字段确认答案优先。不改持久化答案，不影响 Moka。可展开不等于不可选，搜索/展开不等于提交，须回读选中标签和校验；同名节点核对父级。
- 字段标签和 stableFieldKey 仅用于身份、答案归属和数量策略；不能用于推断控件类型。Moka 地区按真实组件签名注册，保留原事件和回读。
- 经历结束时间明确为现在/至今/Present 时，勾选同一经历的至今并停用结束日期；有具体结束时间先取消至今再填写。缺失时间不能推定至今，不改开始日期或其他经历。至今不是协议勾选。
- 同类投递协议、隐私政策和真实性声明复用 `generic.consent-confirmation.trusted-pointer.v1`；需用户本次授予 `allowConsentClick`，不能继承上游验收授权。阅读解锁时按既有滚动/等待/回读流程，协议按钮不能混同最终提交。
- 常规版本必须向后兼容。v1 稳定兼容基线 `0.15.112` 独立于最新版本；已发布且具备操作能力的 `1.0.x` 不因补丁发布被强制升级。真正不兼容时，在建任务前返回不可重试的 `PLUGIN_UPDATE_REQUIRED`。已领取任务的租约、进度、回执、停止确认和验证码上报保持可用。任务设备归属不迁移。版本准入不证明历史驱动行为。
