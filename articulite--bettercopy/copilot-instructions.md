# Project-Scoped Rules

## Walkthroughs
* **Repository Walkthroughs:** All walkthroughs must be created, edited, and maintained directly within the repository under the `walkthroughs/` directory (e.g., `walkthroughs/0007_TopicName.md`) instead of the default local brain path (`<appDataDir>/brain/<conversation-id>/walkthrough.md`).
* **Name Format:** Use a zero-padded 4-digit incrementing prefix followed by an underscore and CamelCase describing the topic for the filename (e.g., `0001_StorageProfilerFixAndControlledBenchmarking.md`).
* **Structure:** Ensure the walkthrough documents the changes made, tests run, and validation results.
