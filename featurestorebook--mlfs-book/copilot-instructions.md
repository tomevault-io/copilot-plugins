## mlfs-book

> Use Hops skills when developing a ML or AI system:

Use Hops skills when developing a ML or AI system:
- hops-fg:  when reading or writing tabular data 
- hops-fv: when training a ML model
- hops-train: when training a ML model
- hops-batch-inference: when making predictions with a ML model in a batch program
- hops-online-inference: when making predictions with a ML model in a network-served deployment
