# cctrace

> Source: [androidZzT/cctrace](https://github.com/androidZzT/cctrace). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Real-time profiler for AI coding agents (Claude Code / Codex) — wraps your agent and renders every session event on a local waterfall timeline. Single Go binary, JSONL on disk, no telemetry, local-first.
