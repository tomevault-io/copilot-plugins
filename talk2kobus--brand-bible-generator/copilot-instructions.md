# AI Agents Documentation

This document provides a detailed overview of the AI agents that power the Brand Bible Generator application. These agents are responsible for interpreting user input and generating the creative assets that form the brand identity.

## Agent 1: Brand Concept Generator

This agent is the core strategist. It takes the user's high-level company mission and translates it into a structured, actionable set of brand concepts.

-   **Model**: `gemini-2.5-flash`
-   **Purpose**: To generate a brand identity framework, including a color palette, typography, and descriptive prompts for visual asset generation.
-   **Trigger**: This agent is invoked when a user submits their company mission via the input form.

### Input

The agent receives a detailed prompt that includes the user's mission statement. The prompt instructs the model to act as a branding expert and provide a response in a strict JSON format.

**Example Prompt Structure:**

```
Based on the following company mission, create a complete brand identity.
Mission: "[USER_PROVIDED_MISSION]"

Provide the output in a JSON format that strictly follows the provided schema.
The 'hex' values must be valid 6-digit hexadecimal color codes...
The font names must be valid Google Fonts...
The logo and mockup prompts must be descriptive, artistic, and suitable for a text-to-image generation model...
```

### Output

The agent's primary output is a JSON object that adheres to the `BrandConcepts` interface defined in `src/types.ts`.

-   **`responseMimeType`**: `application/json`
-   **`responseSchema`**:

```typescript
{
  type: Type.OBJECT,
  properties: {
    colorPalette: {
      type: Type.ARRAY,
      description: "A 5-color palette for the brand.",
      items: {
        type: Type.OBJECT,
        properties: {
          name: { type: Type.STRING }, // e.g., 'Primary Brand Blue'
          hex: { type: Type.STRING },  // e.g., '#FFFFFF'
          usage: { type: Type.STRING } // e.g., 'Primary call-to-action buttons'
        },
      }
    },
    typography: {
      type: Type.OBJECT,
      description: "Google Font pairings for headers and body text.",
      properties: {
        headerFont: { type: Type.STRING }, // e.g., 'Poppins'
        bodyFont: { type: Type.STRING }   // e.g., 'Lato'
      },
    },
    logoPrompt: {
      type: Type.STRING,
      description: "A detailed, artistic prompt for generating the primary brand logo."
    },
    marksPrompts: {
      type: Type.ARRAY,
      description: "An array of 2 detailed prompts for generating secondary brand marks or icons.",
      items: { type: Type.STRING }
    },
    businessCardPrompt: {
      type: Type.STRING,
      description: "A detailed, artistic prompt for generating a realistic business card mockup."
    },
    letterheadPrompt: {
      type: Type.STRING,
      description: "A detailed, artistic prompt for generating a realistic letterhead mockup."
    }
  },
}
```

## Agent 2: Visual Asset Generator

This agent is the visual artist. It takes the descriptive prompts generated by the Brand Concept agent and turns them into high-quality images.

-   **Model**: `imagen-4.0-generate-001`
-   **Purpose**: To create all visual assets for the brand, including the primary logo, secondary marks, and mockups.
-   **Trigger**: This agent is invoked multiple times in parallel after the Brand Concept agent successfully returns its JSON payload. It is called once for each image prompt (`logoPrompt`, `marksPrompts`, `businessCardPrompt`, `letterheadPrompt`).

### Input

The input is a single string: a descriptive prompt for the image to be generated.

**Example Input Prompts:**

-   `"A minimalist and clever logo for an eco-friendly coffee brand named 'Sprout & Sip'. The logo features a single, continuous line that forms both a coffee bean and a sprouting leaf. The style is clean, vector-based, and uses earthy green and coffee brown tones. Centered on a clean, off-white background."`
-   `"A realistic mockup of a business card. The card has a clean, modern design with a textured, recycled paper look. It features the 'Sprout & Sip' logo prominently on one side. The typography uses the brand's header and body fonts for the name, title, and contact information. The color scheme is based on the brand's palette, with a professional and eco-conscious feel."`

### Output

The agent returns a single generated image.

-   **Format**: The image is returned as a base64-encoded string.
-   **Configuration**:
    -   `numberOfImages`: 1
    -   `outputMimeType`: `image/png`
    -   `aspectRatio`: `1:1`
