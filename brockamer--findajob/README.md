# findajob

> Tome by [brockamer](https://github.com/brockamer/findajob) — distributed by [TomeVault](https://tomevault.io)

Self-hosted pipeline for a sane job search. Pulls listings from LinkedIn, Indeed, Greenhouse, and Gmail; LLM filters out the noise; auto-generates a tailored resume, cover letter, and company briefing for each application worth sending. Web UI for triage, Docker Compose to deploy.
