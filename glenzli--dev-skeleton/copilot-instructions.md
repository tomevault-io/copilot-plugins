# Agent Instructions

Before changing this repository:

1. Read `DEV_SKELETON.md`.
2. Read `REVIEW_SKELETON.md` when reviewing or changing skills/templates.
3. Treat those files as orientation, not authority.
4. Verify factual claims against the repository files you are editing.

Do not add CLI tooling, source indexes, long-lived implementation summaries, or test/onboarding/release workflows unless the project direction explicitly changes.

Keep skill prompts short and trigger descriptions precise. Keep templates stable and project-agnostic.
