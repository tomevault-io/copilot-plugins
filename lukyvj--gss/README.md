> Tome by [LukyVj](https://github.com/LukyVj/GSS), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

❴ ● ❵ GSS — GPU Style Sheets. A CSS-like language for 3D scenes: selectors, the cascade, nesting, keyframes and transitions, compiled into one raymarching shader for WebGPU and WebGL2. No Three.js, no meshes. Playground, VS Code extension, and a <gss-scene> tag for any page.
