# shelf

> Tome by [dgahagan](https://github.com/dgahagan/shelf), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Self-hosted home library catalog — scan barcodes or photograph whole shelves (AI vision), auto-fetch metadata & covers, track lending, series, and reading. Offline bookstore mode (PWA). FastAPI + SQLite + HTMX, single Docker container.
