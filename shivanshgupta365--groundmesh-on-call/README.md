GroundMesh On-Call is a Hermes-powered incident-response agency for failed deployments. It gathers current runtime, code, configuration, Git, and runbook evidence; detects stale or conflicting context; prepares one bounded preview remediation; verifies it through tests and ten live checks; and opens a real GitHub pull request for human approval.
