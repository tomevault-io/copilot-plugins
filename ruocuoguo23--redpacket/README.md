# redpacket

> Source: [ruocuoguo23/redpacket](https://github.com/ruocuoguo23/redpacket). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

A decentralized Ethereum red packet (hongbao) smart contract with Chainlink VRF for verifiable random distribution. Supports ETH and ERC20 tokens with both random and fixed amount modes. Built using Foundry framework with upgradeable contract architecture.
