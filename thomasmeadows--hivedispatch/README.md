# HiveDispatch

> Source: [thomasmeadows/HiveDispatch](https://github.com/thomasmeadows/HiveDispatch). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

An Agent Orchestrating Agent for Code that uses tickets in a ticketing system to conduct agents.  This project can be used locally, or on a server so that you can remotely direct coding agents through a ticketing system such as JIRA or Github Projects.
