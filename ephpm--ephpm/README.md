# ephpm

> Tome by [ephpm](https://github.com/ephpm/ephpm) — distributed by [TomeVault](https://tomevault.io)

[WIP] Rust alternative to nginx + PHP-FPM, FrankenPHP, RoadRunner etc. Embeds Zend PHP directly via FFI in a single static binary. 100% PHP compatibility and drop-in replacement for any PHP project with clustering and built-in shared KV store and SQL connection pooling.
