# Todo App - Claude Code Project

## Project Overview
This is a Next.js 15 todo application built with TypeScript, Tailwind CSS, and ESLint.

## Tech Stack
- **Framework**: Next.js 15.3.3 with App Router
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **Linting**: ESLint 9 with Next.js config
- **Fonts**: Geist Sans and Geist Mono

## Project Structure
```
src/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   ├── page.tsx
│   └── favicon.ico
```

## Available Scripts
- `npm run dev` - Start development server with Turbopack
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## Development Notes
- Uses App Router (src/app directory)
- Import alias configured as `@/*` for src directory
- Configured with Turbopack for faster development builds
- Ready for todo app implementation
