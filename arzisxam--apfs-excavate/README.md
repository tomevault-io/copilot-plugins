# apfs-excavate

> Tome by [arzisxam](https://github.com/arzisxam/apfs-excavate) — distributed by [TomeVault](https://tomevault.io)

CLI tool for extracting files from damaged, corrupted, or encrypted APFS disk images. Written in C11, macOS-first (Linux supported). Handles encryption, deleted file recovery, orphan reconstruction, and incremental checkpointing.
