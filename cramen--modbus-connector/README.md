# modbus_connector

> Source: [cramen/modbus_connector](https://github.com/cramen/modbus_connector). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Cross-platform Modbus toolkit (PySide6): master client with register table, polling, live graphs, alarms and bus scanner; device simulator (slave) with register map and expression rules; passive RTU sniffer. EN/RU UI.

The `copilot-instructions.md` file in this directory is the project config converted for GitHub Copilot.
