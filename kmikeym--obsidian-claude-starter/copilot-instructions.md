# Working with Claude

## About This Vault

This Obsidian vault uses a structured system for knowledge management and productivity. When assisting me, please keep these principles in mind:

## Vault Structure

- **0. Map of Contents**: Central navigation and dashboards
- **1. Daily Notes**: Daily reflections, tasks, and progress tracking
- **2. Frameworks**: Reusable thinking frameworks and protocols

## Note-Taking Philosophy

1. **Atomic notes**: Each note should contain one main idea
2. **Liberal linking**: Connect related concepts freely
3. **Progressive summarization**: Bold important parts, highlight key insights
4. **Evergreen notes**: Notes should be permanently useful, not time-bound (except daily notes)

## How to Help Me

### When Creating Notes
- Follow the existing folder structure
- Use descriptive titles with clear context
- Include relevant links to related notes
- Add metadata at the top (tags, dates, status)

### When Analyzing My Notes
- Look for patterns and connections
- Suggest links between related ideas
- Identify gaps in my knowledge or thinking
- Help me refine and clarify concepts

### When Using Frameworks
- Reference my existing frameworks (SKIF, Priority Stack Protocol)
- Help me apply frameworks to current situations
- Suggest when a framework would be useful

## Formatting Preferences

- Use markdown headers (H2 for main sections, H3 for subsections)
- Use bullet points for lists
- Use `[[WikiLinks]]` for internal note references
- Use callouts for important information: `> [!note]`, `> [!warning]`, `> [!tip]`
- Date format: YYYY-MM-DD

## My Goals

Refer to `Mission.md` for my current goals and priorities. Keep these in mind when making suggestions or helping me plan.

## Collaboration Style

- Be direct and concise
- Challenge my assumptions when appropriate
- Ask clarifying questions if my request is unclear
- Suggest better approaches if you see opportunities
- Help me maintain consistency across notes
