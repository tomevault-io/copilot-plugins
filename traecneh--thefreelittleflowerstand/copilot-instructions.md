# Repository Guidelines

This project is a static web site. There are no automated tests, but please verify changes manually by serving the site locally with:

```
python3 -m http.server
```

## Coding Style

- Use two spaces for indentation in HTML, CSS and JavaScript files.
- Keep line length under 120 characters when practical.
- When adding a new post, follow the steps in `README.md` and ensure the post is referenced in `data/posts.json`.
