# cesium-heatbox

> Tome by [hiro-nyon](https://github.com/hiro-nyon/cesium-heatbox), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

A voxel‑based heatmap renderer for CesiumJS that converts existing entities into volumetric density maps. Automatically computes bounds, optimizes voxel count, and applies dynamic color mapping for clear spatial insight. Ships ESM/UMD builds and TypeScript types.  / CesiumJSのエンティティからボクセル型の3Dヒートマップを生成。自動範囲設定と最小ボクセルで高速描画し、密度分布を直感的に可視化。
