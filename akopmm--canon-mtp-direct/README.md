# canon-mtp-direct

> Source: [Akopmm/canon-mtp-direct](https://github.com/Akopmm/canon-mtp-direct). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

High-speed USB-C transfer utility for Canon .CR3 RAW files. Bypasses Android’s 99-file selection limit using native MTP Host Mode and Foreground Services for stable, large-scale imports.
