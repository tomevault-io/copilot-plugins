# springcat

> Source: [lastwhisper00/springcat](https://github.com/lastwhisper00/springcat). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

SpringCat is a lightweight desktop companion that tracks AI coding tasks and displays their progress in a transparent, always-on-top panel. It supports tools such as Codex CLI, Cursor, Gemini CLI, Grok CLI, and WorkBuddy while keeping user data private and stored locally.
