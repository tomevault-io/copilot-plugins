# coreai-kit

> Tome by [john-rocky](https://github.com/john-rocky/coreai-kit), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Run LLMs, VLMs, ASR, TTS, diarization and more fully on-device with Apple's Core AI framework (iOS/macOS 27) — one line of Swift per model, 53 models pinned to immutable Hugging Face revisions, each gated against its source model before enrollment. Plugs into Apple's FoundationModels API: LanguageModelSession with tool calling + guided generation.
