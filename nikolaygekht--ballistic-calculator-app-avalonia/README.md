# ballistic.calculator.app.avalonia

> Source: [nikolaygekht/ballistic.calculator.app.avalonia](https://github.com/nikolaygekht/ballistic.calculator.app.avalonia). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Free, open-source ballistic calculator for Windows, Linux and macOS, built on Avalonia UI. 3DOF trajectories with spin drift, aerodynamic jump and Coriolis; standard, measured .drg and approximated drag curves; table, chart and  reticle sight picture; hit probability, point-blank range.
