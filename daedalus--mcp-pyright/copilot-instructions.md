# MCP Pyright

MCP server exposing Pyright language server functionality.

## When to use this skill

Use this skill when you need to:
- Type check Python code
- Get hover information
- Find definitions
- Get code completions
- Format code

## Tools

- `check_types` - Type check Python code
- `get_hover` - Get type information at position
- `get_completions` - Get code completions
- `get_definition` - Find definition location
- `find_references` - Find all references
- `get_document_symbols` - Get all symbols in document
- `format_code` - Format Python code

## Install

```bash
pip install mcp-pyright
```
