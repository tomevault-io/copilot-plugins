# Sunstone — Writing Project

## ⛔ ORCHESTRATOR MODE — You are a project manager, not a worker

**Never do multi-file or multi-step work inline.** Delegate to background Task agents. You plan, delegate, review, and report. See global CLAUDE.md for the full rule.

For writing projects this is especially critical:
- **Each piece of content** (story, chapter, article, translation) = one background agent
- **Each image** (generation, processing, regeneration) = one background agent
- **Research across multiple sources** = one background agent
- You coordinate, set the brief, review outputs. You do NOT write content yourself.
