在 MiMoCode 的 Agent 环境下，纯文本模型 MiMo-V2.5-Pro 通过智能体编排获得多模态能力：MiMoCode 按需调用具备原生视觉能力的 MiMo-V2.5 处理图像输入，集成 MiMo-V2.5-ASR 实现语音指令转译，并将多模态上下文结构化存储于三重记忆系统中。纯文本"大脑"负责深度推理，多模态模块负责感知输入，协同完成从语音/图像到代码的全流程闭环。
