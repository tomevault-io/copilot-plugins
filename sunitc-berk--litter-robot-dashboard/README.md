This repository shares the Litter-Robot dashboard I built to track the litter and health habits of my cats. A Litter-Robot is an automated, self-cleaning cat litter box: after a cat uses it, it sifts the waste into a sealed drawer, keeping the box clean and giving each cat a fresh bed of litter.
