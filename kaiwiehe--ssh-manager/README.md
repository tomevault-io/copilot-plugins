SSH Manager is a lightweight Windows desktop app for organizing and launching SSH sessions from one place. It combines WinSCP sessions, ~/.ssh/config hosts, and custom app-defined entries into a single tree view, with support for quick connect, session grouping, SSH key deployment, and local port forwarding through Windows Terminal.
