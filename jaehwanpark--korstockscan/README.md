# KORStockScan

> Tome by [JaehwanPark](https://github.com/JaehwanPark/KORStockScan), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

🚀 KORStockScan - AI 기반 코스피 퀀트 자동매매 스나이퍼 KORStockScan은 키움증권 REST API+와 머신러닝(Stacking Ensemble)을 활용하여 코스피(KOSPI) 우량주를 스캐닝하고, 실시간 웹소켓을 통해 최적의 타점을 잡아내어 완전 자동매매를 수행하는 퀀트 트레이딩 봇입니다.  단순한 기술적 지표를 넘어 **'스마트 머니 가속도(외인/기관 매집 속도)'**와 **'시장 상태(Regime) 판독'**을 통해 폭락장에서도 살아남는 강력한 생존력을 목표로 설계되었습니다.
