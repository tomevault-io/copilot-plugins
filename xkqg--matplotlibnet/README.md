# MatPlotLibNet

> Source: [xkqg/MatPlotLibNet](https://github.com/xkqg/MatPlotLibNet) — distributed by [TomeVault](https://tomevault.io)

A .NET 10 / .NET 8 charting library inspired by matplotlib. Fluent API, dependency injection, parallel SVG rendering, polymorphic export (SVG/PNG/PDF), and multi-platform output to Blazor, MAUI, ASP.NET Core, WPF, Angular, React, Vue, Avalonia, Uno, and standalone browser popups.
