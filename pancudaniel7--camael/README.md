# camael

> Source: [pancudaniel7/camael](https://github.com/pancudaniel7/camael) — distributed by [TomeVault](https://tomevault.io)

Camael is an open-source terminal emulator built for engineers who work under strict security and compliance requirements. Forked from Warp, it removes all telemetry, cloud dependencies, and outbound network calls, running entirely on your local machine.  Built for finance, defense, healthcare, and government environments.
