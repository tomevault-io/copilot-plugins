# deepl-to-llm

> Source: [xyonium/deepl-to-llm](https://github.com/xyonium/deepl-to-llm) — distributed by [TomeVault](https://tomevault.io)

DeepL-compatible translation API backed by an LLM - a drop-in replacement so DeepL-wired tools (Collabora Online, etc.) translate with an LLM, with zero client-side changes. Structure-preserving HTML, optional DeepL passthrough with LLM fallback.
