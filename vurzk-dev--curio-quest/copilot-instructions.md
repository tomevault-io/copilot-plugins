# Curio Quest Revival — Diretrizes do Workspace

## Contexto do Projeto
- **Servidor Offline:** Python 3 com `asyncio` rodando nas portas 9899 (ElectroServer 5 binário) e 8080 (HTTP CDN de Books XML e Assets).
- **Cliente:** Adobe AIR 3.4.3 (ActionScript 3 decompilado em `reverse/client_as3`).
- **Dispositivo Real:** Xiaomi Redmi Note 11S (Android) conectado via ADB e Wi-Fi.
