# No Cursor product URLs in published text

Do **not** mention `cursor.com`, `www.cursor.com`, Cursor Cloud, Cursor docs URLs, or “made with Cursor” in anything that lands in this repository or on GitHub.

Applies to:

- Commit subjects and bodies
- PR titles and bodies
- Issue titles, bodies, and comments (`gh issue`, `gh pr comment`)
- README, `docs/`, `CONTRIBUTING.md`, changelog, release notes
- Code comments, CI logs you author, GitHub Action `run` names you add
- Co-authored-by trailers and “generated by” footers

```
❌ docs: generated in Cursor (cursor.com)
❌ See https://cursor.com/docs/...
✅ docs: link phased GitHub issues from the README
```

If a tool would auto-append a Cursor URL or attribution, strip it before commit / `gh pr create`. Talk about **SentryHulud**, npm, CI, and the pipeline — not the editor.
