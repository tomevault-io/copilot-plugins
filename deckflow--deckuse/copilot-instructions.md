# No Cursor attribution

Never add any of these to commit messages, PR bodies, or code comments:

- `Co-authored-by: Cursor <cursoragent@cursor.com>`
- `Made-with: Cursor`
- Any other Cursor attribution / trailer

When creating commits or pull requests, use only the requested message/body content.
