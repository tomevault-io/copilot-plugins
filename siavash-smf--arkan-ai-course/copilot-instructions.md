# CLAUDE.md — ریپوی آموزشی «آرکان، صفر تا صد»

این ریپو، آرشیو منظم شش هفته‌ی دوره‌ی هوش مصنوعی است. کلاینت **فرضی** است: «آرکان،
مشاور استراتژی و رشد کسب‌وکار». هر هفته یک محصول هوش مصنوعی جدید به این کلاینت
اضافه شد.

**این ریپو در درجه‌ی اول یک سند آموزشی است، نه یک محصول در حال توسعه.** قبل از هر
تغییری، این را در نظر بگیرید.

### ⚠️ مهم‌ترین نکته‌ی این ریپو

`apps/۰۱`، `apps/۰۲` و `apps/۰۴` **سه اسنپ‌شات از یک کدبیس‌اند** (به ترتیب زمانی).
`۰۱` و `۰۲` عمداً برای مقایسه و `diff` نگه داشته شده‌اند.

- **برای هر تغییری روی کد سایت/چت‌بات/CRM → در `apps/۰۴-crm/` کار کنید.**
- `apps/۰۱` و `apps/۰۲` **آرتیفکت تاریخی‌اند و نباید تغییر کنند.** اگر باگی در
  آن‌ها هست، همان باگی است که آن هفته وجود داشت — و ارزش آموزشی دارد.

### باگ عمداً رفع‌نشده

`max_tokens = 800` در `apps/۰۴-crm/supabase/chatbot-schema.sql` باعث می‌شود پاسخ‌های
چت‌بات وسط جمله قطع شوند. **این عمداً رفع نشده** تا دانشجو چرخه‌ی
ارزیابی → کشف → رفع → ارزیابی مجدد را تجربه کند. رفعش نکنید مگر کاربر صریحاً بخواهد.

## ۲. الگوهای مشترک همه‌ی اپ‌ها

هر پنج اپ: **Next.js 14 App Router + TypeScript (strict) + Tailwind + Supabase +
OpenRouter**. بدون تست، بدون ESLint config، بدون CI — عمداً.

```bash
npm run dev      # ۳۰۰۰ برای همه، apps/۰۵-سنجش روی ۴۲۰۰
npm run build
```

### زبان

تمام کد، کامنت، پرامپت، رشته‌های UI و مستندات **فارسی** است و RTL کامل. موقع ویرایش
همین را رعایت کنید — از جمله پیام کامیت. فونت‌ها: Estedad (عنوان) / Vazirmatn (متن)،
لوکال از `public/fonts/`.

کامنت‌ها باید **«چرا»** را توضیح دهند، نه «چه».

### 🔴 هک OpenRouter

همه‌ی اپ‌ها یک `fetch` سفارشی دارند که به بدنه‌ی هر درخواست تزریق می‌کند:

```ts
body.reasoning = { effort: "low" }
```

**این را حذف نکنید.** بدون آن، مدل‌های Gemini کل بودجه‌ی توکن را صرف reasoning
می‌کنند و خروجی خالی می‌دهند. به همین دلیل `maxOutputTokens` همه‌جا ≥ ۲۰۰۰ است.

### 🔴 خروجی JSON

هیچ‌جا `generateObject` استفاده نشده — عمداً. الگوی رایج:
`generateText` → حذف code fence → برش از اولین `{` تا آخرین `}` → `JSON.parse` →
`zod.parse` → یک retry با فیدبک خطا.

### 🔴 کش نکست

`supabase-js` زیر کاپوت `fetch` می‌زند و Next.js کشش می‌کند؛ `force-dynamic` جلویش
را **نمی‌گیرد**. کلاینت باید `global.fetch` را با `cache: "no-store"` بپیچد.

### RLS بدون policy

همه‌ی جدول‌ها `enable row level security` دارند با **صفر policy**. عمدی است — کل
دسترسی از سرور با `SUPABASE_SERVICE_ROLE_KEY`. کلاینت anon اضافه نکنید مگر با policy.

### پالت برند

`pine #143A32` · `brass #B5853A` · `bone #F7F3EC` · `sand #E7DECF` · `ink #15201C`
· `slate #5A5F5B` — نسبت ۶۰/۳۰/۱۰. CTA همیشه pine + متن bone. brass هرگز برای متن
ریز روی سفید.

## ۳. قواعد کار روی این ریپو

1. **`apps/۰۱` و `apps/۰۲` را تغییر ندهید** — اسنپ‌شات تاریخی‌اند.
2. **برای کد سایت/چت‌بات/CRM در `apps/۰۴-crm/` کار کنید.**
3. **فارسی بنویسید** — کد، کامنت، UI، کامیت‌مسیج.
4. **هک `reasoning:{effort:"low"}` را دست نزنید.**
5. **از `generateObject` استفاده نکنید.**
6. **باگ عمدی `max_tokens=800` را بدون درخواست صریح رفع نکنید.**
7. **هیچ `.env.local` واقعی در این ریپو نیست** و نباید اضافه شود — فقط
   `.env.local.example`.
8. **مخاطب دانشجوست** — کد باید خوانا و آموزشی بماند؛ انتزاع زودهنگام اضافه نکنید.
9. **بدون تست و lint** — بعد از تغییر کد، `npm run build` بزنید.
10. **اگر درسی از یک باگ گرفتید، در [`docs/درس‌های-مهندسی.md`](docs/درس‌های-مهندسی.md)
    بنویسید.** دو تا از باگ‌های این پروژه دو بار تکرار شدند چون بار اول جایی نوشته
    نشده بودند.
