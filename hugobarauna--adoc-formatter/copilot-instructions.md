# adoc_formatter

Always use Tidewave's tools for evaluating code. Prefer `project_eval` over
running `elixir` or `iex` through the shell.

Use `get_docs` to access documentation and the `get_source_location` tool to
find module/function definitions.

Tidewave's MCP server needs to be running: `mix tidewave`.
