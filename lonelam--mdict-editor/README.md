# mdict-editor

> Tome by [lonelam](https://github.com/lonelam/mdict-editor), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Visual editor for MDict .mdx/.mdd dictionaries — category-managed resources, CodeMirror editing with Ctrl+Click resource jumps, compression pipeline, export with optional lossy copies. Built on mdictlib (Rust) + Tauri 2 + Svelte 5.
