## git-commits

> Git commit rules — no Cursor attribution


Never add "Made-with: Cursor", "Co-authored-by: Cursor", or any Cursor/agent attribution to commits or PRs.

When committing, use only the user's git identity. Commit messages must contain only the subject and body you write — no trailers, footers, or co-author lines.
