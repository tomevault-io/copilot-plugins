# ani-sync

> Source: [Gilfaro/ani-sync](https://github.com/Gilfaro/ani-sync). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Ani-Sync is a robust Rust-based CLI tool for people who manage their anime and manga tracking lists across multiple platforms. It provides a non-destructive, ID-based synchronization mechanism to keep MyAnimeList (MAL), AniList, Kitsu, and MangaBaka lists in harmony.
