同频（Resonance）是一个本地化的 ETF「国家队」资金监控系统。它通过价格位置、份额流向、交易方向、成交额热度、融资杠杆五个指标各自亮灯，当同色灯≥3盏时判定为「危险共振」或「机会共振」，量化识别中央汇金等资金的系统性进出。数据、计算、存储全部在本机，支持一键重建全量历史、定时增量拉取，并提供 CLI 供外部Agent 转 IM 预警。仅用于研究，非投资建议。
