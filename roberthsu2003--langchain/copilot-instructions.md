# LangChain 專案的 Cursor 規則

## 專案的開發環境
- 使用conda
- 專案使用的虛擬環境的名稱是`langchain`

## 終端機的執行
- 必需先進入至`langchain`的虛擬環境
- 務必先啟用 langchain 環境：conda activate langchain
- 使用該環境中的 Python 3.11.13 進行開發
