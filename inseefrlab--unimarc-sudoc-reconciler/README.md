# unimarc-sudoc-reconciler

> Tome by [InseeFrLab](https://github.com/InseeFrLab/unimarc-sudoc-reconciler), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Application web POC de la bibliothèque de l'Insee. Elle permet de comparer les notices bibliographiques du SIGB Syracuse au catalogue Sudoc (ABES), met en évidence les écarts, et permet à un·e documentaliste de corriger et compléter les notices avant de les réexporter dans Syracuse.
