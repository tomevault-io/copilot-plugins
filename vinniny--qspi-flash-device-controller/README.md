# QSPI-Flash-Device-Controller

> Source: [vinniny/QSPI-Flash-Device-Controller](https://github.com/vinniny/QSPI-Flash-Device-Controller). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

This project implements a parameterizable QSPI Flash Controller IP Core in Verilog, bridging a host processor to external QSPI flash memory devices (e.g., Macronix MX25L6436F). The modular, synthesis-ready design supports two mutually exclusive modes: Command Mode for programmable transactions (with optional DMA via AXI master) and Execute-In-Place
