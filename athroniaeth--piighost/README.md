# piighost

> Source: [Athroniaeth/piighost](https://github.com/Athroniaeth/piighost). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Keep PII out of your LLM prompts without breaking the app. piighost de-identifies text and agent conversations, then restores the real values in the response. Pluggable detectors (regex, NER, LLM) and LangChain middleware for LangGraph agents.
