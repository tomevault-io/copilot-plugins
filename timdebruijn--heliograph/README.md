# heliograph

> Source: [Timdebruijn/heliograph](https://github.com/Timdebruijn/heliograph). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

ESP32 firmware that autodiscovers solar inverters over their native RS485 protocols and republishes them as MQTT/Home Assistant, Modbus TCP, REST and Prometheus
