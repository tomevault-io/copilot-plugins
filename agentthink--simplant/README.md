# simplant

> Source: [agentthink/simplant](https://github.com/agentthink/simplant). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

SimPlant 是一款免费开源的 3D 工厂仿真器，专门用于 PLC 编程学习。在 TIA Portal、OpenPLC、Node-RED 里写梯形图或 SCL，连接后即可驱动真实的 3D 物理产线。内置 44 个工控部件、19 个教学场景和自动评分器，支持 OPC UA、Modbus TCP、Snap7、PLCSIM Advanced 四种链路，经真实 S7-1500 验证，MIT 协议，可自由扩展。
