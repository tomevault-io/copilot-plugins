# BlinkUp UI Rules

- 모바일 퍼스트
- 채팅 기반 UX 유지
- 단일 컬럼 중심
- 하단 입력/주요 액션 중심 구조 우선
- 화이트 기반 미니멀 톤
- 과한 원색 / 과한 배지 / 과한 그림자 지양
- 버튼/입력창 터치 영역 충분히 확보 (최소 h-12 / 48px)
