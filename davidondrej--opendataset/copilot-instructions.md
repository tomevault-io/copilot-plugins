# PROJECT

- This repo is the OpenDataset toolkit.
- It helps users generate small, targeted, documented datasets through
  OpenRouter.
- Outputs should be easy to inspect and ready to upload to Hugging Face.

# RULES

- Keep the stack simple: Python, stdlib runtime, minimal dependencies.
- Keep files concise and under 200 lines.
- Never commit real API keys or generated private datasets.
- Use `--dry-run` for tests and examples.
- Keep docs clear, short, and public-facing.
- Keep operating guidance neutral, lawful, and provider-compliant.
