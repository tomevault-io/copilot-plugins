# minz

> Source: [oisee/minz](https://github.com/oisee/minz). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Minz /mɪnts/ - neo compiler for Z80. Features lambdas, SMC, provable optimal RegAlloc and ABI-per-function, seamless ASM integration, Compile-time execution, OOP-like experience via UFCS. Can compile: Nanz, Lizp, PL/M, Pascal, C89, Frill (F#), ABAP. Optimized Z80 assembly for retro/embedded.
