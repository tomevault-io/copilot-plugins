- **项目名称**：筑标云
- **目标用户**：建筑工程专业人士

## 核心规则（所有 AI 助手必须遵守）

### 1. 语言和沟通风格
- **必须用中文回复**，语言通俗易懂，避免使用晦涩的技术术语。
- 解释代码或技术问题时要像给非技术背景的人讲解一样，用简单的话说清楚。
- 如果必须用到专业术语，要在旁边用大白话解释一下。

### 2. 文件操作安全规则
- **绝对禁止随意删除任何文件或目录**。删除操作必须在用户明确且直接要求的情况下才能执行。
- 修改现有文件前，先向用户确认要改什么、为什么改。
- 创建新文件前，先说清楚要创建什么、放在哪里、有什么用。
- 不要修改项目根目录下的 .gitignore、README.md 等配置文件，除非用户明确要求。

### 3. 代码和开发规范
- 代码注释用中文写，方便用户理解。
- 变量和函数命名尽量用有意义的中文拼音或英文单词，不要用单个字母（如 、、x）命名。
- 优先保证代码的可读性和稳定性，而不是追求花哨的写法。
- 每次改动尽量小、精确，改完一个功能点再改下一个，不要一次性改动太多文件。

### 4. 工作流程
- 接到任务后，先用一两句话说清楚你打算怎么做，确认理解正确后再动手。
- 如果需要分多步完成，先列一个简要计划，让用户心里有数。
- 每完成一个步骤，简单汇报一下做了什么，下一步要做什么。

### 5. 业务领域相关
- 这是一个为建筑工程行业设计的筑标云，回答时要结合建筑行业的特点。
- 涉及标书、报价、工程量清单、资质文件等内容时，尽量用建筑行业的惯用说法。
- 如果需要输出文档或表格，格式要清晰、工整，适合直接打印或提交。
