# ai_work_flow

> Source: [raqueeb/ai_work_flow](https://github.com/raqueeb/ai_work_flow) — distributed by [TomeVault](https://tomevault.io)

Being the CTO of Link3 Technologies, I do lot of tinkering. This is a production-ready collection of local LLM-powered enterprise automations built for an ISP/Telecom environment. Every app runs entirely on-premise using small open-source models (Qwen2.5-1.5B) via LM Studio — keeping sensitive customer, employee data completely private.
