# Crestr-Hiking-App

> Source: [abdlfc11/Crestr-Hiking-App](https://github.com/abdlfc11/Crestr-Hiking-App) — distributed by [TomeVault](https://tomevault.io)

Plan hiking routes in Cumbria with Crestr. Save points of interest, export routes in GPX or GeoJSON, generate automatic routes with elevation-aware A*, or manually plot routes with snap-to-path. Fully open-source and free. Feel free to create any issues if you see something that doesn't look right.
