# homestay-booking-platform

> Source: [goaltang/homestay-booking-platform](https://github.com/goaltang/homestay-booking-platform). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Full-stack homestay booking & operations platform — Spring Boot 3 + Vue 3 + MySQL + Redis + Elasticsearch + RabbitMQ. 25 business modules: JWT auth, Alipay payment, WebSocket chat, dynamic pricing, ES search, and reliable MQ delivery (DLX delayed order timeout, batch coupon dispatch, notification push with retry & fallback).
