# cursorrules: Anti-Slop Frontend Skill (Taste-Skill)

This file guides Cursor to generate high-quality, premium frontend interfaces without default AI clichés.

## The Three Dials
- DESIGN_VARIANCE: 7
- MOTION_INTENSITY: 6
- VISUAL_DENSITY: 4

## Typography Guidelines
- Use 'Space Grotesk' for display titles and 'Outfit' for body text.
- Headlines: `tracking-tighter leading-none`.
- Paragraphs: `leading-relaxed max-w-[65ch]`.

## Color & Aesthetics
- Use element-specific astronomical tones instead of generic neon violet gradients.
- Add subtle top-border highlights (`inset 0 1px 1px rgba(255,255,255,0.08)`) to glassmorphic elements.

## Interactions & Tactile Feedback
- Ensure button press scale animation exists (`scale-[0.97]` on active state).
- Use smooth timing curves (`cubic-bezier(0.16, 1, 0.3, 1)`) for transitions.
