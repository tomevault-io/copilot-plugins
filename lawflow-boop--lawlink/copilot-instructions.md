# .github Directory Rules

This directory stores GitHub collaboration metadata only.

- `ISSUE_TEMPLATE/`: issue forms and issue templates.
- `PULL_REQUEST_TEMPLATE.md`: pull request checklist.
- Do not add GitHub Actions workflows or dependency automation here without explicit maintainer approval, because CI/CD configuration is a protected project boundary.
- Do not include secrets, tokens, deployment credentials, or real case data in templates.
