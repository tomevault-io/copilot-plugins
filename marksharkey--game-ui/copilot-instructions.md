# Working Agreement

- Keep components configurable through props and game configuration objects.
- Do not hardcode a specific game's URL, API, database, or authentication behavior in shared UI.
- Preserve accessible links, keyboard behavior, and mobile/desktop responsive layout.
- Bump the package version for published changes and update consuming lockfiles.
- Run the affected game tests and production build before deployment.
