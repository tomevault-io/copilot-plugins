# AWS請求書収集ツール

## ツールの目的
- 毎月発生する複数のAWSアカウントの前々月(実行当日から見てクレジットカード請求書に記載されている請求月)のAWS利用料請求書のダウンロード処理を自動化する
   + 例えば、実行日が2026年8月であれば、2026年7月に支払いが発生している請求書を全て取得する

## 仕様
- あるアカウント(以下、ホームアカウント)に存在するS3バケット(以下、ホームバケット)に請求書の収集対象アカウント(ターゲットアカウント)の前月に支払いが発生している請求書を集約する
   + ターゲットアカウントは複数存在する
   + ホームアカウントがターゲットアカウントに含まれる可能性もある
- ホームアカウント上に作成された以下の特徴を持つIAMユーザー(以下、ホームIAMユーザー)のクレデンシャルが実行環境に環境変数のような形ですでに設定済みであるものとする
   + ホームバケットに対してファイルを読み取り/書き込みするために必要な許可を持つ
   + 後述するターゲットIAMロールをAssumeRoleする許可を持つ
- 各ターゲットアカウントに作成された以下の特徴を持つIAMロール(ターゲットIAMロール)のリストをsetting.yamlにユーザーが設定可能であるものとする
   + 当該アカウントの請求書をダウンロード可能である
   + ホームIAMユーザーがAssumeRole可能である
- setting.yamlにはホームバケットのURLもしくはARNやプレフィックスを指定できる
- 各請求書はs3://{ホームバケット}/{プレフィックス}/{対象の利用月YYYYMM} 以下に集約して保存される
- 現在の年月は特に指定がなければシステム現在時刻から取得する
   + ただし、実行時引数や環境変数などの形でユーザーが上書きできることが望ましい

## 開発言語
- AWS CLIを実行するbashスクリプトで構成するか、python sdk(boto3)を使用すること
