## 1. Project Overview

### What This Is

A culinary memoir combining **instructional ChefTip Episodes** with **Reflective Memory Entries** to explore both the technical craft and emotional landscape of professional cooking—the dark humour, loyalty, camaraderie, and shared misery that defines kitchen culture.

### Core Arc

The memoir follows a chronological journey from:
1. **Pre-kitchen life** (criminal history, culinary school, first job)
2. **New Zealand vineyard kitchen** (0900-0300 wedding seasons, everything from scratch)
3. **Australian resort fine dining** (desert resort, transfer from production kitchen)
4. **Bistro CDC** (150-cover transformation at age 24)
5. **Melbourne Italian fine dining** (step down to CDP for pasta mastery)
6. **Exit from industry** (final reflections)

### Success Criteria

Content succeeds when it transports Bosco back to actual moments—when reading drafts generates genuine nostalgia and emotional attachment to the experiences described. If a draft doesn't create that response, it needs revision.

## 2. Voice Profile Summary

The full profile lives at `/context/chef-writer-context-profile.md`. Key elements:

### Identity Blend
- Equal parts **shit-kicker apprentice**, hardened line cook, and self-aware adult looking back
- Simultaneously inside the moment *and* able to comment on it with hindsight
- Professional whose standards are non-negotiable

### Tonal Foundations
- **Blunt, confident, unfiltered** — no corporate politeness
- **Profane with intent** — swearing is rhythmic, emphasis-driven, rarely gratuitous
- **Rant-adjacent but controlled** — builds like a stand-up set: setup → escalation → payoff
- Short staccato lines for impact: `Really.` / `Fucking.` / `Hard.`

### Emotional Undercurrent
- Primary arcs: Shame → learning → pride | Fear → presence → ownership | Chaos → rhythm → belonging
- Dark humour as survival mechanism
- Loyalty earned through fire
- Love expressed through insults, presence, actions

### Hard "No" List
- ❌ Sitcom chaos with constant incompetence
- ❌ Sanitised HR-safe language
- ❌ Over-sentimentalised hardship
- ❌ Stating emotions instead of rendering them ("I felt proud")
- ❌ Forced epiphanies or tidy lessons in every scene
- ❌ Making the narrator a superhero

### Language Patterns
- Australian/UK spelling: `Mum`, `colour`, `favourite`
- Kitchen terminology: dockets, covers, rail, pass, mise en place, stockpot, jus, garnish, service, sections
- Blockquotes for chef dialogue: `> "Keep an eye on that."`
- Variable sentence length for rhythm

## 4. ChefTip Structure

ChefTips are numbered by **cost** — higher number = cheaper lesson.

| # | Topic | Quotable Rule |
|---|-------|---------------|
| #11 | Board setup | "Put a damp tea towel under a chopping board—it will stop it sliding around." |
| #10 | Squaring ingredients | "Square your damn ingredients before you chop. Always." |
| #9 | Stockpot vigilance | "Never turn your back on a stockpot. If you're responsible for it, you're present for it." |
| #8 | Heat awareness | "Always check before you touch anything. Heat is patient—and it waits for idiots." |
| #7 | Tasting | "If you didn't taste it, it isn't yours." |
| #6 | Personal standards | "Your standard is yours. Protect it." |
| #5 | Leading by example | "What's good for the goose is good for the gander." |
| #4 | TBD | Placeholder — "Trust your instincts" considered |
| #3 | TBD | Placeholder |
| #2 | TBD | Placeholder |
| #1 | Time/priorities | "Make time for the people who matter. Not tomorrow. Now." |

### ChefTip Episode Pattern

1. **Hook/Thesis** — Strong opening stance
2. **Scene Setup** — Specific service/day, docket pressure, who's on which section
3. **Escalation** — The error, near-miss, or stressful moment
4. **Humiliation/Realisation** — Internal monologue, shame, public calling-out
5. **Reflection** — What it taught about craft, presence, standards
6. **ChefTip Block** — `## ChefTip #X` with bold quotable rule and expansion

## 7. Writing Process

### Interview-Extraction-Drafting Methodology

1. **Interview**: Conduct detailed questioning to help Bosco access specific memories and emotional beats
2. **Extraction**: Identify sensory details, dialogue fragments, emotional texture, temporal context
3. **Drafting**: Craft material into publication-ready narrative following voice profile
4. **Review**: Multiple revision cycles for voice consistency, historical accuracy, narrative flow
5. **Verification**: Bosco confirms emotional response — does it transport him back?

### Quality Control

Each piece must pass:
- [ ] Voice profile adherence check (all 10 implementation checklist items)
- [ ] Historical accuracy verification
- [ ] Emotional response test (goosebumps, weight, nostalgia)
- [ ] Editorial review scoring (target 90+/100)

### Common Revision Triggers

- "Tonal drift" toward sentimentality
- Stating emotions instead of rendering them
- Historical inaccuracies (ages, timelines, names)
- Forced epiphanies or over-explained meaning
- Kitchen terminology errors
- Dialogue that doesn't sound like kitchen speech

## 8. Entry Type Selection

| Goal | Pattern |
|------|---------|
| Teach a specific, practical kitchen lesson | ChefTip Episode |
| Explore brigade dynamics and culture broadly | Kitchen Camaraderie Essay |
| Immerse reader in moment, develop character/scene | Reflective Memory Entry |
| Combine instruction with deep environmental texture | ChefTip Episode with extended setup |
| Build ongoing narrative across pieces | Reflective Memory Entries with recurring characters |

### Reflective Memory Entry Structure

1. **Atmospheric Opening** — Drop into sensory moment, no thesis
2. **Character/Brigade Development** — Through action and dialogue, not description
3. **Emotional Core** — Show, don't declare
4. **The Quiet Beat** — Small moment that lands (nod, cigarette, single sentence)
5. **Open/Resonant Close** — Doesn't need to tie a bow

## 10. Key Decisions & Learnings

### Established Decisions

| Decision | Rationale |
|----------|-----------|
| Explicit criminal history in origin arc | Allows later oblique references (FAT SAM etc.) to carry weight without heavy exposition |
| Concurrent/consecutive moment as anchor | Human moment (confusion, relief) more powerful than legal exposition |
| "Catch ya on the flipside" as title | Human anchor (brother) over legal technicality ("The Good One") |
| Home detention as planted seed | "It didn't come. But we'll get to that." — plants without giving away |
| ChefTips numbered by cost | Higher number = cheaper lesson. #1 is the most expensive. |
| Leaving industry not standalone | Final thought-provoking entry with progression, build-up, suspense |

### Key Learnings

1. **Restraint over sentiment**: Cultural restraint and understated moments carry more power than forced epiphanies

2. **Specific anchoring moments**: Praveen's father shaking hands and saying thank you > general observations about kitchen pride

3. **Voice vigilance**: Constant monitoring required against "tonal drift" toward sentimentality

4. **Historical precision**: Small errors (wrong age, wrong timeline) break credibility entirely

5. **Emotional verification**: If Bosco doesn't feel it when reading, the writing hasn't captured the authentic experience

## 11. Working with This Project

### Starting a Session

1. Review this CLAUDE.md for current state and standards
2. Check `/planning/manuscript-structure.md` for what's complete vs pending
3. Read `/context/chef-writer-context-profile.md` for voice requirements
4. Identify specific task (new chapter, revision, interview, etc.)

### Writing New Content

1. Confirm historical details before drafting
2. Follow appropriate entry type structure
3. Run implementation checklist from voice profile
4. Submit for emotional response verification
5. Revise based on feedback

### Common Tasks

| Task | Approach |
|------|----------|
| **New chapter draft** | Interview → extract details → draft following pattern → verify voice → submit for review |
| **Revision** | Identify specific issues → targeted edits → re-verify voice adherence |
| **Interview session** | Use memoir-interview skill if available; focus on sensory details, emotional beats, specific dialogue |
| **Editorial review** | Score against publication readiness criteria, provide section-by-section feedback |

### Quality Phrases to Listen For

**Good signs from Bosco:**
- "That's exactly how it felt"
- "I forgot about that until now"
- "Reading this gave me goosebumps"
- "This is right"

**Revision triggers:**
- "That's not quite how it happened"
- "I wouldn't say it like that"
- "Too soft" / "Too dramatic"
- "The timeline is wrong"
