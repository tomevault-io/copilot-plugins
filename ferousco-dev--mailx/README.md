# Mailx

> Source: [Ferousco-dev/Mailx](https://github.com/Ferousco-dev/Mailx). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

MailX is open-source, developer-first email infrastructure built from the protocol up in Go. It accepts mail over SMTP or a tenant-scoped REST API, stores the source message, processes delivery through a durable PostgreSQL and Redis pipeline, and exposes lifecycle events through signed webhook
