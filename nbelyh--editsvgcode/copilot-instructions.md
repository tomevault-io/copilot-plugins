# Project conventions for Claude

## Git

- **Never commit without explicit confirmation.** Before *every* commit, stop,
  show what would be committed (the diff / staged files and the proposed
  message), and wait for the user to approve. No exceptions — every commit,
  every time. The same applies to pushing.
