# puter-pool

> Source: [Parithosh-Varma/puter-pool](https://github.com/Parithosh-Varma/puter-pool). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

This is Puter Account Pool Manager, a free AI API proxy that pools multiple Puter.com accounts to provide unlimited AI credits. It routes requests across accounts, automatically failovers when daily limits are hit, and exposes an OpenAI-compatible endpoint (/v1/chat/completions) supporting 400+ models (Claude, Gemini, GPT-4o, DeepSeek, etc.).
