# tibotattle

> Tome by [adamallcock](https://github.com/adamallcock/tibotattle), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Privacy-first monitoring for Codex allowance value. TiboTattle reads the session metadata that Codex already stores on your Mac, reconstructs your usage at standard API prices, and compares it with the quota movement your provider reports — so you can see where your allowance stands.
