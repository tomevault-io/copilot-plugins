# stave

> Source: [sufield/stave](https://github.com/sufield/stave) — distributed by [TomeVault](https://tomevault.io)

Stave is a risk reasoning engine that performs static analysis of cloud infrastructure configuration snapshots against system invariants via CEL predicates. It exports standardized facts (JSONL, SMT-LIB) for external reasoning engines from air-gapped snapshots without cloud credentials.
