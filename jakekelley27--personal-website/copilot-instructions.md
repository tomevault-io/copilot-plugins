# Personal Website Project

A self-hosted portfolio and digital presence platform, built with complete control over content and design.

## Vision
Replace social media with a curated, self-hosted website that serves as the primary digital footprint. Integrate with LinkedIn and other platforms for discoverability, but maintain full control over what information is displayed.

## Structure
- **Resume/CV Section**: Creative, digestible presentation of professional experience
- **Data Science Projects**: Showcase of data science work and explorations
- **Photography Portfolio**: Curated selection of best photography work
- **Professional Interests**: Curated visibility into career and hobbies

## Hosting
- Linux server (security hardening and hardening practices to be implemented before public exposure)
- Static site deployment (React/Vue SPA deployed as static files)

## Development Approach
- Modular, iterative development — build sections in phases
- Static-site architecture for simplicity and control
- Design and content-focused initially, dynamic features added as needed
