# GoWDK

> Tome by [cssbruno](https://github.com/cssbruno/GoWDK) — distributed by [TomeVault](https://tomevault.io)

GOWDK is an experimental Go-first web application framework for shipping full-stack web apps as a single deployable binary.  It brings together backend logic, routing, reactivity, forms, APIs, static assets, and server-side rendering with fewer moving parts, fewer dependencies, and a smaller supply-chain attack surface.
