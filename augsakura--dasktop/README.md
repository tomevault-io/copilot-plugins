# Dasktop

> Tome by [AugSakura](https://github.com/AugSakura/Dasktop), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Dasktop 是一款面向 Windows 桌面的轻量整理工具。它通过可移动、可调整大小的 Box，把桌面上的文件、文件夹和快捷方式按用途分组，让桌面保持清爽，同时保留原有文件位置和系统打开方式
