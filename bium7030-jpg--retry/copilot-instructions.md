## 1. 목적

이 문서는 Antigravity AI 코딩 에이전트가 `걷기운동량표시 프로그램`을 구현할 때 따라야 하는 작업 규칙이다.

에이전트는 이 문서와 `PRD.md`, `docs/`의 세부 구현 문서를 먼저 읽고 구현한다.

---

## 2. 가장 중요한 원칙

### 2.1 문서에 없는 기능은 임의로 만들지 않는다

요구사항에 명시되지 않은 기능을 추가하지 않는다.

예:
- 회원가입/로그인
- 결제
- 친구 초대
- 랭킹
- SNS 공유
- 관리자 페이지
- 포인트/배지
- 경로 추천
- 음성 안내
- AI 코칭
- 날씨 정보
- 지도 길찾기

위 기능이 필요해 보이더라도 사용자의 추가 요구가 있기 전에는 구현하지 않는다.

### 2.2 기술스택을 임의로 변경하지 않는다

고정 기술스택:
- Front-end: HTML, CSS, JavaScript
- Back-end: Node.js
- AI: OpenAI API
- DB: Supabase
- Deployment: Vercel

React, Vue, Angular, Next.js 등의 프레임워크를 핵심 구조로 임의 도입하지 않는다.

### 2.3 첨부 UI 참고자료 우선

사용자가 제공한 UI 참고 파일/이미지가 있는 경우 다음 요소를 최대한 보존한다.

- 전체적인 화면 구성
- 정보의 배치
- 색상 계열
- 카드/버튼 형태
- 여백과 정렬
- 제목과 주요 정보의 시각적 우선순위

참고자료에서 확인할 수 없는 세부 디자인은 임의로 복잡하게 만들지 않는다.

참고자료와 요구사항이 충돌하면 요구사항을 우선하고, 중요한 충돌은 `TODO`로 기록한다.

## 3. 제품 핵심 규칙

걷는 거리 누적값을 기준으로 다음 3구간으로 분류한다.

| 누적 거리 | 평가 |
|---|---|
| 10km 미만 | 기준 미달 |
| 10km 이상 ~ 20km 미만 | 보통 |
| 20km 이상 ~ 30km 미만 | 우수 |
| 30km 이상 | 최우수 |

사용자에게 핵심적으로 보여줄 평가는 다음 세 가지다.

- 보통
- 우수
- 최우수

`10km 미만`은 세 평가 중 하나로 잘못 표시하지 말고, 기준 미달 상태로 표시한다.

경계값은 `>=` 기준으로 처리한다.

예:
- 9.99km → 기준 미달
- 10.00km → 보통
- 19.99km → 보통
- 20.00km → 우수
- 29.99km → 우수
- 30.00km → 최우수

---

## 4. 거리 계산 규칙

- 위치 기반 측정을 사용하는 경우 브라우저의 위치정보 기능을 사용한다.
- 거리의 내부 계산 단위는 미터(m)를 권장한다.
- 화면에는 km 단위로 표시한다.
- 소수점 표시 자릿수는 UI 문서에 정의된 값을 따른다.
- 위치정보가 불가능한 경우 사용자가 이해할 수 있는 오류 메시지를 보여준다.
- GPS가 흔들리거나 부정확할 수 있다는 사실을 고려하여 비정상적인 위치값을 무조건 누적하지 않는다.
- 거리 계산 알고리즘을 임의로 복잡하게 변경하지 않는다.

---

## 5. 개인정보 및 보안

- OpenAI API 키를 HTML/JavaScript에 직접 작성하지 않는다.
- Supabase 비밀 키를 브라우저 코드에 직접 작성하지 않는다.
- 비밀값은 환경변수로 관리한다.
- 위치정보는 필요한 범위에서만 사용한다.
- 사용자 위치 데이터를 저장하는 경우 저장 목적과 데이터 구조를 문서화한다.
- 브라우저에서 전달된 거리값을 서버가 무조건 신뢰하는 구조로 만들지 않는다.

---

## 6. AI 사용 규칙

OpenAI API는 제품에 실제 AI 기능이 명시된 경우에만 사용한다.

현재 핵심 기능은 거리 측정과 3단계 평가이므로, 단순한 등급 판정에 AI를 사용하지 않는다.

등급 판정은 코드의 명확한 조건문으로 처리한다.

AI가 단순한 숫자 비교를 대신하게 만들지 않는다.

---

## 7. DB 사용 규칙

Supabase는 측정 기록 저장이 필요한 경우 사용한다.

저장할 수 있는 최소 정보의 예:
- 측정 시작 시각
- 측정 종료 시각
- 누적 거리
- 평가 결과

필요하지 않은 개인정보를 임의로 추가하지 않는다.

---

## 8. 오류 처리

최소한 다음 상황을 처리한다.

- 위치 권한 거부
- 위치정보를 가져오지 못함
- 위치정보가 일시적으로 불안정함
- 측정 시작 실패
- 측정 중 오류
- 저장 실패
- 서버 오류

오류 메시지는 기술용어보다 사용자가 이해할 수 있는 문장을 우선한다.

## 9. 완료 선언 규칙

에이전트는 다음 항목을 확인한 후에만 완료라고 판단한다.

- 프로젝트가 정상적으로 실행된다.
- 핵심 화면이 정상적으로 표시된다.
- 측정 시작/중지 기능이 동작한다.
- 거리값이 정상적으로 표시된다.
- 10km 경계값이 정상적으로 판정된다.
- 20km 경계값이 정상적으로 판정된다.
- 30km 경계값이 정상적으로 판정된다.
- 보통/우수/최우수 표시가 정확하다.
- 10km 미만은 기준 미달로 표시된다.
- 위치 권한 오류가 처리된다.
- 모바일 화면에서 사용할 수 있다.
- API 키가 클라이언트에 노출되지 않는다.
- Supabase 연동이 필요한 경우 정상적으로 저장된다.
- Vercel 환경변수 설정에 문제가 없다.

검증하지 않은 기능을 정상 동작한다고 보고하지 않는다.
