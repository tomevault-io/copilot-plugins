# 项目开发规范

1. 每次改动完成后，都必须创建一个 Git commit，以便后续追踪和回滚。
2. 每次改动后，都必须编写或更新与改动相关的测试。交付前必须运行相关测试和验证，并确保全部通过。
3. 遵循清晰、一致且易于维护的代码规范，并采用模块化编程：模块职责单一、边界明确、依赖清晰；保持游戏核心与平台外壳分离，避免桌面 UI 或平台依赖泄漏到游戏核心中。
