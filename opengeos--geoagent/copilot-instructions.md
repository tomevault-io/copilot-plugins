# Subagents

GeoAgent **1.0** uses a **single Strands `Agent`** by default for low latency. Optional multi-agent patterns (agents-as-tools in Strands) may be documented in a future release.

See [Strands multi-agent docs](https://strandsagents.com/docs/user-guide/concepts/multi-agent/agents-as-tools/).
