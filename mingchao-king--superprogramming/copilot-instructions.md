## Development Methodology

This plugin's development follows SuperProgramming recursively — the methodology
the plugin enforces is the same one used to build it.

### Core Principles

1. **Four-Level Cache**: L1(CLAUDE.md + SessionStart) → L2(Cross-project patterns) → L3(Project quick-ref) → L4(Source code).
2. **Outline First**: No code without a design outline → save to roadmap.
3. **TDD Triplet**: RED(test first) → GREEN(minimal impl) → REFACTOR(clean).
4. **One Feature, One Review, One Test**: Each sub-function: TDD → 8-dimension subagent review → full testing.
5. **Closing the Loop**: Every task ends with roadmap update + cross-project experience extraction.
6. **Anti-Duplication**: Check roadmap §4 before creating anything new.
7. **Roadmap as Single Source of Truth**: 6-section roadmap replaces experience.md. Design + interfaces + progress + experience all in one file.

Full methodology: use `Skill` tool → superprogramming skills.

## Anti-Duplication Checklist

Before writing ANY new class/method:

| # | Check | Command |
|---|-------|---------|
| 1 | **Roadmap §4** | Read roadmap §4 first — already indexed? |
| 2 | New Service method? | `Grep "methodName" **/service/**/*.java` |
| 3 | New DTO/VO? | `Glob **/dto/**`, `Glob **/vo/**` |
| 4 | New util method? | `Grep "methodSig" **/utils/**`, `**/common/**` |
| 5 | New Mapper method? | `Grep "methodName" **/mapper/**` |
| 6 | New constant/enum? | `Grep "VALUE_NAME" **/enums/**` |
| 7 | New dependency? | `Grep "artifactId" pom.xml` |
| 8 | Similar concept exists? | Grep business keyword |
