# Repository UI Constraints

These constraints are mandatory for all pages and components in this repository:

1. Do not use large rounded corners.
2. Use small/regular corner radius only (recommended max: 8px for cards/tags/containers).
3. Do not use purple or purple-like primary accents in UI colors.
4. Prefer blue/cyan/green/orange/neutral palettes for highlights and status visuals.
