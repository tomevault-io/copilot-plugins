# screenshot-time-machine

> Tome by [mdsohaib](https://github.com/mdsohaib/screenshot-time-machine), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Screenshot Time Machine is like a Wayback Machine for your own website, a visual archive of every page over time. One command screenshots every page into dated folders on your machine, and shows which pages changed since your last run. Works with Claude Code, Cursor and Codex. Free and open source.
