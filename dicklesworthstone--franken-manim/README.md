# franken_manim

> Tome by [Dicklesworthstone](https://github.com/Dicklesworthstone/franken_manim), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

A sovereign, deterministic rewrite of 3b1b's manim in pure Rust — native TeX math typesetting (no LaTeX), an analytic Bézier renderer with the 3b1b look, certified bit-reproducible renders, and source compatibility with existing manimlib scenes. One binary; ffmpeg is the only external tool.
