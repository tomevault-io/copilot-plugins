Chinese must be used and the format of the Commit Message must be followed.

## Commit Message

Use Chinese Conventional Commits unless a stricter project rule is introduced:

```text
feat: 新增工程工作流入口调度器
fix: 修复 DDD 校验脚本编码问题
docs: 更新技能组合说明
test: 补充 TDD 协议回归用例
chore: 调整 skill 元数据
```
