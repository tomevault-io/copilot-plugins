# note-by-note

> Tome by [patrickiel](https://github.com/patrickiel/note-by-note), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Browser extension for practicing music along with any page audio or video: real-time pitch shift, speed control, loop ranges, timeline markers, chained practice snippets, vocal reducer, 10-band EQ and chord detection. Chrome MV3 side panel, built with WXT + Svelte 5.
