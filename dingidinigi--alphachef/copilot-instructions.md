# AlphaChef — Claude Code Rules

## Git Workflow

- Always commit after completing any task.
- Use conventional commit messages: `feat:`, `fix:`, `chore:`, `docs:`.
- Never batch multiple unrelated changes in one commit.
- Push to GitHub after every 3 commits.
