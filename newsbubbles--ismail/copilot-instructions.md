## ismail

> Composing, sound design, mixing or recreating a reference track with the ismail MCP tools


Before writing notes or patches with the ismail tools, read `skills/ismail/SKILL.md` and follow it: fill in the Session Sheet first, write a Listening Report after every render, and judge reference matches with `cmp_run` and its drill-down views. The files in `skills/ismail/references/` hold the details (composition, sound design, listening, recreating a reference). Call the `guide` tool once per session for the tool conventions.
