# RCH

> Tome by [ChangfengluoO71](https://github.com/ChangfengluoO71/RCH), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

RCH——本地优先的漫画读者和图书馆经理  一个基于Flutter + Rust构建的跨平台漫画阅读与个人漫画库管理器。RCH不仅仅是一个“打开漫画文件”的阅读器，而是希望把本地漫画、NAS、远程网盘、阅读记录、标签、元数据、存储和多设备同步统一到一个本地优先的漫画库系统中。
