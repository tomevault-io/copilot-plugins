## 核心优化步骤

### 第一步：分析内容现状

从以下维度评分（1-10）：

| GEO因素 | 含义 |
|---------|------|
| 清晰定义 | 有无对核心概念的准确解释（25-50字），首句直接给答案 |
| 可引用语句 | 有无可被AI直接引用的具体数据/声明 |
| 事实密度 | 是否有具体数据、时间、案例支撑（中国数据优先） |
| 来源引用 | 是否标注了来源（中文权威来源：知乎/艾瑞/官方） |
| 问答格式 | 是否采用FAQ、步骤说明等AI友好格式 |
| 权威信号 | 是否有专家背书、机构引用、平台认证 |
| 内容新鲜度 | 内容更新时间是否明确，是否引用最新数据 |
| 结构清晰度 | 段落标题、列表、表格是否清晰 |

**主要弱点**：[列出前3个最弱项]
**快速改进**：[列出最容易改进的2-3项]

### 第二步：应用GEO优化技术

#### 核心技术要点（中国特色）

1. **定义优化（前置答案）**
   - 中文给出清晰定义，25-50字，独立成段
   - 首段前150字内给出核心答案（符合中文阅读习惯）
   - 使用"什么是XXX？"、"XXX是指..."句式

2. **可引用语句创建**
   - 使用中国数据机构：艾瑞咨询、CNNIC、艾媒咨询、QuestMobile、百度指数等
   - 使用"根据XXX显示"、"数据显示"、"据XXX报道"等引出语
   - 创建具体数字+品牌+时间的可引用语句

3. **权威信号强化（中国特色）**
   - 引用中文权威：知乎高赞回答、公众号文章、官方白皮书
   - 引用行业报告：艾瑞、艾媒、36氪研究院、头豹研究院等
   - 标注专家身份：行业专家、企业高管、专业机构
   - 利用平台认证：知乎"优秀回答者"、公众号"原创"标识

4. **结构优化**
   - 使用FAQ格式（问题+答案，首问优先"什么是XXX？"）
   - 添加表格进行对比（Markdown表格）
   - 使用编号列表说明步骤
   - 添加"核心要点"摘要框
   - 首段直接给结论/答案

5. **中国语境适配**
   - 使用中国用户熟悉的表达方式
   - 引用中国本土案例和数据（避免全用英文案例）
   - 适当使用中文网络用语（视平台而定）
   - 使用中文标点和格式

6. **新鲜度标记**
   - 明确标注内容更新时间（年份要新）
   - 引用最新的行业报告/新闻（2024/2025年数据）
   - 添加"数据更新时间"标识

7. **平台适配优化**
   - 知乎风格：专业深度+数据支撑+逻辑清晰
   - 公众号风格：深度长文+故事化叙述+情感共鸣
   - 百家号风格：时效性强+SEO关键词+百度偏好
   - 小红书风格：口语化+真实体验+种草力强

## 最佳实践

1. **答案前置** - 中国AI引擎偏好直接给出答案，再解释
2. **具体数据** - 用真实数据替代模糊表述，优先使用中国数据
3. **引用权威** - 引用知乎、公众号、艾瑞/艾媒等中文权威来源
4. **结构清晰** - 使用标题、列表、表格等结构化格式
5. **语言适配** - 根据目标AI调整表达风格（Kimi偏专业，豆包偏亲切）
6. **保持更新** - 标注内容更新时间，引用最新数据（年份要新）
7. **平台首发** - 优先在知乎/公众号发布，再同步到其他平台
8. **互动运营** - 积极运营知乎/公众号互动数据（影响AI引用权重）
