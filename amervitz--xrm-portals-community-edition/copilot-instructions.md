# Repository Instructions

- Append concise entries for notable changes to the appropriate `CHANGELOG.md` `[Unreleased]` category.
- Never modify the Git index, create commits, or push changes unless explicitly requested. Do not mention whether changes are unstaged, staged, committed, or pushed unless explicitly asked for Git status.

## Commit Messages

- Follow the [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) spec, using these types: `feat`, `fix`, `build`, `ci`, `docs`, `perf`, `refactor`, `revert`, `style`, `test`, `chore`.
- Write the subject in the imperative mood.
- Do not include co-author trailers unless explicitly requested.
