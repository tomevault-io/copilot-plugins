# AGENTS.md

## Project overview
This repository contains a small static web app for tracking exchange rates, the CNN Fear & Greed Index, and basic market status information.

## Current live site
- https://fasten90.github.io/FastenFinance/

## Repository guidance
- Keep the project simple and static.
- The site is served as a GitHub Pages site from the repository root.
- Prefer plain HTML, CSS, and JavaScript changes over introducing frameworks or build tooling.
- Preserve the existing structure of the page and avoid breaking the external API calls.
- If changes affect the public UI, verify that the page still works as a static site.

## Notes
- The page uses Chart.js from a CDN.
- No local build step is required for normal edits.
