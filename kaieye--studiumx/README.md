# StudiumX

> Source: [kaieye/StudiumX](https://github.com/kaieye/StudiumX). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

StudiumX 是一款本地优先的 AI 学习工作区。项目将学习目标、课程讲义、资料资源、任务计划、专注计时和学习记录整合到统一平台，借助 AI 提供个性化教学、路径规划与学习反馈。帮助学习者将零散的学习行为沉淀为可持续迭代的个人知识资产。
