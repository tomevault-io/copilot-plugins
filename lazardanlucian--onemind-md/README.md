# onemind.md

> Tome by [lazardanlucian](https://github.com/lazardanlucian/onemind.md) — distributed by [TomeVault](https://tomevault.io)

onemind.md turns any git repo into a persistent "mind". Thoughts live as git objects on a hidden ref (refs/mind/main) — written via plumbing, invisible to git status. You get decisions with reasons, full history/diff/blame on your thinking, and it all clones with the repo. No database, no service, no API key — just git.
