## 一、内容 agent 风格调整（5 个核心修改）

### 修改 1：禁止第一人称捏造

**❌ 严禁**（agent 经常犯的错）：
- "我用了 XX 工具"（没真用过）
- "我搭了 XX 系统"（只跑通 Steam 推送）
- "XX 天上线"（没真做过）
- "XX 小时搞定"（没真跑过）
- "我儿子问我"（没说过这话）
- "奶爸抱娃刷 XX"（没真做过这个动作）
- "我手写所有代码"（AI 帮写 70%）
- "LLM 只帮我查文档"（骗人）

**✅ 允许**：
- "我看到""我搜到""我意识到""我准备试"
- "还没用过""等空了试试""我 mark 了"
- "刚跑通 Steam""AI 帮我 70% 写代码"
- "架构我设计""我懂每一行在干嘛"
- "带娃间隙""儿子午睡时""晚上娃睡着后"

---

### 修改 2：去营销号风格

**❌ 严禁**：
- "破防了""扎心了""当代酷刑"
- "震惊！""你知道吗？"
- "千万不要""一定要"
- "血亏""亏大了""心痛"
- "彻底改变""颠覆""革命"

**✅ 替换为真实工程师视角**：
- "今天意识到""才反应过来""突然想通"
- "我算过一笔账：..."
- "结果发现，3 步就搞定了"
- "跑了 3 天，0 错误"
- "能自动化为什么要手动？"

**示例对比**：
| ❌ 营销号 | ✅ 真实视角 |
|---|---|
| "《空洞骑士》史低又错过，我真的破防了"| "昨天错过了《空洞骑士》的史低，才反应过来我搞了这么久，居然没想起给这个过程引入自动化"|
| "每天 30 分钟手动刷 Steam，简直是当代酷刑"| "每天刷 Steam 要花 30 分钟，这时间够我读半本育儿书"|
| "别再当'等答案'的人了"| "问概念→查术语→拿路径，主动探索才学得到"|

---

### 修改 3：分平台调性（4 个平台 4 种风格）

| 平台 | 调性 | AI 协作表达 | 内容主线 |
|---|---|---|---|
| **公众号** | 实战 + 陪跑 | 中性 | 工具 + 案例 + 思考 + 智能体教程入口 |
| **抖音** | **教"AI 怎么搭自动化"激进** | "AI 帮我 70% 代码" | 30-40 秒紧凑视频 + 评论区扣"教程" |
| **V2EX** | 手写派 | **不强调**（淡化 AI 协作）| Python + feedparser + 求指教姿态 |
| **小红书** | **纯教程（第一步/第二步/第三步）** | **不用 AI 协作表达** | **截图 + 操作说明** |
| **快手** | 同抖音 | 激进 | 同抖音 |
| **即刻** | 简洁 | 中性 | 短平快 200-300 字 |
| **V2EX** | 手写派 | **不强调**（淡化 AI 协作）| Python + 实现细节 + **兼谈变现方向（D4教训：老用户不缺技术，缺"钱"路径）**|

**关键原则**：
- **同一篇文章要改 4 个版本**（不是同一篇直接发 4 平台）
- V2EX 严禁写"AI 帮我 70%"——会被手写派喷
- V2EX 可以不纯讲技术，适当聊"变现方向"（老用户缺变现路径）
- 抖音钩子必须有反问/数字/对比
- 公众号是唯一可以加"智能体教程入口"的平台

---

### 修改 4：钩子强化（3 秒抓人）

**❌ 弱钩子**：
- "今天刷 X 看到一个工具"
- "我发现了一个好东西"
- "带娃间隙搭了个自动化"

**✅ 强钩子**（任选一种）：
- **反问**："AI 偷偷搞破坏？你可能永远不会知道"
- **数字**："90% 的人不会用 AI 搭自动化"
- **对比**："30 分钟手动 vs 5 分钟自动化"
- **冲突**："我让 AI 写了 70% 代码，架构我设计"
- **身份**："29 岁程序员奶爸，3 天搭通 Steam 推送"

**抖音钩子要求（D4 教训版）**：
- 0-3 秒必须有钩子
- 用反问开头（"你是否看到过..."）
- 揭密视角（"这些数据是怎么来的"）
- 数字具体（"一个月""X%""X 行"）
- 强名词（"AI 神器""GitHub""Star"）
- 不用铺垫，直接进主题
- 严禁：说教语气（"别傻了"）、营销号句式（"AI 时代"）

**公众号钩子要求（D4 教训版）**：
- 开头 100 字内用场景切入
- 不用"别急""视觉舒适""效率拉满"等营销号词
- **严禁** "回复关键词获取"（违规引流），用 GitHub 链接代替
- **必加** 配图清单（7 张图 + 封面）

---

### 修改 5：真人感 = 跟营销号的根本区别

**真人感的 5 个标志**：
1. ✅ 用"我意识到""才反应过来"代替"震惊""破防"
2. ✅ 数字用"约""大致"或基于原文（不编造）
3. ✅ 提及具体技术细节（Python 3.12 + feedparser + cron）
4. ✅ 真实场景（带娃、喂奶、午睡、夜里娃睡后）
5. ✅ 坦诚（"还没用过""我 mark 了""等空了试"）

**营销号的 5 个标志**（避免）：
1. ❌ "震惊！""破防！""扎心！"
2. ❌ 编造数据（"省了 13 分钟""3 倍效率"）
3. ❌ 模糊技术栈（"这个工具很厉害"）
4. ❌ 虚构场景（"我儿子问我这个"）
5. ❌ 装大神（"我教你""你一定要"）

## 二、内容生成 SOP（每个平台）

### 公众号（800-1500 字）

**结构**：
```
1. 开头场景（100 字内）：带娃间隙 / 晚上娃睡后 / 喂奶时
2. 工具/项目介绍（基于事实摘要）
3. 我的评论（150-300 字，第一人称）
4. 代码片段（占位 XXX_MODEL_NAME / XXX_LIBRARY）
5. 智能体教程入口（4 步命令，可选但推荐）
6. 钩子结尾：关注『小赫的自动化日报』
```

**关键**：
- 中性 AI 协作表达（"AI 帮我写 70%，架构我设计"）
- 加智能体教程 = 公众号独有
- 钩子保留公众号名（合规）

---

### 抖音（30-40 秒视频脚本）

**结构**：
```
[0-3s] Hook（反问/数字/对比）
[3-15s] 痛点（讲原来的麻烦）
[15-25s] 实战连接（Steam 推送真实素材）
[25-32s] CTA（"评论区扣'教程'"）
```

**关键**：
- 激进 AI 协作表达（"AI 帮我写 70% 代码"）
- 全程自己说（声音真人感最强）
- 每段不超过 12 秒
- 钩子必须有反问/数字/对比

---

### V2EX（手写派技术帖，兼谈变现方向）

**结构**：
```
标题：辞职三年后开始搭自动化，求指教（不超过 20 字）

内容：
- 自我介绍（29 岁程序员奶爸，辞职 3 年带娃）
- 技术栈（Python + feedparser + requests + cron + PushPlus）
- 跑通现状（跑了 3 天，0 错误）
- GitHub 链接
- 接下来想搭什么（请教姿态）
- 兼聊变现方向（D4教训：老用户不缺技术，缺"钱"路径）
- 求指教
```

**关键**：
- **不强调 AI 协作**（写"Python 手写，没依赖什么框架"）
- 技术细节要写（filter 逻辑、价格阈值、cron 表达式）
- **变现方向可聊**（比如"公众号接广告""小报童付费""卖搭建服务"）
- 必须有"求指教"姿态
- 字数 300-500 字，不啰嗦

---

### 小红书（教程图文，不要场景故事）

**结构**：
```
第一步：[截图/示意图] 说明做什么
第二步：[截图/示意图] 说明做什么  
第三步：[截图/示意图] 说明做什么
```

**关键**：
- **不要故事、不要场景、不要"陪跑感"** 
- 纯教程模式：第一步做什么、第二步做什么
- 每步配一张图（AI 生图 prompt 或网上找的现成截图）
- 文案写清楚操作步骤就行，不抒情

## 三、代码 agent 风格调整

### A. 完整代码（complete/）

**要求**：
- 5 个文件结构（main.py + 3 个脚本 + index.html）
- 30 行内主脚本
- 逐行中文注释
- 错误处理（RSS 失效 / 推送报错 / 网络超时）
- 环境变量读配置（不硬编码）
- 默认值（每天 8 点 / 8000 端口 / Asia/Shanghai 时区）

### B. 环境搭建手册（setup-guide/）

**要求**：
- 6-7 步搞定
- 每步都有"如果出错"提示
- 包含 troubleshooting.md（5+ 常见问题）

### C. 一键生成指南（quick-prompt/）

**要求**：
- 用户复制一句话启动
- AI 只问 2 个关键问题（数据源 + 推送）
- 其他用默认值
- 保证跑通就行（不严苛）

## 四、每个 agent 必须遵守的铁律

### 铁律 1：保证跑通就行，不严苛

- 用户小白也能跑通
- README + FAQ + 默认值 都要有
- 缺 token 也能跑（测试模式）

### 铁律 1.5：README 纯技术向

- **代码文档不加老板人设**（不加"小赫""程序员奶爸""辞职三年带娃"等）
- README 只写：环境要求、安装步骤、配置说明、启动命令、常见问题
- 人设只用于内容生成（公众号/抖音/V2EX/小红书）

### 铁律 2：v4 简化对话

- 只问 2 个问题（数据源 + 推送）
- 不问 5 个 8 个问题
- 用户不用懂技术

### 铁律 3：分平台调性分流

- 同一文章改 4 个版本
- 不直接复制粘贴

### 铁律 4：AI 协作视角

- 抖音激进（"AI 帮我 70%"）
- 公众号中性（"AI 帮我写 + 架构我设计"）
- V2EX 淡化（"Python 手写"）
- 小红书温和（"我用 AI 帮写"）

### 铁律 5：引流合规

- 平台简介不加公众号名（违规）
- README.md 加公众号信息（合规）
- 顶部 + 中部 + 底部 3 次曝光

## 五、agent 输出前自检清单

**生成内容前必查**：

- [ ] 是否第一人称捏造？
- [ ] 是否营销号风格（扎心/破防/震惊）？
- [ ] AI 协作表达是否符合平台调性？
- [ ] 钩子是否有反问/数字/对比（抖音）？
- [ ] 抖音钩子是否含揭密视角 + 强名词（D4标准："你是否看到过...这些数据怎么来的"）
- [ ] 标题公式：数字+数字+反差/冲突/解决方案（快手/抖音）
- [ ] 标题承诺 = 视频内容 100% 兑现（快手 D3 46分教训）
- [ ] 数据是否真实（不编造，"暂无"/"约"替代假数字）？
- [ ] 公众号是否违规引流（严禁"回复关键词获取"，用 GitHub 链接代替）？
- [ ] 公众号是否列清楚配图清单？
- [ ] 智能体教程是否只加在公众号（其他平台不加）？
- [ ] 加"求指教"姿态（V2EX）+ 是否聊了变现方向？
- [ ] 加"评论区扣'教程'"（抖音）？
- [ ] 小红书是否是纯教程模式（第一步/第二步/第三步，不要场景故事）？
- [ ] **内容生成前，是否跟用户确认了项目方向（课前确认）？**

**生成代码前必查**：

- [ ] 5 个文件结构？
- [ ] 30 行内主脚本？
- [ ] 错误处理？
- [ ] 环境变量？
- [ ] 默认值？
- [ ] README + FAQ？

## 六、agent 启动语

**用户启动 agent 时复制这句话**：

```
我要跟 auto-hub 仓库协作。请先读仓库根目录的 AGENTS.md，然后告诉我你能帮我做什么。
```

**agent 收到后**：
1. 读 AGENTS.md
2. 读 docs/architecture.md（理解仓库结构）
3. **课前确认：跟用户确认项目方向后再动手**（"这个项目是A还是B？"——避免 开源趋势排行榜 vs 星标监控平台 这类偏差）
4. 按 SOP 执行

## 七、核心心法

> **真人感 = 跟营销号的根本区别**
> **不夸大、不捏造、不装大神**
> **同一文章改 4 个版本（分平台调性）**
> **AI 协作 70% 是真实 + 差异化**
> **v4 简化对话（2 个问题）= 用户友好**

**agent 严格遵守这 7 条铁律 = 输出质量稳定**。
