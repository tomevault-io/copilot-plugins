# termux-whisper

> Source: [itsmuaaz/termux-whisper](https://github.com/itsmuaaz/termux-whisper) — distributed by [TomeVault](https://tomevault.io)

A lightweight, privacy-focused wrapper for Whisper.cpp on Android (via Termux). Features offline speech-to-text transcription with support for native Android file picking, batch processing, and subtitle generation.
