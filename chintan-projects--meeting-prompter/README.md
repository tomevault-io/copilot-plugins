Liquid-Meeting-Intelligence is an open-source reference architecture for building "Privacy-First" AI agents using Liquid Foundation Models (LFMs). Unlike traditional AI assistants that rely on high-latency cloud APIs, this project runs a unified multimodal "backbone" entirely on local hardware (8GB+ RAM).
